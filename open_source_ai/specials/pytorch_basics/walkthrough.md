# PyTorch 특강 따라하기

프로젝트 준비와 시간표는 [실습지](lab.md)를 따른다. 같은 프로젝트 루트에서 진행한다.

## 1교시

`uv run ex01` → `2 3` → `/bye`. 2배 한 결과 `[4, 6]`이 파일에 저장된다.

`uv run ex02` → `outputs/tensor.pt` → `/bye`. 새 실행에서 `[4, 6]`을 읽고 다시 연산한다. [상세 절차](examples/period1/README.md)를 확인한다.

## 2교시

CSV 6행의 시간·점수를 읽고 `uv run ex03`을 실행한다. MSE·회귀식과 2.5·5.5시간의 예측을 기록한다. epoch 한 값만 바꿔 비교한 뒤 기본 설정으로 다시 학습해 저장한다.

## 3교시

`uv run ex04`에서 같은 두 시간을 입력해 저장 모델의 예측을 비교한다. 이 명령에는 학습 루프가 없다. 다른 시간도 입력하고 학습 범위 밖 예측의 한계를 적는다.
