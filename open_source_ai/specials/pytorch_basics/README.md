# 선택 특강 — PyTorch 텐서와 작은 회귀 모델

이 특강은 모델 내부 계산과 학습을 직접 살펴보고 싶을 때 진행한다. 정규 수업은 4주차 Ollama → 5주차 LangChain → 6주차 RAG → 7주차 LoRA → 9주차 Streamlit 앱 순서로 이어지며, 이 특강을 선행 조건으로 두지 않는다.

## 세 교시의 결과

| 교시 | 설명·시연 20분 | 실습 30분 | 명령 |
|---|---|---|---|
| 1 | 텐서 생성·연산·파일 저장·불러오기 | 계산 결과를 저장하고 새 실행에서 복원 | `uv run ex01`, `uv run ex02` |
| 2 | 작은 CSV 데이터와 선형 회귀 | 가상 공부 시간·점수 데이터로 학습 | `uv run ex03` |
| 3 | 학습한 가중치 저장·복원·예측 | 모델을 다시 학습하지 않고 새 시간의 점수 예측 | `uv run ex04` |

교시마다 설명·시연 20분, 실습 30분, 휴식 10분이다. 첫 시간에 자동미분 공식을 풀게 하지 않는다. 두 번째 시간의 학습 코드에서 예측 → 손실 → 기울기 계산 → 가중치 갱신을 연결한다.

## 준비와 구조

[실습지](lab.md)대로 `uv init --package --python 3.12 --vcs none pytorch-skeleton`으로 구조를 확인한다. 교재의 `examples` 전체를 개인 작업 폴더에 복사하고 그 루트에서 `uv sync`한다. 의존성은 torch와 NumPy이며 CPU로 진행한다. 별도 언어 모델 다운로드가 필요 없다.

`main()`은 시작 함수, scripts는 명령 연결, build-system은 설치 방법이다. scripts를 바꾸면 `uv sync`를 다시 실행한다. 저장 경로·회귀 데이터·예측 함수는 `src/shared/`에 모은다.

## 완료 기준

- [ ] 텐서 연산 결과를 `outputs/tensor.pt`에 저장하고 다른 실행에서 복원했다.
- [ ] 가상 데이터 6행과 `점수 = 가중치 × 시간 + 편향`의 뜻을 설명했다.
- [ ] MSE가 어떤 오차를 재는지, 학습 전후 어떻게 달라졌는지 기록했다.
- [ ] `outputs/regression.pt`를 불러와 재학습 없이 같은 입력의 예측을 확인했다.
- [ ] 학습 범위 밖 입력의 결과를 무조건 정확하다고 해석하지 않았다.
