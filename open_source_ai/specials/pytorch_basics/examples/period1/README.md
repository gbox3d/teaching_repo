# PyTorch 특강 1교시 — 텐서 연산과 파일 저장

이번 시간에는 **숫자를 텐서로 만들고, 계산 결과를 저장한 뒤 다른 프로그램에서 다시 불러온다.** 모델의 입력·가중치·계산 결과도 텐서로 다루므로, 모델을 사용하기 전에 이 동작부터 익힌다.

흐름은 `2 3 입력 → 텐서 생성 → 2배 계산 → 파일 저장 → 프로그램 종료 → 파일에서 4 6 복원`이다. 미분과 학습 루프는 이 시간에 다루지 않는다.

## 1. 실행 위치

`pyproject.toml`과 `src/`가 보이는 프로젝트 루트에서 실행한다. 이 `period1` 폴더는 설명을 읽는 곳이다.

```powershell
uv sync
uv run ex01
```

코드는 [ex01_tensors](../src/ex01_tensors/__init__.py)에 있다. `uv run ex01`은 이 패키지의 `main()`을 실행한다.

## 2. 텐서를 만들고 계산한다

프로그램의 `숫자>`에 다음을 입력한다.

```text
숫자> 2 3
```

프로그램은 입력을 `[2.0, 3.0]`이라는 텐서로 만든다. 텐서는 여러 숫자를 담고 함께 계산하는 PyTorch 자료형이다.

| 코드 | 하는 일 | 이 입력의 결과 |
|---|---|---|
| `torch.tensor(values, dtype=torch.float32)` | 입력 숫자를 텐서로 만들기 | `[2.0, 3.0]` |
| `tensor + 1` | 모든 값에 각각 1 더하기 | `[3.0, 4.0]` |
| `tensor * 2` | 모든 값에 각각 2 곱하기 | `[4.0, 6.0]` |
| `tensor.sum()` | 모든 값을 합하기 | `5.0` |

`+ 1`은 값을 하나 더 붙이는 동작이 아니다. 텐서 안의 각 숫자에 1을 더한다.

## 3. 계산 결과를 저장하고 종료한다

`ex01`은 위 계산 중 **2배 한 결과**를 저장한다.

```python
result = tensor * 2
torch.save(result, TENSOR_PATH)
```

`TENSOR_PATH`는 공용 패키지에서 정한 `outputs/tensor.pt`다. 프로그램이 `outputs` 폴더를 만들고 파일을 저장한다. 새 입력을 계산하면 같은 파일을 덮어쓴다.

```text
2배 한 결과를 저장했습니다: outputs/tensor.pt
숫자> /bye
```

VS Code 탐색기에서 파일이 생겼는지 확인한다. `.pt`는 텍스트 문서가 아니므로 편집기로 글자를 읽는 대신 PyTorch로 불러온다.

## 4. 새 프로그램에서 불러온다

PowerShell로 돌아온 뒤 두 번째 명령을 실행한다. 코드는 [ex02_save_load](../src/ex02_save_load/__init__.py)에 있다.

```powershell
uv run ex02
```

`파일>`에는 저장한 파일의 경로를 입력한다.

```text
파일> outputs/tensor.pt
불러온 텐서: tensor([4., 6.])
불러온 값에 1 더하기: tensor([5., 7.])
파일> /bye
```

불러오는 코드는 다음 줄이다.

```python
tensor = torch.load(filename, map_location="cpu", weights_only=True)
```

저장 파일에서 텐서를 읽고 CPU에 올린다. `weights_only=True`는 텐서 등 제한된 자료를 읽는 옵션이다. 이 실습에서는 `ex01`이 만든 파일을 사용한다.

`ex01`을 종료했어도 파일에는 계산 결과가 남아 있다. `ex02`는 그 값을 불러와 다시 계산한 것이다. 파일을 읽는 동작 자체가 모델 학습이나 생성은 아니다.

## 5. 입력을 바꿔 같은 과정을 반복한다

`ex01`을 다시 실행해 `-1 4`를 입력하고 종료한다. `ex02`에서 같은 파일을 불러오면 이번에는 `[-2.0, 8.0]`이 나와야 한다. 이전 `[4.0, 6.0]` 대신 마지막에 저장한 값이 남았는지 확인한다.

추가로 빈 입력은 건너뛰는지, 잘못된 숫자는 입력 안내가 나오는지 확인한다. `ex02`에 없는 파일 경로를 입력하면 먼저 저장하라는 안내가 나온다.

## 출력에 붙은 세 속성

| 표시 | 이 예제에서 뜻하는 것 |
|---|---|
| `shape: (2,)` | 숫자 두 개가 들어 있는 1차원 텐서 |
| `dtype: torch.float32` | 각 숫자를 32비트 실수로 저장 |
| `device: cpu` | 이 텐서가 CPU에서 계산됨. CUDA GPU를 사용할 수 있으면 ex01에 `cuda:0` 등이 표시될 수 있음 |

`ex02`는 읽는 장치를 CPU로 지정하므로 저장할 때 GPU를 썼어도 불러온 텐서의 device는 CPU다.

완료 기준은 두 입력의 연산 결과, 저장 파일의 위치, 새 프로그램에서 복원한 값을 설명하는 것이다. 결과와 이유는 `week05_note.md`에 남긴다. [실습지의 시간표](../../lab.md#1교시-실습--텐서-연산과-파일-저장)를 따른다.
