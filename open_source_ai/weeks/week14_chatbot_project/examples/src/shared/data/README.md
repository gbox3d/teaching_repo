# 공통 참고 자료와 공개 평가 데이터

기준일은 2026-11-12, 평가 자료 버전은 v1이다. 공식 페이지에서 확인한 사실을 교재용으로 짧게 다시 썼다.
사이트 전체를 수집하거나 원문·사진·교가를 복제한 데이터가 아니다.
공통 자료에 포함된 사실을 평가 범위로 삼으며 실시간 서비스는 조회하지 않는다.

| 문서 ID | 내용 | 공식 출처 |
|---|---|---|
| wku-location | 익산시, 도로명·번호, 우편번호, 대표전화 | [찾아오시는 길](https://www.wku.ac.kr/about/campus-info/road-map.html) |
| wku-values | 교훈, 교육목표, 건학정신 요약 | [건학정신 및 교육목표](https://www.wku.ac.kr/about/school-info/intro.html) |
| wku-symbols | 교색·교조·교목·교화 | [교가/상징](https://www.wku.ac.kr/about/school-info/symbol.html) |

| wku-services | 공식 홈페이지·웹정보서비스·WAFFLE-i·중앙도서관 주소 | [원광대학교 홈페이지](https://www.wku.ac.kr/) |

주소 페이지 본문에는 이전 광역자치단체명이 남아 있어 하단의 현재 주소 표기를 사용했다.
같은 페이지의 일부 교통 안내에는 다른 학교 이름이 섞여 있어 이 자료와 문항에서 제외했다.
연혁 페이지 제목의 오기와 개교기념일·개설일 차이로 혼동하지 않도록 개설 연도와 기관 이름을 중심으로 담았다.

## 파일 구성

- [corpus.json](corpus.json): 챗봇이 검색하거나 학습에 사용할 참고 자료 5개.
- [public_questions.json](public_questions.json): 공개 질문 20개. fact 12개, composite 4개, unknown 4개.
- [public_answers.json](public_answers.json): 질문 ID에 대응하는 정답 사실별 허용 표현, 필요한 문서 ID, 답변 불가 여부.

`unknown`은 제공된 자료로 답할 수 없다는 뜻이다. 학교의 실제 서비스에 그 정보가 없다는 뜻은 아니다.
모집 인원·실시간 좌석·개인 장학금·당일 식단은 공통 자료의 범위 밖이다.

이 폴더에는 비공개 최종 문항을 넣지 않는다.
챗봇은 corpus.json을 사용하고, 평가 도구만 질문·정답 파일을 읽는다.
공개 질문과 정답은 학습자가 점수를 이해하고 구현을 개선하기 위한 자료이며 문항별 정답 조회표로 제출하지 않는다.
자료 오류나 허용 표현 누락을 정정할 때는 버전을 올리고 모든 제출물에 같은 기준을 적용한다.

원문 권리는 각 출처에 있다. 문서별 URL과 확인일은 corpus.json에도 포함했다.
원광대학교 명칭은 이번 공개 과제의 대상으로 사용하며, 대학이 제공·보증하는 챗봇이라는 뜻은 아니다.
