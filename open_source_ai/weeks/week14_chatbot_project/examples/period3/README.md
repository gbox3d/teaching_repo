# 14주차 3교시: 학생 함수 개선과 재평가

앞선 교시의 `examples/` 프로젝트를 이어 쓴다. 수정할 파일은 [student_bot](../src/student_bot/__init__.py) 하나다. `ex03`은 `ex01`과 같은 대화 함수를 사용하므로 바뀐 학생 코드가 두 명령에 모두 적용된다.

```powershell
uv run ex03
uv run evaluate
```

`evaluate`는 `ex02`의 별칭이다. 같은 공개 20문항으로 전후를 비교한다. 질문과 정답을 새로 만들거나 교시별 자료 사본을 만들지 않는다.

30분 실습에서는 실패 원인 하나 선택, 검색 또는 프롬프트 수정, 같은 질문으로 대화 확인, 전체 재평가, 개선된 문항과 남은 실패 설명 순서로 진행한다. 근거가 없는 질문에서 답을 추측하지 않는지도 확인한다. 빈 입력은 건너뛰고 `/bye`나 Ctrl+C로 대화를 종료한다.

채점 규칙과 워커를 확인하려면 다음 테스트를 실행한다. 이 테스트에는 Ollama가 필요 없다.

```powershell
uv run python -m unittest discover -s tests -v
```

자동 테스트 통과와 실제 모델의 점수 향상은 별도 결과다. 상세 활동과 제출 기준은 [실습지](../../lab.md)를 따른다.
