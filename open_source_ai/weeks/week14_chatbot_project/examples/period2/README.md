# 14주차 2교시: 공개 시험과 오답 확인

1교시에 사용한 `examples/` 루트에서 실행한다. 프로젝트나 자료를 새로 복사하지 않는다.

읽을 파일은 [평가 진입점](../src/ex02_evaluate/__init__.py), [채점기](../src/shared/evaluation.py), [공개 질문](../src/shared/data/public_questions.json), [공개 정답](../src/shared/data/public_answers.json)이다. 점수 규칙은 [공개 시험 설명](../README.md#공개-시험과-점수)을 따른다.

```powershell
uv run ex02
```

워커가 시작될 때마다 준비 질문 한 개에 최대 120초를 허용하며 점수와 문항별 소요 시간에서 제외한다. 본 시험은 문항당 30초이고 사실 12문항·복합 4문항·자료 부족 4문항을 모두 집계한다. 문항별 응답, 정답 별칭, 세부 점수, 오류, 소요 시간을 읽는다. 결과는 터미널에 표시하고 자동 저장하지 않는다.

30분 실습에서는 평가 전 예상, 전체 시험 실행, 실패 문항의 실제 응답과 별칭 비교, 자료 검색과 답 형식 중 수정할 부분 선택 순서로 진행한다. 답변 F1이 0일 때는 출처가 맞아도 출처 득점이 0이며, 답 후보 나열은 정밀도를 낮춘다. 정답과 채점기는 수정하지 않는다. 상세 활동과 제출 기준은 [실습지](../../lab.md)를 따른다.
