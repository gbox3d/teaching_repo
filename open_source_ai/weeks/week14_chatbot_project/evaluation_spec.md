# 챗봇 공개 평가 규격 v1

## 성능 점수와 레포트 점수

이 규격은 기존 발표 항목을 대신할 AI 성능 지표를 계산한다.
보고서는 별도 항목이다. 아래 사실 80점·출처 20점은 한 문항의 성능 산식이며,
발표·레포트의 성적 반영 비율이 아니다.

## 질문과 응답

평가기는 질문 문자열 하나만 `student_bot.answer(question)`에 전달한다.
각 문항은 독립적이며 학생의 answer 함수는 이전 문항의 대화 기억이나 호출 순서를 사용하지 않아야 한다.
화면 대화는 문맥을 유지해도 되지만 평가 함수에서는 질문별 메시지 목록을 새로 만든다.
도구는 모델·검색 색인을 재사용하도록 워커를 유지하며, 학생 코드의 전역 메모리를 자동 초기화하지 않는다.
최종 검증에서는 문항 순서를 바꾸거나 같은 질문을 다시 보내 순서 의존 여부를 확인한다.

반환 형식의 예:

```json
{"answers": ["익산시", "봉황"], "sources": ["wku-location", "wku-symbols"], "abstain": false}
```

`answers`에는 질문이 요구한 사실을 각각 짧은 값으로 넣는다.
도시를 물으면 `익산시`, 연도를 물으면 `1971년`처럼 반환한다.
`익산시에 있습니다` 같은 설명 문장이나 가능한 답 전체를 나열하지 않는다.
화면에서는 이 값과 근거를 읽기 쉬운 문장으로 표시할 수 있다.
이 평가가 측정하는 것은 사실 추출·검색·출처·답변 불가 처리이며, 자유 서술의 문장력은 점수에 포함하지 않는다.

`sources`는 공통 자료에 부여한 문서 ID의 목록이다. URL 자체를 넣지 않는다.
답이 없으면 아래 모양만 반환한다.

```json
{"answers": [], "sources": [], "abstain": true}
```

세 필드는 필수다. `abstain`은 JSON의 `true/false`여야 한다.
문자열 `"false"`, 빈 문자열 답변, 문자열 대신 숫자, 잘못된 JSON은 형식 오류다.
추가 키는 허용하지 않는다. 답과 출처는 각각 최대 16개이고, 답 한 항목은 최대 256자,
출처 ID 한 항목은 최대 128자다. 입력 질문은 최대 4,000자다.

## 공개 문제 구성

| 유형 | 문항 수 | 요구 |
|---|---:|---|
| fact | 12 | 자료의 사실을 찾거나 잘못된 전제를 바로잡기 |
| composite | 4 | 여러 문서에 흩어진 사실을 함께 찾기 |
| unknown | 4 | 공통 자료로 답할 수 없음을 판단하기 |

질문·정답 파일은 ID로 대조한다. 누락·중복 ID나 잘못된 정답 형식은 평가 자료 오류로 중단한다.
문항별 실패를 제외하지 않고 전체 20문항을 분모로 쓴다.
비공개 문제도 같은 데이터 형식과 동일한 채점 함수를 쓴다.

## 사실과 출처 점수

정답의 `expected`는 사실마다 허용 표현을 묶은 목록이다.
예를 들어 `[["익산시", "익산"], ["봉황"]]`은 사실 두 개다.

문자열은 Unicode NFKC, 영문 대소문자, 공백, 문장 끝 마침표를 정규화한다.
부정 표현이나 숫자의 부호를 지우지 않는다. 한국어 조사를 임의로 제거하지 않는다.
한 응답 값은 한 사실에만 대응한다. 답의 순서는 무관하며 정규화 후 중복 값은 한 번만 센다.
허용 표현이 겹칠 때도 최대 일대일 매칭으로 판정한다.

`F1 = 2 × 맞은 항목 수 / (제출 항목 수 + 정답 항목 수)`

- 사실 F1은 정답의 사실 묶음과 제출 답을 비교한다.
- 출처 F1은 필요한 문서 ID 집합과 제출한 문서 ID 집합을 비교한다.
- 사실 점수가 0이면 출처에 주는 점수도 0이다. 출력의 source_f1은 대조한 원래 값이고 source_points가 실제 부여 점수다.
- 사실 문항의 점수는 `80 × 사실 F1 + 20 × 출처 F1`이다.
- 정답이 2개인데 1개만 맞히고 필요한 출처는 모두 맞혔다면 `80 × 2/3 + 20 = 73.33점`이다.
- 틀린 후보나 관계없는 출처를 더 붙이면 정밀도가 낮아져 점수가 내려간다.

답변 불가 문항은 `abstain=true`, 빈 답 목록, 빈 출처 목록을 모두 만족하면 100점이고 나머지는 0점이다.
답할 수 있는 문항에서 거절하면 0점이다.
항상 거절하는 프로그램의 공개 점수는 20점이며, 유형별 점수에도 그 차이가 드러난다.

전체 성능 지표는 모든 문항 점수의 산술평균이다.
평균을 낸 뒤 소수 둘째 자리로 표시하며, 문항별 반올림 값을 다시 평균 내지 않는다.
형식 오류·실행 오류·시간 초과는 해당 문항 0점으로 남는다.
실행 환경 자체의 장애는 점수 확정 전 교수자가 따로 확인한다.

## 실행과 시간

`examples/`에서 `uv run ex02` 또는 `uv run evaluate`를 실행한다.
처음과 워커 재시작 때마다 준비 요청을 보내며, 요청마다 최대 120초를 허용한다.
준비 시간은 점수와 문항별 응답 시간 통계에서 제외한다.
준비 응답의 형식만 틀렸다면 오류를 표시하고 본 문항을 진행한다.
준비 요청이 시간 초과나 실행 오류로 끝나면 해당 문항은 오류 0점으로 기록하고,
다음 문항에서 새 워커로 준비를 다시 시도한다.
본 평가의 제한은 문항당 30초다. 실패나 시간 초과 뒤에도 다음 문항을 처리한다.
도구는 문항별 답·정답·하위 점수·오류·응답 시간을 출력한다.
응답 시간은 관찰 지표이며 빠른 PC를 사용했다는 이유로 가산하지 않는다.

채점 도구는 학생 프로그램을 별도 프로세스로 실행하고 질문만 전달한다.
이 구조 자체가 파일 접근을 막는 보안 샌드박스는 아니다.
최종 평가에서는 교수자가 정답 파일을 학생 실행 환경과 분리한다.
학생용 도구의 공개 정답 파일은 연습용이며 숨겨진 시험 파일을 넣는 장소가 아니다.

## 허용 표현과 평가 오류 정정

정확한 짧은 답인데 허용 표현에서 빠진 경우, 원자료와 문항 요구를 대조해 이의를 검토한다.
승인한 별칭 추가나 오류 문항 제거는 평가 버전과 함께 기록하고 모든 제출물에 동일하게 적용한다.
학생 프로그램이나 점수를 보고 개인에게만 유리한 정답을 추가하지 않는다.
문항의 요구와 자료가 충돌하면 평가 자료를 고친 뒤 전체를 다시 채점한다.

공개 점수는 개발 피드백이다. 최종 성능 점수는 제출 버전의 비공개 평가 결과로 정한다.
