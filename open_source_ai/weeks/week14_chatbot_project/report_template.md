## 1. 만들고자 한 기능

어떤 질문에 답하는 챗봇인지, 답할 수 있는 범위와 없는 범위를 적는다.
실행 화면과 평가 함수가 같은 구현을 쓰는 위치를 가리킨다.

## 2. 구현 내용과 선택 이유

입력 → 자료 검색 또는 학습 모델 → 답변·출처 반환 과정을 설명한다.
주요 파일과 함수가 하는 일을 본인 말로 적는다.
RAG, 파인튜닝, 프롬프트, 기타 알고리즘 중 실제로 사용한 것만 설명한다.
사용하지 않은 기법을 억지로 추가할 필요는 없다.

## 4. 실패와 해결 과정

질문, 실제 답변, 기대한 사실·출처, 원인 추정, 수정, 다시 확인한 결과를 연결한다.
실행 오류가 있었다면 오류 메시지와 해결 시도를 적는다.
공개 문제를 모두 맞혔다면 직접 만든 새 질문이나 표현 변경으로 한계를 점검한다.
