# 1차 종합과제 루브릭 — 100점 상대 배점

## 적용 원칙

- 아래 배점은 100점 기준의 상대 배점이다. 학교 적용 시 실제 성적 비율·마감은 학교 운영 문서가 정한다.
- 채점은 제출된 commit id를 새 폴더에 `git clone`해서 README의 재현 절차대로 실행하며 진행한다. 실행되지 않으면 문서 점수가 실행 점수를 대체하지 않는다.
- 팀 제출은 팀 점수를 기본으로 하되, 개인 기여 증거가 최소 기준에 미치지 못한 사람은 항목 2(협업 근거)를 개인별로 판정한다.

부분 충족은 항목 배점의 40~70%, 미충족은 0~30% 범위에서 근거를 적어 판정한다.

## 감점 적용 원칙

- 실제 토큰·비밀번호·개인정보가 저장소 또는 이력에 있으면 항목 6은 0점이며, 제거와 토큰 회전 사실을 README에 적은 경우에만 다른 항목을 정상 채점한다.
- `evidence/`의 JSON과 보고서의 숫자가 맞지 않으면 항목 5를 부분 충족 이하로 본다. 실행 없이 적은 값으로 판단되면 미충족이다.
- 모델 가중치 파일을 커밋한 경우 항목 1에서 재현성 감점(용량·라이선스·clone 실패)을 적용한다.
- 캡처만 있고 명령·commit이 없는 산출물은 해당 항목의 증거로 인정하지 않는다.
- 제출한 commit id와 저장소 HEAD가 다르면 제출한 commit id 기준으로만 채점한다.
- 지각·마감은 학교 운영 문서가 정한다. 이 문서는 감점 비율을 정하지 않는다.
