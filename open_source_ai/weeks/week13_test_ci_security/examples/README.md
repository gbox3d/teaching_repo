# 13주차 예제 — 교시별 실습 진입점

실습은 `lab.md`의 교시·문제·시간 순서를 따른다. 각 폴더에는 **그 교시까지 쓰는 코드와 자료의 실제 사본**이 있다. 다음 교시 기능을 미리 요구하거나 다른 교시 폴더를 import하지 않는다. 학생이 추가할 기능·테스트와 팀별 기록은 실습 과제로 남겨 두었다.

| 교시 | 들어갈 폴더 | 실습 | 자료의 범위 |
|---|---|---|---|
| 1교시 | [period1](period1/README.md) | [모델 없는 테스트](../lab.md#1교시-실습--가짜-클라이언트로-서비스-테스트-만들기) | 19개 테스트 시작 코드·ruff |

## 이어서 실습할 때

폴더의 참조 코드를 그대로 복사하는 것과 자신이 실습에서 수정한 결과를 이어가는 것은 다르다. 기존 코드·테스트·기록·Git 이력을 보존하고, **실습지 준비 절의 전환 명령**으로 해당 교시의 새 자료를 가져온다. 특히 이미 채운 양식이나 앞 교시 과제를 원본으로 덮어쓰지 않는다.
