# 13주차 3교시 — 감사·비밀 검색·교차 리뷰

[해당 실습 단계·문제·완료 조건](../../lab.md#3교시-실습--의존성-감사와-비밀-검색-교차-리뷰) · [교시별 색인](../README.md)

이전 교시 서비스·테스트·CI에 **감사·비밀 점검 도구와 리뷰 양식**을 더한 누적 자료다. 실습용 가짜 토큰은 실행 중 개인 복사본에만 만들고 커밋하지 않는다.

## 시간별 파일 대응

| 실습 시간 | 단계 | 이 폴더의 파일·경로 | 확인할 증거 |
|---|---|---|---|
| 0–4분 | 예상 | `pyproject.toml`, `security_check.ps1` | 패키지·취약점·검출 수 예상 |
| 4–11분 | 의존성 감사 | `audit_report.py` | outputs/audit-*.md |
| 11–18분 | 비밀·모델 검색 | `security_check.ps1` | 깨끗함→문제3종→제거 증거 |
| 18–27분 | 교차 리뷰 | `REVIEW_CHECKLIST.md` | 근거 코멘트2개·판정·응답 |
| 27–30분 | 증거 정리 | `evidence/week13/`, `reviews/week13.md` | 보고서·리뷰 URL |

파일명이 짧게 적힌 경우 바로 앞 열의 같은 하위 폴더를 기준으로 읽는다. 시간과 완료 조건은 연결된 실습지를 따른다.

## 실행 위치와 명령

실습을 이어갈 때는 [실습지 준비 절](../../lab.md)에 따라 기존 `ci_lab` Git 저장소에 감사·보안 도구와 리뷰 양식만 추가한다. 아래 명령도 그 저장소에서 실행한다. 독립 실행을 확인할 때만 이 폴더 전체를 별도 새 폴더로 복사한다. Python 명령은 `pyproject.toml` 옆에서 실행한다. `uv.lock`·`.venv/`는 배포하지 않았으므로 최초 `uv sync`로 개인 환경을 만든다.

```powershell
uv sync
uv run python audit_report.py --sample
# 개인 Git 저장소에서 PowerShell로 실행
.\security_check.ps1
```

## 기본 실행과 실습 후 검증

--sample은 실제 감사 결과가 아닌 가상 보고서 형식 연습이다. 네트워크가 있으면 옵션 없이 실제 감사를 한다. 보안 스크립트는 추적·스테이징한 파일을 검사하며 깨끗한 저장소는 문제 0건이다. 새 폴더의 원본 테스트는 19개이며 개인 실습본은 22개를 유지한다.
