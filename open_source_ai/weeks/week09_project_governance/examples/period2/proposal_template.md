## 1. 문제

> [사용자]가 [상황]에서 [문제]를 겪는다. 지금은 [기존 해법]으로 해결하지만 [한계]가 있다.

기준: 사용자·상황·문제·기존 해법·한계가 모두 들어 있는가. "챗봇을 만든다"처럼 해법이 먼저 나오지 않는가.

## 7. 아키텍처

```text
사용자 ──▶ UI (Gradio 또는 정적 HTML)
              │  HTTP
              ▼
        FastAPI 앱 서버 ── /health · /chat ── 요청 검증 · 출처 붙이기
              │  /api/chat (stream, think:false, options)
              ▼
        Ollama 모델 서버 ── (1순위 모델 + LoRA 어댑터 또는 프롬프트)
              ▲
   RAG 문서(docs/) · 평가셋(data/eval.jsonl) · 실험 기록(experiments/)
```

(팀 구조에 맞게 상자·화살표를 고친다. 쓰지 않는 상자는 지운다. 화살표에는 데이터 이름을 쓴다.)

기준: 상자마다 실제 계획이 있는가. 12주차 베타 범위와 일치하는가.
