# 행동 강령

이 프로젝트는 [Contributor Covenant](https://www.contributor-covenant.org/) 행동 강령을 채택한다. 전문(현재 공개 버전)은 위 사이트에서 읽을 수 있으며, 전문과 이 요약이 다르면 전문이 우선한다.

## 채택 선언

우리는 나이, 신체 조건, 국적, 성별, 경험 수준, 학력, 종교 등과 관계없이 모든 참여자가 괴롭힘 없이 참여할 수 있는 프로젝트를 만든다. 이 강령은 저장소(Issue·PR·리뷰·토론)와 프로젝트를 대표하는 모든 자리에서 적용된다.

## 기대하는 행동

- 다른 사람의 시간과 관점을 존중한다.
- 코드와 결정에 대해 말하고, 사람에 대해 말하지 않는다.
- 실수를 인정하고 배운 것을 나눈다.
- 피드백은 이유와 대안을 함께 준다.

## 허용하지 않는 행동

- 모욕, 비하, 차별적 표현, 괴롭힘
- 동의 없는 개인정보(실명·연락처·학번 등) 공개
- 협업 자리에서 부적절한 성적·폭력적 표현
- 리뷰나 결정을 방해하려는 반복적인 방해 행위

## 신고와 처리

- 신고 경로: (팀 내 담당 표시 이름 또는 강의자에게 알리는 방법을 적는다. 이메일·연락처를 저장소에 쓰지 않는다.)
- 신고를 받은 사람은 48시간 안에 접수 사실을 알리고, 관련 당사자와 별도로 이야기한다.
- 처리 단계: 주의 → 경고 → 일시적 참여 제한 → 영구 제외. 단계와 이유는 신고자와 당사자에게 알린다.
- 팀 안에서 해결되지 않으면 강의자가 조정한다.

## 출처

이 문서는 Contributor Covenant를 채택하고 요약한 것이다. 전문을 그대로 두고 싶으면 위 사이트에서 최신 버전을 내려받아 이 파일을 교체하고 "채택 선언"과 "신고와 처리" 절만 유지한다.
