# 라이선스 선택 안내

팀 저장소의 **코드** 라이선스를 고른다. 이 파일은 선택이 끝나면 지우고, 결과는 `LICENSE` 파일과 `README.md`의 라이선스 절에 남긴다.

## 두 가지 기본 선택지

| 항목 | MIT | Apache-2.0 |
|---|---|---|
| SPDX ID | `MIT` | `Apache-2.0` |
| 성격 | 짧은 permissive | permissive + 특허 조항 |
| 재배포 조건 | 저작권·라이선스 고지 유지 | 고지 유지 + 변경 사항 표시 + NOTICE |
| 특허 | 언급 없음 | 기여자의 특허 사용 허가 명시, 특허 소송 시 종료 |
| 어울리는 경우 | 작은 도구, 빠른 채택 | 여러 기여자·기업 참여, 특허 우려 |

이 수업의 기본 모델(Qwen 계열)과 주요 라이브러리(transformers·peft 등)가 Apache-2.0이므로, 팀 코드도 Apache-2.0으로 두면 고지 방식이 같아 관리가 단순하다. 더 짧은 문서를 원하면 MIT를 고른다. 둘 다 GPL 계열 코드를 **가져와 섞을 때**는 GPL 조건이 우선한다는 점을 기억한다.

## 선택 절차

1. 2주차 `license_matrix.md`를 열어 이 프로젝트가 의존할 패키지·모델·데이터의 라이선스를 확인한다.
2. copyleft(GPL·AGPL) 의존성이 있으면 그 코드를 배포물에 포함할지 먼저 결정한다.
3. MIT 또는 Apache-2.0을 고르고 이유를 한 문장으로 적는다.
4. `LICENSE` 파일을 만든다. 전문은 [Choose a License](https://choosealicense.com/)에서 복사하고 저작권 표기 줄의 연도와 이름을 팀 표시 이름(예: `team-a contributors`)으로 바꾼다.
5. `README.md`의 라이선스 절과 `pyproject.toml`에 같은 라이선스를 적는다.

```toml
# pyproject.toml 에 추가
[project]
license = "Apache-2.0"
```

## 코드 라이선스가 정하지 않는 것

- **모델 가중치**: 모델 카드의 라이선스·약관(Apache-2.0, 커뮤니티 라이선스, RAIL 계열 등)을 따른다. 오픈 웨이트가 곧 오픈소스는 아니다.
- **학습·평가 데이터**: CC 계열 등 데이터 라이선스와 개인정보 규정을 따른다.
- **LoRA 어댑터**: 기반 모델의 라이선스가 어댑터 배포 조건에 영향을 준다. 공개 전에 기반 모델 약관을 다시 읽는다.

세 가지 모두 `SOURCES.md`에 이름·버전·라이선스·용도를 적는다.

## 확인

- [ ] `LICENSE` 파일이 저장소 루트에 있고 GitHub 저장소 페이지에 라이선스 이름이 표시된다.
- [ ] `README.md`·`pyproject.toml`·`LICENSE`가 같은 라이선스를 가리킨다.
- [ ] `SOURCES.md`에 모델·데이터 라이선스가 코드와 구분되어 적혀 있다.
