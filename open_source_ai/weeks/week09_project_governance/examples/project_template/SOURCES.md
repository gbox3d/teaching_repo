# 출처와 라이선스

이 프로젝트가 사용하는 외부 자원(모델·데이터·코드)을 모두 적는다. 새 자원을 들여오는 PR은 이 표를 함께 갱신한다. 5주차 `SOURCES.md`, 2주차 `license_matrix.md`의 항목을 옮겨 시작한다.

## 모델

| 이름·ID | 버전/revision·태그 | 라이선스(SPDX 또는 약관 이름) | 상업적 이용 | 재배포·파생 조건 | 용도 | 출처 URL |
|---|---|---|---|---|---|---|
| (예: Ollama 태그 또는 HF ID) | (태그 또는 commit hash) | | | | 생성 / 임베딩 / LoRA 기반 | |

## 확인
