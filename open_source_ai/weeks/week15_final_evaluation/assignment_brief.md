# 기말과제 — 원광대 소개 챗봇

원광대 소개 자료를 바탕으로 질문에 답하고 근거를 제시하며, 자료로 답할 수 없는 질문을 구분하는 챗봇을 개발한다. 14주차에 규칙·공개 평가셋·공개 도구를 안내하고, 15주차에 비공개 최종평가와 개발 레포트 평가를 진행한다.

## 과제 정본

과제 범위·허용 자료와 도구·제출물·제출 방법은 [14주차 과제 안내](../week14_chatbot_project/assignment_brief.md)를 따른다. 이 문서는 15주차에서 정본과 평가 문서를 연결하는 안내다.

| 내용 | 확인할 문서 |
|---|---|
| 과제 요구사항과 최종 제출 | [과제 안내](../week14_chatbot_project/assignment_brief.md) |
| 평가 함수·평가셋 구성·산식·허용 별칭·환경 | [평가 명세](../week14_chatbot_project/evaluation_spec.md) |
| 개발 내용과 실험 결과 작성 | [개발 레포트 양식](../week14_chatbot_project/report_template.md) |
| 프로젝트 준비와 공개 평가 실행 | [공개 평가 도구 안내](../week14_chatbot_project/examples/README.md) |

## 두 평가 축과 기존 배점

| 기존 항목 | 대체·유지하는 평가 내용 | 기준 |
|---|---|---|
| 발표 | AI 성능 평가로 대체 | [AI 성능 루브릭](presentation_rubric.md), 0~100 지표 |
| 레포트 | 개발 내용을 정리한 레포트를 별도로 평가 | [개발 레포트 루브릭](assignment_rubric.md), 0~100 지표 |

학교의 기존 발표·레포트 비율은 그대로 유지한다. 두 지표는 학교가 정한 각 항목의 배점에 따라 각각 환산한다. 성능 측정과 레포트의 학습 과정 평가는 구분하고, 최종 성적은 공통 채점 원칙에 따라 제출 근거를 검토한 뒤 확정한다.

## 준비에서 최종평가까지

1. 14주차에 공개한 자료와 평가 규칙을 읽고 공개 도구로 기준 구현을 확인한다.
2. 구현을 개선하며 같은 조건의 전후 결과, 선택 이유, 실패·수정·검증 과정을 레포트에 기록한다.
3. 과제 정본이 정한 방법과 마감에 프로그램과 개발 레포트를 제출한다.
4. 15주차에 평가자가 확정 제출본을 같은 환경·같은 규격의 비공개 문항으로 평가한다. 공개 점수는 개선용이며 최종 성능 점수와 혼합하지 않는다.
5. 평가자는 개발 레포트를 별도로 읽고 성능 결과와 함께 학교 배점에 맞춰 검토한다.

이전 오픈소스 릴리스 패키지의 필수 목록은 이번 과제에 적용하지 않는다. 릴리스 태그, 정해진 발표 시간, 말솜씨, 발표 영상, CI 통과, commit·Issue·PR 개수는 필수 조건이나 채점 항목이 아니다. 프로그램과 개발 레포트의 구체적인 제출 항목은 위 과제 정본에만 둔다.
