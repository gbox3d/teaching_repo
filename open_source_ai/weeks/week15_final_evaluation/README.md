# 15주차 — 원광대 소개 챗봇 최종평가

기말과제는 원광대 소개 챗봇이다. 14주차에 과제 규칙·공개 평가셋·공개 평가 도구를 안내하고, 15주차에 제출 프로그램을 비공개 평가셋으로 평가한다. 개발 내용을 정리한 레포트는 별도로 평가한다.

## 평가의 두 축

| 기존 성적 항목 | 이번 과제에서 평가하는 내용 | 지표 범위 |
|---|---|---:|
| 발표 | 챗봇의 사실 답변·근거 문서·답변 불가 처리 성능 | 0~100 |
| 레포트 | 목적·설계, 구현 이해, 개선 실험, 한계·재현·출처 | 0~100 |

기존 발표 점수만 AI 성능 평가로 대체한다. 발표와 레포트의 기존 비율은 유지하며, 학교가 정한 각 항목의 배점으로 성적을 환산한다. 자동 평가 결과는 성능 측정값이며, 최종 성적은 제출물 검토와 학교의 공통 채점 원칙을 함께 적용해 확정한다.

## 과제 규칙과 실행 안내의 정본

| 확인할 내용 | 정본 |
|---|---|
| 과제 범위·자료·제출물·제출 방법 | [14주차 과제 안내](../week14_chatbot_project/assignment_brief.md) |
| 입출력 규격·공개 및 비공개 평가·산식·정규화·허용 별칭·평가 환경 | [평가 명세](../week14_chatbot_project/evaluation_spec.md) |
| 개발 과정과 실험 결과 작성 양식 | [개발 레포트 양식](../week14_chatbot_project/report_template.md) |
| 프로젝트 준비·공개 평가셋·평가 도구 실행 | [공개 평가 도구 안내](../week14_chatbot_project/examples/README.md) |

이 주차에서는 위 정본을 이어 사용한다. 공개 평가 점수는 개선에 사용하고, 최종 성능은 같은 규격의 비공개 평가로 확인한다. 비공개 문항과 정답은 학생용 공개 저장소에 두지 않는다.

## 학습 목표

1. 제출할 챗봇이 공개된 입출력 규격을 지키는지 확인한다.
2. 사실 답변, 근거 문서, 답변 불가 처리의 오류를 구분하고 개선 전후 결과를 설명한다.
3. 개발 레포트에서 구현 선택과 실제 수정·검증 과정을 연결한다.
4. 공개 연습 결과와 비공개 최종 성능을 구분해 해석한다.

## 수업 흐름

| 교시 | 설명·시연 20분 | 실습 30분 | 확인할 기록 |
|---|---|---|---|
| 1교시 | 제출 규칙과 공개 평가 결과 읽기 | 기존 프로젝트에서 공개 평가를 실행하고 제출본·환경 확인 | 공개 결과, 오류 관찰, 제출본 식별 정보 |
| 2교시 | 비공개 최종평가 절차와 성능 지표 | 평가자는 제출본을 같은 환경에서 평가하고, 학생은 공개 결과와 자신의 구현 설명을 대조 | 평가자의 비공개 결과, 학생의 개발 근거 |
| 3교시 | 레포트 평가 기준과 결과 해석 | 레포트의 실험·한계·재현 절차·출처와 제출 정보를 점검 | 개발 레포트, 제출 확인 |

각 교시는 설명·시연 20분, 실습 30분, 휴식 10분으로 운영한다. 제출 마감과 평가 실행 일정은 학교 운영 공지를 따른다. 최종평가는 확정된 제출본으로 진행하며, 비공개 결과를 보고 제출본을 바꾸는 연습으로 운영하지 않는다.

## 준비와 완료 기준

14주차에 준비한 프로젝트와 공개 평가 도구를 이어 쓴다. 모델·의존성·자료 준비와 실행 명령은 [공개 평가 도구 안내](../week14_chatbot_project/examples/README.md)를 따른다.

- [ ] 제출 프로그램이 평가 명세의 입력과 출력 형식을 지키는지 확인했다.
- [ ] 공개 결과에서 사실·근거·답변 불가·형식 오류를 구분했다.
- [ ] 같은 조건의 개선 전후 결과와 선택 이유를 레포트에 적었다.
- [ ] 제출본과 레포트가 같은 구현을 설명하며 실행 절차와 출처를 찾을 수 있다.
- [ ] 과제 정본에 따라 프로그램과 개발 레포트를 제출했다.

릴리스 태그, 발표 시간, 말솜씨, 발표 영상, CI 통과, 동료 저장소 검증은 이번 기말과제의 필수 조건이나 별도 채점 항목이 아니다. 기존 폴더 이름은 링크 호환을 위해 유지하며 현재 과제 규칙은 위 정본을 따른다.
