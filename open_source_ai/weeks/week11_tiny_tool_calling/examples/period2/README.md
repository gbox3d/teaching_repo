# 11주차 2교시 · Ollama·Needle 고정 평가

[실습지](../../lab.md)의 2교시를 따른다. 설명·시연 20분 뒤 실습 30분, 휴식 10분이다. 실행 위치는 이 폴더의 상위 `examples/`다. 교시마다 프로젝트나 자료를 복사하지 않는다.

읽을 코드: [ex02_compare](../src/ex02_compare/__init__.py) · [shared](../src/shared/__init__.py)

```powershell
uv run ex02
```

같은 16문항을 Ollama와 Needle에 보낸다. 초기 LED 상태·도구 정의·기대값을 유지하며 모델 준비 시간과 추론 시간을 구분한다.

시뮬레이터는 별도 터미널에서 켜 둔다. 입력의 기대 결과를 먼저 적고 실행한 뒤 TCP 연결을 유지한 상태에서 `GET /state`로 확인한다. 변경할 값은 소스의 상수에서 찾는다. 상세 시간표와 기록 항목은 실습지에 있다.
