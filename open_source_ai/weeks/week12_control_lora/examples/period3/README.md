## 실행 위치와 소스

2교시 학습 프로세스의 종료를 확인하고 같은 주차 `examples/`에서 새 명령을 시작한다. 이 `period3/`은 안내만 담는다. `[project.scripts]`의 `ex03_restore:main`과 [src/ex03_restore/__init__.py](../src/ex03_restore/__init__.py)를 읽는다.

```powershell
uv run ex03
```

복원 대상은 `models/baseline.cact`, `models/tuned.cact`다. `ex03`는 두 파일을 차례로 읽어 같은 16문항을 자동 평가하며 대화 입력을 기다리지 않는다. 기본 체크포인트·어댑터·추론 파일의 역할을 구분한다. 산출 경로와 실패 시 확인 위치는 [전체 안내](../README.md)를 따른다. 파일 존재와 새 프로세스 로드 성공을 각각 확인한다.

## 실습 순서

30분의 세부 시간은 [실습지](../../lab.md)가 정본이다.

| 순서 | 읽거나 실행할 것 | 확인할 근거 |
|---|---|---|
| 복원 | `uv run ex03`와 `.cact` 설정 | 새 프로세스에서 파일을 읽은 근거 |
| 조건 맞추기 | 기본·학습 모두 4bit·20L, 같은 도구·생성 조건 | 일반 배포 기본 2bit와 구분 |
| 비교 | 학습에 쓰지 않은 같은 문항 | 기대·학습 전·학습 후 호출 |
| 분석 | 함수 선택·인자·환경 오류 | 실제 관찰·원인 가설·다음 확인 방법 |

평가 16문항은 한국어 8·영어 8, 호출 10·무호출 6이다. 학습 48개와 문자열이 다르지만 이 검사만으로 의미 독립성까지 증명하지는 않는다. 독립 문항 사이에는 모델 이력을 초기화한다. 로컬 학습 모델의 `confidence=None`을 기본 모델의 점수 임계값과 같은 방식으로 판단하지 않는다.

매 문항 LED를 `[0, 64, 128, 255]`로 복원한다. TCP는 대화·세션 동안 한 번 유지하고, 이력 초기화를 위해 연결을 끊지 않는다. 해제하면 LED가 초기화된다. 호출은 허용 목록·인자 이름·타입·범위 검사 뒤 실행하고 `GET /state`와 대조한다. 센서 수치는 `read_environment()` 반환에서 읽는다. 제안만 본 경우에는 실제 제어 성공으로 쓰지 않는다.

함수 정확도, 호출 완전일치(호출 목록 순서·인자 값 포함), 실제 상태 성공, 오호출률, median·p95를 읽는다. 인자 이름·값의 대응과 함수 호출 목록 순서를 대조하며 JSON 딕셔너리 키 나열 순서는 평가하지 않는다. 지연 출력은 초 단위다. ms로 환산하면 단위를 함께 표시한다. 기준 실측은 [주차 안내](../../README.md)를 참고한다.
