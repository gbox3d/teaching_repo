# 3차 종합과제 작은 제어 모델의 학습과 복원

## 과제 목적과 범위

명령·정답 호출 데이터를 고쳐 작은 제어 모델을 LoRA로 학습하고, 저장한 모델을 새 프로세스에서 복원해 같은 미학습 문항으로 비교한다. 7주차 LoRA의 학습·저장 개념을 12주차 Needle 3 툴 콜링에 적용하는 과제다. 결과와 함께 본인이 선택하고 관찰한 이유를 설명한다.

15주차 원광대학교 소개 챗봇 기말과제와 구분한다. 학교별 실제 배점·마감·제출 위치·개인 또는 팀 운영은 학교 공지를 따른다. 이 안내는 새 점수 비율이나 커밋 횟수를 정하지 않는다.

## 제출할 내용

| 내용 | 확인할 결과와 설명 |
|---|---|
| 데이터 점검·수정 | 사용한 명령과 정답 호출, 수정 전후, 수정 이유. 함수·인자 값이 명령의 어느 부분에 근거하는지 설명 |
| 학습과 저장 | `uv run ex02` 실행 환경, 실제 학습 설정, 길이 초과 사전 검사, 관찰한 loss, `adapter.safetensors`와 `tuned.cact` 저장 확인 |
| 새 프로세스 복원 | 학습 프로세스를 종료하고 `uv run ex03`에서 `.cact`를 읽은 근거. 어댑터와 추론 파일의 차이 설명 |
| 동일 문항 비교 | 학습에 쓰지 않은 같은 문항, 기본 4bit·20L와 학습 4bit·20L의 호출, 동일 도구·생성 조건·초기 상태 확인 |
| 오류 분석 | 함수 선택 오류, 인자 오류, 호출 형식 오류, 실행·환경 오류를 구분하고 관찰 근거·원인 가설·다음 확인 방법 제시 |
| 재현 안내 | 저장소 전체 clone, 주차 `examples/`에서의 실행 순서, 수정한 상수와 데이터, 실제 산출 경로, 막힌 단계와 해결 시도 |

본문·코드 주석·첨부 문서·질문에서 이해를 설명할 수 있다. 길이나 화면 수를 맞추기 위한 설명은 요구하지 않는다. 표와 터미널 발췌 또는 화면을 사용하되, 무엇을 확인한 근거인지 붙인다.

수업 기본 데이터는 `examples/src/shared/data/train_examples.jsonl`의 48행이며 `query`·`answers`·`reasoning`을 읽는다. 공용 스키마를 합친 `models/training_input.jsonl`은 학습 입력이다. 초기 상수는 `EPOCHS=4`, `BATCH_SIZE=4`, `MAX_LEN=1024`, `LEARNING_RATE=1e-4`로 최초 실측 뒤 바뀔 수 있다. 모든 예제 길이를 검사하고 한도 초과 시 중단한다.

공용 함수가 `models/adapter.safetensors`, B=0인 `models/baseline_adapter.safetensors`, `models/baseline.cact`, `models/tuned.cact`를 만든다. B=0 어댑터는 기본 가중치를 바꾸지 않는다. 기본 체크포인트는 `models/checkpoints/needle3.safetensors`다. 학생은 데이터·상수를 수정하고 공용 내보내기를 사용한다.

## 함수와 실행 경계

정답 호출은 `turn_on(index)`, `turn_off(index)`, `set_brightness(index, value)`, `read_environment()` 계약을 따른다. `index`는 정수 0~3, `value`는 정수 0~255다. 근거 없는 인자 값을 채우지 않고 도구와 무관한 명령에는 빈 호출을 둔다.

모델의 호출 제안, 실행기의 허용 목록·인자 검사, 실제 실행 결과를 구분해 설명한다. 장치를 실행했다면 `GET /state`로 상태를 확인하고 센서값은 함수 반환에서 읽는다. TCP 연결은 대화·세션 동안 유지하며 연결 해제 시 LED 초기화가 비교에 미치는 영향도 적는다. 13주차 시뮬레이터 앱 완성은 이 과제의 필수 범위에 추가하지 않는다.

## 비교 기록 양식

| 미학습 문항 | 기대 호출·근거 | 학습 전 호출 | 학습 후 호출 | 차이와 원인 가설 |
|---|---|---|---|---|
| 실제 사용 문항 |  |  |  |  |

기본 비교는 16문항(한국어 8·영어 8, 호출 10·무호출 6)이며 학습 48개와 문자열이 다르다. 문자열 차이만으로 의미 독립성을 확정하지 않는다. 매 문항 LED를 `[0, 64, 128, 255]`로 복원한다. 함수 정확도·호출 완전일치(호출 목록 순서·인자 값 포함)·실제 상태 성공·오호출률·median·p95를 실제 출력에서 읽는다. 인자 이름·값과 함수 호출 목록 순서를 대조하며 JSON 딕셔너리 키 나열 순서와 혼동하지 않는다.

조건에는 두 모델의 4bit·20L 여부, 도구 정의, 생성 설정, 문항 사이 이력 초기화와 시뮬레이터를 쓴 경우의 초기 상태를 적는다. loss가 내려가도 미학습 문항이 성공했다고 단정하지 않는다. 결과가 같거나 악화된 경우에도 관찰을 그대로 남긴다. 비교 문항을 학습 데이터로 옮긴 뒤 그 문항을 다시 미학습 평가라고 부르지 않는다.

기준 PC의 학습·저장·복원과 16문항 실제 제어 실측은 [주차 안내](README.md)에 있다. 이 값은 교재 준비 과정의 단일 실측이며 자기 결과로 옮겨 쓰지 않는다. 자신의 실패·측정값·환경을 구분해 설명한다.

## 실패·질문 기록

실패한 경우 실행 명령, 실제 오류, 확인한 파일·설정, 바꾼 내용과 재시도 결과를 적는다. 다음에 확인할 위치를 좁힌 질문도 학습 근거다. 다른 사람의 실행 결과를 참고하면 출처와 자기 실행 여부를 구분한다. 아직 생성되지 않은 산출물이나 실행하지 않은 복원을 완료로 쓰지 않는다.

AI 도구를 사용했다면 받은 도움, 파일에 적용한 내용, 본인이 수정·검증한 부분을 밝힌다. 사용 사실만으로 감점하지 않으며 자기 이해의 근거를 함께 평가한다. 모델·데이터의 출처와 라이선스를 적고 개인정보·비밀은 제출물에서 제외한다. 큰 가중치 파일의 전달 방식은 학교 공지를 따른다.
