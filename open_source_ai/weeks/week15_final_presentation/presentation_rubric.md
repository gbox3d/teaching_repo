# AI 성능 루브릭 — 기존 발표 항목 대체

원광대 소개 챗봇의 AI 성능을 0~100 지표로 평가한다. 기존 발표 항목은 이 성능 평가로 대체하며, 발표 시간·말솜씨·슬라이드·질의응답 전달력은 점수에 포함하지 않는다. 개발 내용은 [레포트 루브릭](assignment_rubric.md)으로 별도 평가한다. 발표와 레포트의 기존 비율을 유지하고 실제 성적은 학교의 각 항목 배점에 따라 환산한다.

## 평가 규칙의 정본

입출력·평가셋·정규화·허용 별칭·계산 방법·환경은 [14주차 평가 명세](../week14_release_feedback/evaluation_spec.md)가 정본이다. 아래는 공개 규격의 요약이며, 도구와 문항은 [공개 평가 도구 안내](../week14_release_feedback/examples/README.md)에서 확인한다. 제출 범위는 [과제 안내](../week14_release_feedback/assignment_brief.md), 개발 기록은 [레포트 양식](../week14_release_feedback/report_template.md)을 따른다.

## 평가 함수와 문항 구성

평가 함수는 `answer(question) -> dict` 형식으로 다음 값을 반환한다.

| 키 | 타입 | 의미 |
|---|---|---|
| `answers` | `list[str]` | 질문에 답하는 짧은 사실의 목록 |
| `sources` | `list[str]` | 답의 근거가 되는 문서 ID 목록 |
| `abstain` | `bool` | 자료로 답할 수 없어 답변을 보류하는지 여부 |

14주차 공개 평가셋은 명확한 사실 16문항과 답변 불가 4문항으로 구성한 20문항이다. 15주차에는 같은 입출력·문항 구성·채점 규격의 비공개 최종평가를 실시한다. 공개 결과는 개발·개선용이며 비공개 최종 성능 점수와 섞지 않는다. 비공개 문항·정답은 공개 저장소에 두지 않는다.

## 문항 점수와 성능 지표

| 문항 또는 반환 상태 | 점수 |
|---|---|
| 사실 문항 | `80 × 답 집합 F1 + 20 × 근거 집합 F1` |
| 사실 문항에서 답 집합 F1이 0 | 근거에 주는 점수도 0으로 처리하므로 문항 점수는 0 |
| 답변 불가 문항 | `abstain=true`이고 `answers=[]`, `sources=[]`이면 100, 그 외에는 0 |
| 반환 형식 오류 | 해당 문항 0 |

각 F1은 0~1 범위다. 답과 근거는 평가 명세의 정규화·허용 별칭을 적용한 집합으로 비교한다. 필요한 사실이나 근거를 빠뜨리는 경우와 불필요한 항목을 덧붙이는 경우를 모두 반영한다. 집합 처리와 빈 값의 세부 판정은 평가 명세를 따른다.

최종 성능 지표는 비공개 평가의 전체 문항 점수 평균이다. 사실 문항만 따로 평균하거나 답변 불가 문항을 제외하지 않는다. 위 80·20은 한 사실 문항 안의 답·근거 배점이며, 발표와 레포트의 성적 비율이 아니다.

응답 시간은 보고용이다. 공개 도구는 문항당 30초 제한을 적용하며, 환경·준비 시간·초과 시 처리는 평가 명세에 따른다. 빠른 응답에 가점을 주거나 학생 PC 성능으로 점수를 나누지 않는다.

## 평가 결과 확인

평가자는 제출본·자료·모델·평가 도구·평가셋·실행 환경을 기록하고 문항별 원출력과 점수를 보존한다. 점수가 같아도 사실 오류, 근거 오류, 답변 불가 처리, 형식 오류는 구분해 설명한다.

의미가 같은 답의 별칭 누락, 잘못된 정답·근거, 평가 도구 오류는 원자료로 재검토한다. 오류를 정정하면 영향을 받는 모든 제출물에 같은 규칙을 적용하고 변경 전후 기록을 남긴다. 평가 환경 장애도 학생 구현의 오류와 구분한다.

자동 계산값은 성능 지표다. 이 값만으로 검토 없이 성적을 확정하거나 학교의 공통 채점 원칙을 생략하지 않는다. 학습 과정과 질문·수정·검증은 개발 레포트에서 별도로 평가하고, 실제 성적은 기존 발표·레포트 배점과 공통 원칙에 따라 확정한다.

## 기록 항목

| 항목 | 기록할 내용 |
|---|---|
| 평가 대상 | 제출본과 실행에 사용한 코드·자료·모델의 식별 정보 |
| 평가 조건 | 평가셋·도구 버전, 환경, 실행 시각, 적용한 제한 |
| 문항별 결과 | 반환 원문, 답·근거 F1, 답변 불가 및 형식 판정, 문항 점수 |
| 성능 지표 | 전체 문항 평균 /100 |
| 응답 시간 | 관찰한 시간과 시간 제한 초과 여부, 점수와 별도 기록 |
| 재검토 | 판정·환경 오류의 근거, 정정 범위, 변경 전후 결과 |
| 학교 성적 처리 | 기존 발표 항목 배점과 검토 근거 |

비공개 문항·정답과 학생별 결과는 학교의 비공개 보관 위치에서 관리한다.
