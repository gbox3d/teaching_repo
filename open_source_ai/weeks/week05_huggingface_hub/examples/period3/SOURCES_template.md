# SOURCES — 사용한 모델·데이터·코드의 출처

> 프로젝트: 로컬 AI 도우미 · 작성자: student01
> 이 표는 8주차 2차 종합과제 「라이선스 분석 보고」의 시작점이다. 새 자원을 쓸 때마다 행을 추가하고, 지운 자원은 행을 남긴 채 용도 칸에 "사용 중지"라고 적는다.

## 기록 규칙

- 버전 칸에는 commit hash(모델) 또는 데이터셋 revision·버전을 적는다. "최신"이라고 쓰지 않는다.
- 라이선스 칸에는 SPDX 식별자를 쓴다. 목록에 없으면 `LicenseRef-이름`으로 적고 조건 요약에 핵심 조건을 쓴다.
- 변경 내용 칸에는 내가 손댄 것(필터링·정제·번역·병합·파인튜닝)을 적는다. 그대로 썼으면 "없음".
- 출처 URL은 저장소 페이지 주소를 적는다. 다운로드 링크나 미러 주소는 쓰지 않는다.

## 메모

- 원문 데이터와 주석(라벨)의 라이선스가 다른 경우 둘 다 적고 더 제한적인 쪽을 기준으로 삼는다.
- 카드에 라이선스가 없는 자원은 사용할 수 없다. 표에 넣지 않는다.
