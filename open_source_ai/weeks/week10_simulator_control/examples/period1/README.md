# 10주차 1교시 · Python 수동 명령

[실습지](../../lab.md)의 1교시를 따른다. 설명·시연 20분 뒤 실습 30분, 휴식 10분이다. 실행 위치는 이 폴더의 상위 `examples/`다. 교시마다 프로젝트나 자료를 복사하지 않는다.

읽을 코드: [ex01_manual](../src/ex01_manual/__init__.py) · [Board 제어 API 원본](../../../../../tools/bleuno-control/src/bleuno_control/__init__.py)

```powershell
uv run ex01
```

수동 입력은 `on 0`, `off 0`, `pwm 1 128`, `sensor`이며 `/bye`로 종료한다. 네 함수로 같은 TCP 연결을 재사용하고 종료 전에 상태를 확인한다.

빈 줄은 건너뛰고 잘못된 명령·번호·밝기를 입력하면 오류 안내 뒤 다음 입력을 받는다. `/bye`, Ctrl+C 또는 입력 종료(EOF)는 TCP 연결을 닫으며 LED 상태는 유지한다. 처음 연결할 수 없거나 실행 중 연결이 끊기면 안내 후 종료한다. 시뮬레이터 실행 상태를 확인한 뒤 `uv run ex01`을 다시 실행한다.

시뮬레이터는 별도 터미널에서 켜 둔다. 입력의 기대 결과를 먼저 적고 실행한 뒤 TCP 연결을 유지한 상태에서 `GET /state`로 확인한다. LED 번호는 0~3, 밝기는 0~255로 바꿔 입력한다. 상세 시간표와 기록 항목은 실습지에 있다.
