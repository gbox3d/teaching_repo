# 9주차 실습 — 입력할 수 있는 AI 앱

## 준비

```powershell
uv init --package --python 3.12 --vcs none streamlit-skeleton
```

`src/`·`pyproject.toml`·`.python-version`을 확인하고 교재의 `examples` 전체를 별도 작업 폴더에 복사한다. 그 루트에서 `uv sync`를 수업 전에 마친다. 각 교시에는 `streamlit run` 뒤에 적힌 `app.py`를 연다. 모델은 [예제 준비](examples/README.md)를 따른다.

## 1교시 실습 — 첫 화면

| 시간 | 활동 |
|---|---|
| 0–5분 | 명령·브라우저 주소 확인 |
| 5–15분 | 입력·버튼 실행 |
| 15–25분 | 제목·출력 문장 변경 |
| 25–30분 | 재실행 관찰·기록 |

1. 프로젝트 루트에서 `uv run streamlit run src/ex01_widgets/app.py`을 실행하고 표시된 로컬 주소를 브라우저로 연다.
2. 수업용 이름을 입력하고 버튼을 누른다. 실명은 입력하지 않는다.
3. 소스의 `st.title`·`st.text_input`·`st.button`·`st.write`가 화면 어느 부분인지 찾는다.
4. 제목과 출력 문장을 하나씩 바꾸고 저장해 화면 변화를 확인한다.
5. 종료는 터미널에서 Ctrl+C다. `/bye`는 이 웹 앱의 종료 명령이 아니다.

## 2교시 실습 — 채팅 앱

| 시간 | 활동 |
|---|---|
| 0–5분 | Ollama·모델 확인 |
| 5–15분 | 앞 내용 다시 묻기·세 차례 대화로 수량 계산 |
| 15–25분 | 대화 지우기·역할 문장 수정 |
| 25–30분 | 상태와 스트리밍 기록 |

1. 앞 서버를 종료하고 `uv run streamlit run src/ex02_chat/app.py`를 실행한다.
2. 좋아하는 색을 알려 준 뒤 다시 묻는다. 답이 조각으로 출력되는지 확인한다. 대화를 지운 뒤 아래 세 문장을 한 번에 붙여 넣지 않고 차례로 보낸다.

   | 차례 | 입력 | 확인할 점 |
   |---|---|---|
   | 1 | 딸기가 3개 있습니다. | 사실을 알려 주었을 때 짧게 확인하는가 |
   | 2 | 저와 친구가 1개씩 먹었습니다. | 두 사람이 각각 먹은 양을 반영하는가 |
   | 3 | 몇 개 남았나요? | 앞선 수량을 사용한 계산식과 단위가 있는가 |

3. `session_state.messages`가 재실행 사이에 대화를 보존하는 부분과 요청의 `messages`에 앞선 발언을 넣는 부분을 찾는다. 답이 틀리면 이력 전달과 계산 실수를 나누어 확인한다. 계산이 틀렸다는 사실만으로 이력이 빠졌다고 판단하지 않는다.
4. 대화 지우기를 누르고 이전 메시지가 사라졌는지 확인한다. `몇 개 남았나요?`만 다시 보내 앞선 정보가 있을 때와 답을 비교한다.
5. `src/shared/__init__.py`의 `CHAT_PROMPT`에서 문장 하나를 바꿔 같은 질문을 다시 입력한다. LangChain과 Ollama 호출을 5주차 코드와 연결한다.

답변 본문이 비거나 공백뿐이면 앱은 경고를 표시하고 assistant 메시지를 저장하지 않는다. 이때도 사용자 질문은 이력에 남는다. 3교시 문서 검색 앱도 같은 방식으로 처리한다.

## 3교시 실습 — 문서 검색 앱

| 시간 | 활동 |
|---|---|
| 0–5분 | 가상 도서관 문서 확인 |
| 5–15분 | 질문 두 개·검색 근거 비교 |
| 15–25분 | 내 텍스트 문서로 교체 |
| 25–30분 | 자료 밖 질문·한계 기록 |

1. 앞 서버를 종료하고 `uv run streamlit run src/ex03_rag/app.py`을 실행한다.
2. 기본 문서는 수업용 가상 도서관 안내다. 대출 기간과 운영 시간 질문을 입력한다.
3. 검색한 문단을 펼쳐 답의 근거와 문단 번호가 맞는지 확인한다. 유사도 점수는 확률이 아니다.
4. 개인정보 없는 작은 UTF-8 `.txt` 문서를 업로드한다. 빈 줄로 나눈 문단을 임베딩해 검색한다.
5. 문서에 없는 질문을 입력해 답변을 점검한다. 문서를 바꾸면 이전 문서의 대화는 초기화된다.

완료 조건은 작동하는 앱, 두 차례 대화, 문서 검색 근거와 실제 답의 연결을 설명하는 것이다. 파일 업로드만으로 학습했다고 설명하지 않는다. 결과는 `week09_note.md`에 기록한다.
