# Streamlit 따라하기

프로젝트 루트에서 시작하고 자세한 시간표는 [실습지](lab.md)를 따른다.

1. `uv run ex01`의 주소를 연다. 이름을 입력하고 버튼 출력과 소스 저장 뒤 재실행을 확인한다. Ctrl+C로 종료한다.
2. `uv run ex02`에서 색을 알려 주고 다시 묻는다. 대화 지우기로 메시지가 사라지는지 확인한다. Ctrl+C로 종료한다.
3. `uv run ex03`에서 대출 기간을 묻고 검색 문단과 답의 출처를 대조한다. 자기 문서로 바꾸고 자료 밖 질문도 확인한다.

연결 오류는 Ollama 실행 상태·모델 이름·주소부터 확인한다. 모델 파일이 없으면 수업 전 준비를 완료한다. 업로드 문서는 UTF-8 txt로 준비한다. 다운로드나 새 모델 학습을 실습 시간에 끼워 넣지 않는다.
