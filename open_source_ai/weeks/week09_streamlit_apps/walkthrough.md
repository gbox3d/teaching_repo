# Streamlit 따라하기

9주차 `examples/` 폴더에서 시작하고 자세한 시간표는 [실습지](lab.md)를 따른다.

1. `uv run streamlit run src/ex01_widgets/app.py`을 실행하고 터미널에 표시된 주소를 연다. 이름을 입력하고 버튼 출력과 소스 저장 뒤 재실행을 확인한다. Ctrl+C로 종료한다.
2. `uv run streamlit run src/ex02_chat/app.py`에서 색을 알려 주고 다시 묻는다. 대화를 지운 뒤 `딸기가 3개 있습니다.` → `저와 친구가 1개씩 먹었습니다.` → `몇 개 남았나요?`를 각각 보낸다. 계산식에 앞선 수량이 반영됐는지 본다. 다시 대화를 지우고 마지막 질문만 보내 비교한 뒤 Ctrl+C로 종료한다.
3. `uv run streamlit run src/ex03_rag/app.py`에서 대출 기간을 묻고 검색 문단과 답의 출처를 대조한다. 자기 문서로 바꾸고 자료 밖 질문도 확인한다.

연결 오류는 Ollama 실행 상태·모델 이름·주소부터 확인한다. 모델 파일이 없으면 수업 전 준비를 완료한다. 업로드 문서는 UTF-8 txt로 준비한다. 다운로드나 새 모델 학습을 실습 시간에 끼워 넣지 않는다.

채팅·문서 검색 앱은 빈 답변이나 공백뿐인 답변을 받으면 경고를 표시하고 assistant 기록을 남기지 않는다. 계산이 틀렸을 때는 요청에 이전 메시지가 포함됐는지와 모델이 그 숫자를 제대로 계산했는지를 따로 확인한다. 화면에 대화가 남아 있는 것만으로 모델에 이력이 전달됐다고 판단하지 않는다.
