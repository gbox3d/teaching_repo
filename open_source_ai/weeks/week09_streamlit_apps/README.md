# 9주차 — Streamlit으로 로컬 AI 앱 만들기

4주차 Ollama → 5주차 LangChain → 6주차 RAG → 7주차 LoRA에서 확인한 기능을 사용자가 입력할 수 있는 앱 화면으로 연결한다. 8주차 평가는 기존 일정대로 운영한다.

## 교시별 결과

| 교시 | 설명·시연 20분 | 실습 30분 | 실행 |
|---|---|---|---|
| 1 | 위젯, 버튼, 재실행 | 수업용 이름을 입력하는 첫 앱 | `uv run ex01` |
| 2 | chat_input·chat_message·session_state | 기억하며 스트리밍하는 Ollama 채팅 앱 | `uv run ex02` |
| 3 | 파일 업로드, 캐시, 검색 문단 표시 | 텍스트 문서에 질문하는 RAG 앱 | `uv run ex03` |

교시마다 설명·시연 20분, 실습 30분, 휴식 10분이다. 먼저 동작하는 앱 하나를 만들고 입력·답변·검색 근거를 확인한다.

## 준비

[실습지](lab.md)대로 Python 3.12 패키지 프로젝트를 확인하고 `examples` 전체를 복사한다. 한 프로젝트 루트에서 세 명령을 실행한다. `main()`은 Streamlit 실행 시작점이고 scripts는 명령 연결, build-system은 패키지 설치 방법이다. scripts 수정 뒤에는 `uv sync`를 다시 실행한다.

Ollama와 생성 모델 `qwen3.5:2b`, 임베딩 모델 `intfloat/multilingual-e5-small`을 사용한다. 설치·다운로드는 수업 전에 마친다. 생성 모델은 `OLLAMA_MODEL`·`OLLAMA_HOST`, 임베딩 모델은 `HF_EMBED_MODEL`로 지정한다.

7주차 PEFT 어댑터를 이 앱에서 바로 Ollama 모델 이름으로 넣지는 않는다. 기본 앱이 완성된 뒤 지원되는 실행 경로를 확인해 별도 연결한다.

## 완료 기준

- [ ] 다른 텍스트 문서로 바꿔 앱을 다시 사용했다.

## 남는 시간의 선택 확장

모든 주제를 필수로 더하지 않고 앱 하나가 완성된 뒤 한 가지를 고른다.

| 주제 | 보여 줄 입출력 | 연결할 개념 |
|---|---|---|
| 얼굴·이미지 임베딩 | 두 이미지 → 벡터 → 유사도 비교 | RAG의 문서 벡터 비교와 같은 유사도 개념 |
| 음성 인식 | 짧은 녹음 → 텍스트 | 앱의 질문 입력을 음성으로 바꾸기 |
| 음성 출력 | 답변 텍스트 → 음성 | 앱의 답을 듣게 하기 |
| 약 1B급 소형 모델 | 같은 질문 → 속도·답 비교 | 실행 자원과 답 품질 비교 |
| 디퓨전 방식 모델 | 같은 작업의 생성 방식 비교 | 자기회귀와 다른 생성 방식 소개 |

얼굴의 위치 검출과 얼굴 임베딩의 유사도 비교를 구분한다. 코사인 유사도는 정답 확률이 아니며 문서·얼굴 모델의 벡터를 서로 직접 비교하지 않는다. 공개 샘플이나 사용을 허락받은 자료로 비교한다. 선택 주제의 모델·지원 언어·사용 조건은 시연 전에 카드와 실행기로 확인한다.
