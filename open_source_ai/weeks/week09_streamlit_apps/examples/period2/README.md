# Streamlit으로 로컬 AI 앱 만들기 · 2교시

[실습지](../../lab.md)의 2교시를 따른다. 실행은 `pyproject.toml`이 있는 프로젝트 루트에서 한다.

```powershell
uv run streamlit run src/ex02_chat/app.py
```

기억하며 대화하는 앱을 실습하고 입력·결과·값을 바꾼 비교를 기록한다. 실습 30분 뒤 휴식 10분이다.

`딸기가 3개 있습니다.` → `저와 친구가 1개씩 먹었습니다.` → `몇 개 남았나요?`를 각각 보낸다. 마지막 답의 계산식과 단위를 확인하고, 대화를 지운 뒤 마지막 질문만 다시 보낸다. 요청에 이전 메시지를 넣는 코드와 계산 결과를 따로 확인한다. 본문이 비면 앱은 경고를 표시하며 그 답을 대화 기록에 넣지 않는다.
