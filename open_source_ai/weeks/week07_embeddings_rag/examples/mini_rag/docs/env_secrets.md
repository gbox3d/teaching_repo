# 환경변수와 비밀정보 관리

서버 주소, 모델 이름, 토큰처럼 PC마다 달라지는 값은 코드에 직접 쓰지 않고 환경변수로 읽는다. Python에서는 `python-dotenv`의 `load_dotenv()`로 `.env` 파일을 읽은 뒤 `os.environ.get("OLLAMA_HOST", "http://localhost:11434")`처럼 기본값과 함께 가져온다.

`.env`에는 실제 값이 들어가므로 `.gitignore`에 넣어 커밋하지 않는다. 대신 어떤 변수가 필요한지 보여 주는 `.env.example`을 빈 값으로 만들어 커밋한다.

설정의 우선순위는 코드의 기본값이 가장 낮고, 환경변수가 그 위, 명령행 인자가 가장 높다. 이렇게 하면 같은 코드를 GPU가 있는 PC와 없는 PC에서 인자만 바꿔 실행할 수 있다.

비밀 값을 한 번이라도 커밋했다면 삭제 커밋을 해도 이력에 남는다. 이 경우 토큰을 새로 발급(회전)하고 옛 토큰을 무효화하는 것이 유일한 안전한 조치다.
