# 2교시 — 공개 AI 프로젝트 탐색표

[실습지 2교시](../../lab.md#2교시-실습--공개-ai-프로젝트-탐색표)의 **학생용 양식**이다.
1교시 개인 폴더에 [oss_survey_template.md](oss_survey_template.md)를 복사한다.
Python 실행이나 모델 다운로드는 없다.

```powershell
Set-Location C:\classwork\osa-week01
Copy-Item oss_survey_template.md oss_survey.md
```
실습 문제 1의 세 저장소를 조사하고 문제 2의 OSAID 판정을 작성한다.
완료하면 `oss_survey.md`에 라이선스·활동 근거 URL과 판정 문장이 있다.
네트워크가 없으면 강의자가 준비한 저장소 화면·원문을 사용하고 미확인 항목을 표시한다.
완성 답안은 포함하지 않는다. 다음 [3교시](../period3/README.md)는 첫 uv 실행이다.

## 실습 시간표

| 단계 | 시간 | 활동 |
|---|---:|---|
| 문제·예상 | 0–5분 | 세 저장소의 라이선스와 활동 수준을 예상, 템플릿 복사 |
| 조사 | 5–20분 | 저장소별 5개 항목을 화면에서 읽어 표에 기록 |
| OSAID 판정 | 20–25분 | 저장소마다 "어느 항목을 만족하는가" 한 문장 |
| 검증·기록 | 25–30분 | 근거 URL 대조, 표 완성 |

시간은 설명·시연 20분 뒤 시작하는 **실습 30분 기준**이다. 휴식 10분은 별도다.
