# 5주차 따라하기

준비와 시간표는 [실습지](lab.md)를 따른다. 세 명령 모두 같은 프로젝트 루트에서 실행한다.

## 1교시

`uv run ex01`을 실행하고 리스트·튜플 질문을 차례로 입력한다. 각 답 뒤에 다시 `나>`가 보이고 빈 줄은 건너뛰어야 한다. `/bye`로 종료한다. ChatOllama의 모델·주소가 4주차 Ollama와 같은지 확인한다.

## 2교시

`uv run ex02`에서 리스트 질문을 입력한다. 종료 후 `ROLE` 한 값만 바꿔 같은 질문을 한다. 답은 매번 달라질 수 있으므로 실제 차이를 적는다. 프롬프트의 변수 이름과 invoke의 입력 키를 확인한다.

## 3교시

`uv run ex03`에서 수업용 이름·색을 알린 뒤 색을 다시 묻는다. 출력 조각을 모은 답이 이력에 추가되는지 코드로 확인한다. 종료 후 `"history": []`로 바꿔 다시 실행하고 차이를 비교한다.

## 막혔을 때

| 증상 | 확인 |
|---|---|
| 명령을 찾지 못함 | 프로젝트 루트와 `uv sync`, scripts 확인 |
| 연결 실패 | Ollama 앱과 `OLLAMA_HOST` 확인 |
| 모델을 찾지 못함 | `ollama list`와 `OLLAMA_MODEL` 대조 |
| 프롬프트 변수 오류 | 템플릿의 변수와 invoke 입력의 키 대조 |
| 이전 대화를 못 맞힘 | ex03에서 history를 보내는지 확인하고 모델 답의 한계도 기록 |
