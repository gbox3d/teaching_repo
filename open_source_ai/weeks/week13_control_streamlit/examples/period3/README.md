[실습 문제와 시간표](../../lab.md#3교시-실습-streamlit-제어-ui) · [예제 색인](../README.md)

## 실행 위치와 명령

1·2교시와 같은 `examples/`에서 실행한다. `uv run ex03`가 Streamlit을 시작한다.

```sh
uv run ex03
```

headless로 시작하므로 `http://127.0.0.1:8501`을 브라우저로 직접 연다. 포트는 [ex03_app/__init__.py](../src/ex03_app/__init__.py)의 `PORT = 8501`, 화면은 [app.py](../src/ex03_app/app.py)에서 확인한다. UI는 12주차 `examples/models/tuned.cact`와 공용 기본 도구 설명을 사용한다. `ex02`의 `DESCRIPTIONS` 변경은 자동 전달되지 않는다. 같은 경로로 재학습했다면 서버를 재시작해 이전 모델 캐시를 비운다.

## 캐시와 세션

모델 준비는 `st.cache_resource`로 반복 적재를 줄인다. TCP 연결은 세션 단위로 유지한다. 다른 사용자와 소켓을 전역 공유하지 않는다. 공용 predictor의 `Lock`은 `reset()`과 `complete()`를 한 묶음으로 처리한다. 요청은 독립적이며 한 PC에서 제어 창 하나만 사용한다.

화면을 다시 그릴 때 현재 LED 상태를 조회한다. 입력 확정 이벤트에서만 새 호출을 처리하며, 재실행 때 같은 요청을 다시 실행하거나 TCP 연결을 새로 만들지 않는다. 사용자가 새 요청으로 제출한 동일 문장은 새 입력이므로 화면 재실행과 구분한다.

## 확인할 화면과 동작

- 연결 상태와 명시적 연결 해제 수단
- 사용자 요청, 모델 호출 제안, 실행 전 검증 결과
- 함수의 실제 반환과 `GET /state`로 조회한 LED 상태
- 센서 요청 시 `read_environment()`가 반환한 온도·습도

“시뮬레이터 연결”을 누른 뒤 “제어 요청”에 밝기를 명시한 요청을 적고 “요청 실행”을 누른다. 표시된 응답과 LED 상태를 확인한다. 입력 제출 없이 화면 재실행을 일으켜 호출·연결이 늘지 않는지 확인한다. 연결 해제 후 LED 초기화도 조회한다. 화면이 보였다는 사실만으로 중복 호출·세션 격리를 검증했다고 쓰지 않는다.

## 종료

UI의 “연결 해제”를 먼저 실행하고 상태를 확인한 뒤 Streamlit 서버를 실행한 터미널에서 `Ctrl+C`로 종료한다. 브라우저 탭 닫기만으로 TCP 해제를 보장하지 않는다. 직접 확인한 화면·재실행·연결 동작과 확인하지 못한 항목을 구분해 기록한다.

## 재학습 후 앱 재시작

12주차에서 같은 `tuned.cact` 경로를 재학습해 덮어썼다면, 화면에서 연결을 해제하고 앱 서버 터미널에서 `Ctrl+C`를 누른 뒤 `uv run ex03`로 다시 시작한다. 브라우저 새로고침만으로 캐시된 가중치는 갱신되지 않는다.
