# 7주차 3교시 — 저장한 결과로 다시 대화

[실습지 3교시](../../lab.md#3교시-실습--저장한-결과로-다시-대화)의 소스 안내다. 이 폴더에서는 실행하지 않는다. [examples 프로젝트](../README.md)의 개인 복사본 루트에서 이전 교시와 같은 환경을 이어 쓴다.

| 명령 | 읽을 소스 | 하는 일 |
|---|---|---|
| `uv run ex04` | [ex04_compare](../src/ex04_compare/__init__.py) | 새로 불러온 어댑터의 끄기·켜기 비교 |
| `uv run ex05` | [ex05_merge](../src/ex05_merge/__init__.py) | 어댑터를 합친 전체 모델·토크나이저 저장, 시연 또는 선택 실습 |
| `uv run ex06` | [ex06_merged_chat](../src/ex06_merged_chat/__init__.py) | 저장한 병합 폴더를 Python에서 읽어 대화, 시연 또는 선택 실습 |

`ex04`에서 같은 질문의 학습 전후 답을 기록한다. 형식(새 항목 이름)과 사실을 따로 확인하고, 다시 실행해 저장된 어댑터로 대화한다. 사실에 맞게 답하게 하려면 6주차의 어떤 방법을 쓸지 적는다.

선택 실습은 `uv run ex05` → `uv run ex06` 순서다. 기존 프로젝트에 새 명령을 반영한 뒤에는 먼저 `uv sync`를 다시 실행한다. 어댑터만 담은 `adapters/run-001/`과 달리 `models/merged-run-001/`에는 모델·토크나이저 전체가 있으므로 `ex06`은 이 폴더를 직접 읽는다. Ollama 가져오기는 [별도 선택 경로](../README.md#ollama로-다시-대화하기)다. 어느 경로도 필수 완료 조건에 추가하지 않는다.

대화 예제는 질문을 반복 입력하고 `/bye`로 끝낸다. 빈 줄은 건너뛰며, 앞 질문을 기억하지 않는다. 수정할 값은 소스 위쪽의 상수다. 교시마다 프로젝트나 데이터를 복사하지 않는다. 시간 배분과 완료 조건은 실습지를 따른다.
