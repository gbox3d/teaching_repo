# 7주차 3교시 — 저장한 결과로 다시 대화

[실습지 3교시](../../lab.md#3교시-실습--저장한-결과로-다시-대화)의 소스 안내다. 이 폴더에서는 실행하지 않는다. [examples 프로젝트](../README.md)의 개인 복사본 루트에서 이전 교시와 같은 환경을 이어 쓴다.

| 명령 | 읽을 소스 | 하는 일 |
|---|---|---|
| `uv run ex04` | [ex04_compare](../src/ex04_compare/__init__.py) | 새로 불러온 어댑터의 끄기·켜기 비교 |
| `uv run ex05` | [ex05_merge](../src/ex05_merge/__init__.py) | 병합·Ollama 연결 시연 또는 선택 실습 |

`ex04`에서 같은 질문의 학습 전후 답을 기록한다. 형식(새 항목 이름)과 사실을 따로 확인하고, 다시 실행해 저장된 어댑터로 대화한다. 사실에 맞게 답하게 하려면 6주차의 어떤 방법을 쓸지 적는다.

대화 예제는 질문을 반복 입력하고 `/bye`로 끝낸다. 빈 줄은 건너뛰며, 앞 질문을 기억하지 않는다. 수정할 값은 소스 위쪽의 상수다. 교시마다 프로젝트나 데이터를 복사하지 않는다. 시간 배분과 완료 조건은 실습지를 따른다.
