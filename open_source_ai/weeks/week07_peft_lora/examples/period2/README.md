# 7주차 2교시 — 내 답변 예시로 LoRA 학습

[실습지 2교시](../../lab.md#2교시-실습--내-답변-예시로-lora-학습)의 소스 안내다. 이 폴더에서는 실행하지 않는다. [examples 프로젝트](../README.md)의 개인 복사본 루트에서 이전 교시와 같은 환경을 이어 쓴다.

| 명령 | 읽을 소스 | 하는 일 |
|---|---|---|
| `uv run ex03` | [ex03_train](../src/ex03_train/__init__.py) | 항목 이름을 바꾼 데이터로 학습·어댑터 저장 |

먼저 `src/shared/data/sample_sft.jsonl`에서 찾아 바꾸기(`Ctrl+H`)로 `기억할 점:`을 자기가 정한 항목 이름으로 모두 바꾼다. 학습을 시작하면 첫 답변(제우스)에 새 이름이 보이는지, loss와 저장 파일을 확인한다. 느린 CPU에서는 `STEPS`를 3으로 줄여 실행 경로를 확인한다.

대화 예제는 질문을 반복 입력하고 `/bye`로 끝낸다. 빈 줄은 건너뛰며, 앞 질문을 기억하지 않는다. 수정할 값은 소스 위쪽의 상수다. 교시마다 프로젝트나 데이터를 복사하지 않는다. 시간 배분과 완료 조건은 실습지를 따른다.
