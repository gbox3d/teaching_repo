# 7주차 1교시 — Ollama 대화와 학습 도구 연결

[실습지 1교시](../../lab.md#1교시-실습--ollama-대화와-학습-도구-연결)의 소스 안내다. 이 폴더에서는 실행하지 않는다. [examples 프로젝트](../README.md)의 개인 복사본 루트에서 실행하고, 2·3교시에도 이 환경을 이어 쓴다.

| 명령 | 읽을 소스 | 하는 일 |
|---|---|---|
| `uv run ex01` | [ex01_ollama](../src/ex01_ollama/__init__.py) | 기존 Ollama 대화와 프롬프트 변경 |
| `uv run ex02` | [ex02_transformers](../src/ex02_transformers/__init__.py) | 작은 모델을 Transformers로 직접 실행, 같은 형식 지시 확인 |

프롬프트·RAG는 입력을 바꾸고, LoRA는 학습할 가중치를 바꾼다. 같은 형식 지시를 `ex01`과 `ex02`의 `PROMPT`에 덧붙여 2B와 0.5B가 따르는지 비교한다. 서로 다른 모델의 답변을 학습 전후로 비교하지 않는다.

`ex01`을 `/bye`로 끝낸 뒤 `ex02`로 넘어가기 전에 `ollama stop qwen3.5:2b`를 실행한다. 대화를 끝내도 남아 있을 수 있는 Ollama 모델을 내려 GPU 메모리를 확보한다. `ex01`의 `MODEL`을 바꿨다면 그 모델 이름을 쓴다.

대화 예제는 질문을 반복 입력하고 `/bye`로 끝낸다. 빈 줄은 건너뛰며, 앞 질문을 기억하지 않는다. 수정할 값은 소스 위쪽의 상수다. 교시마다 프로젝트나 데이터를 복사하지 않는다. 시간 배분과 완료 조건은 실습지를 따른다.
