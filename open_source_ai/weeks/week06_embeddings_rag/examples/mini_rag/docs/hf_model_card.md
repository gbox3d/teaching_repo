# Hugging Face 모델 카드와 캐시

Hugging Face Hub의 모델 저장소에는 가중치 파일과 함께 README 형식의 모델 카드가 있다. 모델 카드에서 먼저 볼 항목은 라이선스, 의도된 용도, 학습 데이터, 평가 결과, 알려진 한계와 편향이다.

일부 모델은 gated 상태라 약관에 동의하고 액세스 토큰을 발급받아야 내려받을 수 있다. 토큰은 `.env` 파일에만 두고 코드나 저장소에 적지 않는다.

모델 ID 뒤에 revision(커밋 해시)을 지정하면 나중에 파일이 바뀌어도 같은 버전을 다시 받을 수 있다. 내려받은 파일은 `HF_HOME` 아래 캐시 폴더의 blobs와 snapshots에 저장되며, `huggingface_hub`의 `scan_cache_dir()`로 용량을 확인한다.

네트워크가 없는 실습실에서는 `HF_HUB_OFFLINE=1`을 설정하면 캐시에 있는 모델만 사용한다. 수업 직전 여러 PC에서 동시에 내려받지 않도록 미리 캐시해 둔다.
