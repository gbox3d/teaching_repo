# 6주차 3교시 — 긴 글 나누기와 내 문서 도우미

[실습지](../../lab.md)의 3교시를 따른다. 실행 위치는 복사한 `examples` 프로젝트 루트다. 1·2교시와 같은 프로젝트를 이어 쓴다.

읽을 코드: [ex05_chunk](../src/ex05_chunk/__init__.py) · [ex06_my_docs](../src/ex06_my_docs/__init__.py) · 자료 [odyssey.md](../src/shared/data/odyssey.md)

```powershell
uv run ex05
uv run ex06
```

`ex05`는 `## 제목`으로 나뉘지 않은 긴 글을 `CHUNK_SIZE`자 조각으로 나눠 저장하고 질문과 가까운 조각을 찾는다. 앞 네 조각의 처음과 끝 30자를 보여 주므로 겹친 부분을 눈으로 확인할 수 있다. `ex06`은 `src/shared/data/`의 `.md` 파일을 모두 조각으로 나눠 저장하고 `[출처]`에 `파일명#조각번호`를 붙여 답한다. 자기 글을 `.md`로 저장해 그 폴더에 넣으면 내 문서 도우미가 된다. 빈 줄은 건너뛰고 `/bye`로 종료한다. 예상 → 실행 → 값 하나 수정 → 비교 → 기록 순서로 진행하며 실습 시간은 30분이다. 세부 시간표·입력 예시·완료 기준은 실습지에 있다.
