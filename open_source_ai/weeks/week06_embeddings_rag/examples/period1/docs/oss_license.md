# 오픈소스 라이선스 기초

오픈소스 라이선스는 저작권자가 코드의 사용·수정·재배포 조건을 미리 허락해 둔 문서다. 라이선스 파일이 없는 코드는 공개되어 있어도 마음대로 쓸 수 없다.

허용적(permissive) 라이선스인 MIT, Apache-2.0, BSD는 저작권 표시와 라이선스 사본을 유지하면 상업적 이용과 재배포를 허용한다. Apache-2.0은 여기에 특허 사용 허락 조항을 함께 담고 있어서 기여자의 특허로 사용자를 공격하지 못하게 막는다.

카피레프트(copyleft) 라이선스인 GPL은 수정한 코드를 배포할 때 같은 라이선스로 소스를 공개하도록 요구한다. AGPL은 배포하지 않고 네트워크로 서비스만 제공하는 경우까지 소스 공개 의무를 넓힌다.

라이선스 이름은 SPDX 식별자(MIT, Apache-2.0, GPL-3.0-only 등)로 적으면 도구가 자동으로 읽을 수 있다. 모델 가중치의 라이선스는 코드와 다를 수 있으므로 모델 카드에서 따로 확인한다.
