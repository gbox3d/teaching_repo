# 6주차 따라하기

준비와 시간표는 [실습지](lab.md)를 따른다. 여섯 명령 모두 같은 프로젝트 루트에서 실행하고, 값을 바꿀 때는 파일 맨 위의 상수만 고친다.

## 1교시

`uv run ex01`을 실행하면 첫 줄에 벡터 길이 1024와 앞 다섯 숫자가 나온다. `헤라는 결혼의 여신이다.`를 입력하면 신화 문장 세 개가 위에, 점심·파이썬 문장이 아래에 온다. `오늘 저녁 메뉴는 라면이다.`와 `변수는 값을 담는 상자다.`를 입력해 1위가 점심·파이썬 문장으로 바뀌는지 본다. `uv run ex02`에서 `메두사를 죽인 영웅은 누구야?`를 입력하고 세 결과의 제목과 점수를 적는다. 종료 후 `TOP_K`를 1로 바꿔 다시 실행한다.

## 2교시

`uv run ex03`에서 같은 질문을 입력하면 `자료 없이>`와 `자료 넣고>` 두 답이 나온다. 자료 없는 답이 틀렸는지 신화 자료 파일로 확인한다. `uv run ex04`에서 신화 질문 두 개와 `토르의 망치 이름은 무엇이야?`를 입력하고 `[출처]` 줄의 점수를 비교한다. 종료 후 `RULES` 문장 하나를 바꿔 같은 질문을 다시 한다.

## 3교시

`uv run ex05`는 첫 줄에 글자 수와 조각 수를 보여 준다. 질문을 입력해 어느 조각이 나오는지 보고, 종료 후 `CHUNK_SIZE`를 150과 1000으로 바꿔 조각 수와 결과를 비교한다. `uv run ex06`은 자료 폴더의 파일별 조각 수를 먼저 출력한다. 메모장으로 쓴 글을 `src/shared/data/`에 `.md`로 저장하고 다시 실행해 그 글에 대해 질문한다.

## 막혔을 때

| 증상 | 확인 |
|---|---|
| 명령을 찾지 못함 | 프로젝트 루트와 `uv sync`, scripts 확인 |
| 연결 실패 | Ollama 실행 여부와 `OLLAMA_HOST` 확인 |
| `model "bge-m3" not found` | `ollama pull bge-m3` 뒤 `ollama list` 확인 |
| 질문 전에 몇 초 기다림 | 실행할 때마다 자료 전체를 벡터로 바꾸는 시간이다. 저장소가 메모리에만 있어 상수를 고쳐 다시 실행하면 다시 기다린다 |
| 자료에 있는데 "자료에 없습니다" | `[출처]`에 그 글이 있는지 본다. 없으면 검색 문제, 있으면 작은 모델의 한계다. 둘을 구분해 기록한다 |
| 답이 자료와 다름 | 자료 파일을 열어 실제 문장과 대조하고 모델이 보탠 부분을 적는다 |
| 실행하자마자 `UnicodeDecodeError`로 멈춤 | 자료 폴더에 UTF-8이 아닌 `.md`가 있다. 메모장 [다른 이름으로 저장]에서 인코딩을 UTF-8로 골라 다시 저장한다 |
| 내 글이 파일별 조각 수에 없음 | 확장자가 `.md`인지(`.md.txt`가 아닌지), `src/shared/data/`에 저장했는지, 다시 실행했는지 확인 |
