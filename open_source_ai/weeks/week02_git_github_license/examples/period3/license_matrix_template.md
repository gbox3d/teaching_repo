## 열 채우는 규칙

- **종류**: `코드`(패키지·저장소), `모델`(가중치), `데이터`(데이터셋·문서) 중 하나.
- **라이선스 이름**: 원문에 적힌 이름 그대로. 모델은 모델 카드 상단의 `license:` 태그와 저장소의 LICENSE 파일을 함께 본다.
- **SPDX ID**: <https://spdx.org/licenses/> 목록의 식별자. 목록에 없으면 `LicenseRef-` 접두사로 직접 이름을 붙인다(예: `LicenseRef-Llama-Community`, `LicenseRef-Gemma-Terms`). 두 라이선스 중 선택이면 `MIT OR Apache-2.0`처럼 쓴다.
- **상업적 이용**: `가능` / `조건부(조건)` / `불가`. 사용 정책이나 사용자 수 제한이 있으면 `조건부`로 적고 괄호에 조건을 쓴다.
- **재배포 조건**: 지켜야 할 것을 핵심 단어로. 예: `고지 유지`, `NOTICE 유지·변경 표시`, `소스 공개·동일 조건`, `출처 표기`, `출처 표기·동일 조건`, `비상업만`.
- **출처 URL**: 라이선스 원문이 있는 위치(저장소 LICENSE 파일, 모델 카드, 데이터 카드). 검색 결과나 블로그는 출처가 아니다.

## 확인 절차

1. 패키지: PyPI 페이지의 License 표시를 보고, 저장소의 LICENSE 파일로 확정한다. 둘이 다르면 저장소 파일을 우선한다.
2. 모델: Hugging Face 모델 카드의 `license:` 태그 → 저장소 파일 목록의 LICENSE → 모델 카드 본문의 사용 정책 순으로 읽는다. Ollama 라이브러리의 모델은 해당 페이지의 라이선스 링크를 따라간다.
3. 데이터: 데이터 카드의 라이선스와 "의도된 용도·금지 용도"를 읽는다. 라이선스가 없거나 "연구 전용"이면 `불가` 또는 `조건부(저작권자 문의)`로 적는다.
4. 같은 계열이라도 크기·버전별로 라이선스가 다를 수 있다. 정확한 모델 ID로 확인한다.
