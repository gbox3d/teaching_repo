# 3교시 — 라이선스 판별과 LICENSE 추가

[실습지 3교시](../../lab.md#3교시-실습--라이선스-판별과-license-추가)의 **문제 카드와 빈 양식**이다.

| 단계 | 파일 | 내 저장소에 만들 파일 |
|---|---|---|
| 문제 1 | [license_cards.md](license_cards.md) | `license_cards_answers.md` |
| 문제 2 | [license_matrix_template.md](license_matrix_template.md) | `license_matrix.md` |
| 확장 | [CONTRIBUTING_sample.md](CONTRIBUTING_sample.md) | 기여물 라이선스 문장 |

개인 저장소에 위 자료를 복사한 뒤 이름을 바꾸고 작성한다.
카드 10문항의 판단·근거, 선택한 LICENSE, 5행 이상의 라이선스 표가 완료 결과다.
정답은 포함하지 않는다. Python·GPU는 사용하지 않는다.
네트워크가 없으면 강의자가 준비한 라이선스 원문을 사용하고 URL은 복구 후 확인한다.

## 실습 시간표

| 단계 | 시간 | 활동 |
|---|---:|---|
| 문제·예상 | 0–3분 | 카드 규칙 읽기, 10문항 판단 예상 |
| 판별 카드 | 3–13분 | `license_cards_answers.md` 10문항 판단·근거 |
| LICENSE 추가 | 13–19분 | MIT 또는 Apache-2.0 선택, 파일 추가, 이유 1문장, commit·push |
| 라이선스 표 | 19–26분 | `license_matrix.md` 항목 5개 이상 |
| 검증·기록 | 26–30분 | SPDX ID 대조, 설명 문장 |

시간은 설명·시연 20분 뒤 시작하는 **실습 30분 기준**이다. 휴식 10분은 별도다.
