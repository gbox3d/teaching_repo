# 라이선스 판별 카드 10문항

3교시 실습용이다. 이 파일에는 정답이 없다. 개인 저장소에 `license_cards_answers.md`로 복사해 채운다.

## 규칙

- 판단은 **가능 · 조건부 · 불가** 중 하나만 고른다.
- 근거에는 라이선스 이름과 조항의 핵심 단어(고지 유지, 소스 공개, 네트워크 제공, 비상업, 동일 조건, 사용 정책, 특허)를 넣는다.
- 판단이 갈리는 카드는 라이선스 원문·모델 카드·데이터 카드에서 확인하고 출처 URL을 적는다. 검색 결과 요약 페이지는 출처로 쓰지 않는다.
- "모르겠다"는 답이 아니다. 모르면 **불가**로 두고 무엇을 확인해야 하는지 적는다.
