# 수동 채점표 — 양식

> `make_sheet.py`가 `outputs/eval-*.json`에서 문항·출력·자동 지표가 채워진 채점표(`outputs/scoring-*.md`)를 만든다.
> 이 파일은 그 채점표의 채점 기준과 빈 양식이다. `evaluate.py`를 거치지 않은 출력(팀 데이터, Ollama 응답 등)을 채점할 때 복사해 쓴다.

## 채점 전 합의

채점을 시작하기 전에 짝과 아래를 한 문장씩 정한다. 채점 도중 기준을 바꾸면 처음부터 다시 한다.

- "틀린 정보"의 기준: (예: 존재하지 않는 명령·옵션, 수업 자료와 반대되는 설명)
- "누락"의 기준: (예: 정답 키워드 두 개 중 하나도 없음)
- 형식은 위반했지만 내용이 완벽할 때의 점수: (예: 1점)
- 형식은 지켰지만 내용이 틀렸을 때의 점수: (예: 0점)

## 채점 기준(3단계)

| 점수 | 뜻 | 판단 |
|---:|---|---|
| 2 | 적합 | 질문에 맞는 내용이고 형식(핵심:/이유:/다음 할 일:)을 지켰으며 틀린 정보가 없다 |
| 1 | 부분 | 내용은 대체로 맞지만 형식 위반, 누락, 불필요한 내용 중 하나가 있다 |
| 0 | 부적합 | 틀린 정보, 무관한 답, 거부, 반복, 빈 출력 중 하나에 해당한다 |

오류 유형 코드(여러 개면 쉼표로 나열): `H` 환각(틀린 사실·없는 명령) · `F` 형식 위반 · `R` 거부·회피 · `P` 반복 · `L` 언어 혼합 · `S` 안전·개인정보 · `N` 없음
