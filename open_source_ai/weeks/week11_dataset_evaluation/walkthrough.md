# 11주차 따라하기

[실습지](lab.md)의 준비를 마친 뒤 전체 clone 안의 `open_source_ai/weeks/week11_dataset_evaluation/examples`에서 실행한다. Python 3.12, `cactus-compute==4.2.0`, Ollama의 `qwen3.5:2b`를 사용한다.

## 준비 확인

저장소 루트의 터미널 A에서 `uv run --python 3.12 tools/bleuno-sim/sim.py --bind 127.0.0.1`을 실행한다. 창 없는 검증에는 `--no-window`를 추가한다. 터미널 B는 주차 `examples/`에서 `uv sync`를 실행한다. 모델·패키지 최초 준비는 비교 측정 전에 마친다.

## 1교시 · Needle 명령 입력

`uv run ex01`에서 `Turn on LED 0.`과 `0번 LED를 켜 줘.`를 입력한다. 밝기 변경·온습도 읽기도 이어서 입력한다. 한국어 요청이 틀리거나 보류되면 그 입력과 반환을 그대로 기록한다. 현재 관찰만으로 언어별 성능 수치를 만들지 않는다.

`ex01_needle`에서 `Cactus(tools=list, auto_date=False)`, `complete()`, `function_calls`를 찾는다. Python은 허용한 함수와 인수만 실행한다. 빈 호출 목록도 표시해 입력과 비교한다. 매 문항 `reset()`은 모델 대화 상태를 비운다. 실제 상태는 TCP 연결을 유지한 채 HTTP `GET /state`로 확인한다.

## 2교시 · 두 모델 비교

`uv run ex02`는 공용 `control_cases.json`의 한글 8·영어 8문항을 두 모델에 보낸다. 호출 10·무호출 6문항의 기대값은 유지한다. 매 문항 LED를 `[0, 64, 128, 255]`로 복원하고 예열 1회는 집계에서 제외한다.

준비 시간은 별도로 적고 추론 시간의 median·p95를 비교한다. 함수 선택 정확도, 전체 호출 완전 일치, 제어 성공률, 무호출 오호출률을 각각 읽는다. 오류와 거부를 누락하지 않는다. 공식 형식의 `confidence`와 실측 정확도는 구분한다. 수업 화면은 호출 목록을 출력하며 실제 정답 여부는 기대값과 상태로 판정한다.

Kev는 공식 카드로 영어 선택지 판단이라는 목적을 확인한다. 일반 도구 호출과 구분하며 별도 설치나 실행 결과를 제출할 필요는 없다.

## 3교시 · 도구 설명 변경

`uv run ex03`에서 기준 입력과 결과를 기록한다. 종료한 뒤 `ex03_descriptions`의 `DESCRIPTIONS` 한 항목만 바꾼다. 같은 기능의 영어·한국어 설명이나 번호·밝기 범위를 명시한 설명을 비교할 수 있다.

같은 명령으로 다시 시작해 새 `Cactus` 인스턴스를 만든다. 도구 이름·인수·검증·모델은 유지한다. 같은 입력과 무호출 입력을 다시 넣고 제안·실제 상태를 기록한다. 설명 수정과 가중치 학습의 차이를 한 문장으로 적는다.

## 막혔을 때

| 증상 | 확인 순서 |
|---|---|
| 라이브러리 경로 오류 | 전체 clone 여부, source 상대 path, `uv sync` |
| Needle 준비 실패 | Python·패키지 버전, 실행 환경 지원과 최초 다운로드 상태 |
| 호출 목록이 비어 있음 | 요청을 수행할 도구가 있는지, 거부 문항인지, 실제 반환 내용 |
| LED 상태가 예상과 다름 | 인수 검증, 연결·해제, 문항 초기 상태, `GET /state` |
| 변경 설명이 반영되지 않음 | `DESCRIPTIONS` 수정 위치, 프로그램 재실행과 새 인스턴스 |
| 비교 수치가 다름 | 같은 16문항·기대값·예열 제외·측정 구간인지 |
