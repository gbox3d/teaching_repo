# 8주차 예제 — 실습 교시별 진입점

[실습지](../lab.md)의 1·2·3교시 순서에 맞춘 자료다. 먼저 해당 교시 README에서 **시간 → 실습 단계 → 파일 → 실행 위치**를 확인한다. 원본은 보관하고 개인 폴더에 복사한다.

| 실습 시간 | 폴더 | 그 시간에 사용하는 자료 |
|---|---|---|
| 1교시 | [period1/](period1/README.md) | 모의 실기 A 복구 시작 자료 |
| 2교시 | [period2/](period2/README.md) | 모의 실기 B 기능 추가 시작 코드 |
| 3교시 | [period3/](period3/README.md) | 개인 실기 진행 카드·과제 점검 |

## 폴더 사용 원칙

- 각 period에는 해당 교시까지 필요한 코드·양식·입력 파일의 실제 사본이 있다. 다른 period를 import하거나 호출하는 래퍼는 없다.
- 개인 출력·설정·어댑터 전달 방법은 각 README와 실습지 준비 절에 있다. 가상환경은 복사하지 않는다.
- 의도적 오류·TODO와 평가 자료는 시작 자료이며 정답이 아니다.
- 모델·패키지는 수업 전에 준비한다. CPU·모델 없음·네트워크 제한 대체 경로는 각 README를 따른다.
- Python은 해당 프로젝트에서 `uv run`으로 실행한다. lock은 학기 기준 확정 후 기준 PC에서 생성·검증해 배포한다.

## 기존 자료와의 관계

`mock_exam/`과 `assignment_check.ps1`은 기존 링크와 이전 자료를 위한 **통합 참고본**으로 남긴다. 이번 실습은 위 period 폴더에서 시작한다. 설치·환경은 [공통 uv 가이드](../../../uv_guide.md), 배포 제외 확인은 [GitHub 배포 가이드](../../../github_distribution.md)를 참고한다.
