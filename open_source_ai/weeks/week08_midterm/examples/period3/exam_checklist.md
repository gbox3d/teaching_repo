# 3교시 진행 카드

- [ ] 0–5분: 환경 점검 시각, 지정 저장·제출 경로, 시작 git status 확인
- [ ] 5–22분: 요구사항별 완료 조건 표시, 가장 짧은 실행 경로부터 해결
- [ ] 막힌 항목: 증상 / 관찰 / 시도 각 한 줄
- [ ] 22–27분: 정상·실패 실행, 출력 파일·답안 다시 확인
- [ ] 27–30분: commit, commit id 기록, 제출 파일 다시 열기

## 다른 슬롯에서 평가하는 분반

- [ ] assignment_check.ps1로 과제 저장소 점검
- [ ] 새 clone에서 README의 설치·인덱스 생성·평가를 그대로 실행
- [ ] README에 누락된 절차 보완 후 commit
- [ ] [2차 종합과제 안내](../../assignment_brief.md)의 제출 전 검사 목록 확인

실제 문항·starter·답안은 비공개 패킷을 따른다. 이 문서는 답안 양식이 아니다.
