# 8주차 3교시 — 개인 실기평가와 대체 운영

개인 실기의 **공개 진행 카드와 환경 점검 도구**다. 비공개 평가 starter·문항·정답은 포함하지 않는다. 평가가 다른 슬롯인 분반에는 종합과제 검사 도구를 제공한다.

기준: [실습지의 3교시](../../lab.md#3교시-실습--개인-실기평가와-대체-운영). 아래 시간은 실습 30분의 구간이며, 설명 20분·휴식 10분은 기존 시간표를 따른다.

## 시간과 파일 대응

| 시간 | 실습 단계 | 읽거나 실행할 파일 |
|---|---|---|
| 0–5분 | 환경·저장 경로 점검 | `check_env.py`, `exam_checklist.md` |
| 5–22분 | 비공개 문항 해결 또는 과제 재현 | 비공개 패킷 / `assignment_check.ps1` |
| 22–27분 | 정상·실패 경로 검증 | `exam_checklist.md` |
| 27–30분 | commit id·제출 재확인 | `exam_checklist.md` |

## 이전 산출물과 시작 위치

2교시 결과물은 본인 복사본에 보관한다. 이 폴더의 `check_env.py`·`config.py`는 점검에 필요한 실제 사본이다. `examples/period3`을 개인 폴더로 복사한 뒤 그 안에서 실행한다. 비공개 패킷에 별도 점검기가 있으면 그 지시를 우선한다.

## 실행 순서

복사·`.env` 생성·이전 산출물 전달은 **새 실습 폴더에서 최초 1회만** 한다. 이미 작업 중이면 이 명령들을 생략하고 실행 위치 확인부터 이어간다. 기존 개인 코드·설정·결과를 덮어쓰지 않는다. 새 period의 누적 코드와 개인 변경은 비교하여 필요한 수정만 옮긴다.

```powershell
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
uv sync
uv run python check_env.py
Get-Content outputs\env-check.json
# 평가가 다른 슬롯인 분반의 대체 실습
.\assignment_check.ps1 -RepoPath <내 과제 저장소>
```

실제 평가 작업은 지정된 비공개 저장 경로에서 하고 `git status`·최종 commit id를 기록한다.

## 예상 출력과 완료 확인

시각이 있는 `outputs/env-check.json`과 제출 경로·파일·commit id 점검 기록을 남긴다. 과제 대체 운영은 검사 FAIL 조치와 깨끗한 clone에서 README 재현을 확인한다.

## 대체 경로

연결 장애는 발생·보고 시각을 적고 감독에게 알린다. 공개 카드로 비공개 시험 조건을 대신하지 않는다. 평가 시간·허용 도구·제출 경로는 학교 운영 문서가 기준이다.

실측 결과·답안은 개인 실습 폴더에 기록한다. 실제 비밀정보와 환경 폴더를 공개하지 않는다. 학기 기준이 정해지면 기준 PC에서 생성·검증한 lock을 배포하며, 현재 원본에는 lock을 넣지 않았다.
