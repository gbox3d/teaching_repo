## 역할

여기는 둘 이상의 과목에서 같은 학습목표로 재사용하는 템플릿과 모듈을 두는 곳이다.
현재 교재의 파일 완전중복은 거의 없으므로, 먼저 폴더만 만들고 실제 내용은 검토 후 승격한다.

## 승격 기준

다음 조건을 모두 만족할 때만 과목 폴더에서 `_shared/`로 옮긴다.

1. 둘 이상의 교재가 실제로 사용한다.
2. 학습목표와 설명 순서가 같다.
3. 학교명·분반·배점·마감·LMS 정보가 없다.
4. 독립적으로 읽거나 실행할 수 있다.
5. 변경 시 영향을 받는 교재를 색인할 수 있다.

## 후보

- 주차 모듈 템플릿: `README`, `slides`, `lab`, `examples` (강의 대본은 비공개 별도 관리)
- Git·GitHub 기본, 재현 가능한 개발환경
- 테스트·비밀정보·공급망 보안·릴리스
- 발표·보고서·범용 루브릭 빈 양식
- 설치 확인과 장애 보고 양식

## 두지 않는 것

- 학교별 평가 비율과 실제 시험문제
- 학생 제출물, 성적, 출석과 개인정보
- 학교 내부 시스템(LMS 등) 선택자나 로그인 절차
- 실제 API 키, 비밀번호, 쿠키와 브라우저 프로필
- 특정 학기에만 유효한 임시 공지
