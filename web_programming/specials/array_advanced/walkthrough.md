# 배열 심화 따라하기

다섯 예제의 실행 결과를 먼저 확인한 뒤 [실습지](lab.md)의 비교 활동으로 이어 간다. 보강수업 자료이며 정규 11주차 제출물과는 별도다.

## 1. 파일과 서버 준비

저장소를 내려받아 VS Code에서 `teaching_repo` 폴더를 연다. `web_programming/specials/array_advanced/examples/`에서 실습할 폴더를 찾는다.
화면은 [W3.CSS CDN](https://cdnjs.cloudflare.com/ajax/libs/w3-css/4.1.0/w3.min.css)을 사용하므로 인터넷 연결이 필요하다.

저장소 루트의 터미널에서 실행한다.

```bash
node web_programming/tools/static-server/server.mjs web_programming 8111
```

예상 결과: 터미널에 서버 주소가 표시된다. 브라우저에서 http://localhost:8111/specials/array_advanced/examples/01_insert_delete/ 를 연다. 화면 모양이 없으면 F12 → Network에서 `w3.min.css` 요청의 상태를 확인한다.

## 2. 삽입과 삭제

값 칸에 귤을 입력하고 push를 누른다. 배열은 네 항목이 되고 반환값은 `4`다. 초기화 후 같은 값으로 unshift를 누르면 귤이 맨 앞에 놓인다.

다시 초기화한 뒤 위치 1에 귤을 splice 삽입한다. 배열은 `['사과', '귤', '바나나', '포도']`, 반환값은 `[]`다.
초기화 후 위치 1을 splice 삭제하면 배열은 `['사과', '포도']`, 반환값은 `['바나나']`다.

예상 결과: 반환값 칸이 변경 후 배열과 항상 같지는 않다. pop·shift로 배열을 비운 뒤 한 번 더 실행하면 `undefined`가 나타난다.

## 3. 순회

주소 끝을 `02_iteration/`으로 바꾼다. for...of 실행과 forEach 실행을 차례로 누른다.

예상 결과: 두 목록 모두 하늘 80점·바다 60점·노을 90점이다. for...of의 반환값 칸은 반복문이므로 해당 없음, forEach의 반환값은 `undefined`다. 반복 실행해도 목록은 세 항목이다.

## 4. 조건 선택

주소 끝을 `03_filter/`로 바꾼다. 최소 점수 70에서 filter 실행을 누른다. 이어 100에서 다시 실행한다.

예상 결과: 70에서는 하늘·노을 두 명, 100에서는 `[]`와 0명이 나온다. 원본 세 학생은 그대로다. 콜백은 학생을 지우는 대신 포함할지 판단한다.

## 5. 값 변환

주소 끝을 `04_map/`으로 바꾼다. 가산점 5로 map 실행을 두 번 누른다. 이어 가산점 10으로 실행한다.

예상 결과: 두 번 누른 결과는 모두 85·65·95이며 10에서는 90·70·100이다. 원본은 80·60·90이다. 코드에서 원본 대신 새 `{ name, score }` 객체를 만드는 줄을 확인한다.

## 6. 합계와 빈 배열

주소 끝을 `05_reduce/`로 바꾼다. 합계 계산을 누르고 표의 누적값 0→80→140과 다음 값 80→140→230을 확인한다.
빈 배열을 선택한 뒤 다시 계산한다.

예상 결과: 일반 입력은 합계 230·콜백 3회, 빈 배열은 합계 0·콜백 0회다. 표도 세 행에서 빈 표로 바뀐다. 원본 학생 배열은 유지된다.

## 7. 코드 수정과 기록

각 폴더의 `app.js`에서 조건·가산점 계산·초깃값을 찾아 읽는다. [실습지](lab.md)의 입력 비교를 수행하고 예상과 관찰의 차이를 남긴다. 파일을 바꾼 뒤 저장·새로고침해야 새 코드가 반영된다.

실습을 마치면 서버 터미널에서 Ctrl+C를 누른다. 이 예제는 저장 기능이 없으므로 배열 변화는 새로고침 후 남지 않는다. 작성한 코드와 별도로 보관한 기록은 남는다.
