# 웹프로그래밍 특강 자료

정규 15주 수업과 별도로 운영하는 1회성 실습 자료를 모은다. 특강도 주차별 자료와 같은 문서 구조를 쓰되,
한 번의 수업에서 눈에 보이는 결과물 하나를 끝내는 데 초점을 둔다.

## 운영 기준

- 1회 90~120분. 설명·시연 뒤 바로 만들어 보는 실습 중심이다.
- 정규 주차의 실습 점수·시험에 넣지 않는다. 운영 여부와 시기는 강의자가 정한다.
- 결과물은 **캡처 1장으로 보여 줄 수 있는 화면**으로 끝낸다.
- 확인과 캡처의 기준은 정규 주차와 같이 **공개 주소**다. 로컬 미리보기는 작업 중 확인용이다.
- 외부 서비스의 키는 공개해도 되는 것만 저장소에 둔다. 비밀 키·비밀번호·개인 위치 정보는 저장소·제출물·캡처에 넣지 않는다.
- 공개 저장소와 캡처에 실명·학번·전화번호·실제 이메일을 넣지 않는다.

## 폴더 구성

| 파일·폴더 | 역할 |
|---|---|
| <code>README.md</code> | 학습 목표, 운영 흐름, 준비물, 완료 기준, 안전 규칙 |
| <code>slides.md</code> | Marp 형식 PT 원고 |
| <code>walkthrough.md</code> | 처음부터 그대로 따라 하는 단계(할 일 → 예상 결과) |
| <code>lab.md</code> | 실습 시간표, 단계별 문제와 힌트, 막혔을 때, 제출물 |
| <code>examples/</code> | 실행 가능한 예제와 설명 |

강의 대본과 실습 해답은 강의자가 별도로 관리한다.

특강 자료는 특정 서비스의 이용 허용 범위를 법률적으로 판정하지 않는다.
수업 밖에서 공개·배포하기 전에는 사용 목적과 배포 형태에 맞춰 해당 서비스의 최신 공식 문서와 운영 정책을 다시 확인한다.
