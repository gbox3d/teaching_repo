# 웹프로그래밍 특강 자료

정규 15주 수업과 별도로 운영하는 1회성 실습 자료를 모은다. 특강도 주차별 자료와 같은 문서 구조를 사용하되, 한 번의 수업에서 실행 가능한 결과물을 완성하는 데 초점을 둔다.

## 운영 기준

- 1회 90–120분
- 설명·시연 뒤 바로 실행하고 수정하는 실습 중심
- 실습 순환: 문제 읽기 → 예상 → 구현 → 관찰 → 오류 설명 → 확장
- 정상 동작뿐 아니라 권한 거부, 잘못된 입력, 설정 누락 같은 실패 경로도 확인
- 외부 API 키와 개인 위치 정보는 저장소·제출물에 포함하지 않음

## 폴더 구성

| 파일·폴더 | 역할 |
|---|---|
| <code>README.md</code> | 학습 목표, 운영 흐름, 실행·보안 기준 |
| <code>slides.md</code> | Marp 호환 PT 원고 |
| <code>lab.md</code> | 문제→예상→구현→관찰→오류 설명→확장 실습지 |
| <code>examples/</code> | 실행 가능한 예제와 테스트 안내 |

특강 자료는 특정 서비스의 이용 허용 범위를 법률적으로 판정하지 않는다. 실제 공개·배포 전에는 사용 목적과 배포 형태에 맞춰 해당 서비스의 최신 공식 문서와 운영 정책을 다시 확인한다.
