# 연주기와 멜로디 조합기

이 폴더 전체를 정적 서버로 엽니다. 저장소 루트에서 실행할 경우 다음 명령을 사용합니다.

```powershell
node web_programming/tools/static-server/server.mjs web_programming/specials/synthesizer/examples/build 8000
```

연주기는 `http://localhost:8000/`, 조합기는 `http://localhost:8000/compose.html`입니다. GitHub Pages에 이 폴더 전체를 올려도 동작합니다. Node.js는 파일을 제공할 때만 필요하고 오디오·편곡은 브라우저가 처리합니다. 별도 API나 환경 변수는 없습니다.

## 연주기

1. 곡을 고르고 재생을 누릅니다. 초기 곡은 `only_you.json`입니다.
2. BPM·리듬·코드 파형·필터와 각 악기 체크를 바꿉니다.
3. 정지를 누릅니다. 새 예약을 멈추고 이번 연주의 출력 게인을 낮춘 뒤 연결을 끊습니다.
4. `my_song.json`을 골라 멜로디 없는 8마디 연습곡과 비교합니다.

곡을 바꾸는 동안 재생 버튼은 비활성화됩니다. 마지막으로 선택한 곡만 반영됩니다. 불러오기에 실패하면 악보를 비우고 오류를 표시합니다. BPM 슬라이더 범위는 80~140이므로 파일의 BPM이 범위를 벗어나면 재생값은 끝값으로 맞춰집니다.

## 조합기

- 라이브러리의 이름 버튼은 한 마디 미리 듣기, `+`는 선택한 마디 뒤에 추가입니다. 선택이 없으면 맨 끝에 추가됩니다.
- 편곡 마디를 누르면 선택됩니다. 같은 마디를 다시 누르면 선택이 해제됩니다. 키보드 Tab·Enter로도 선택할 수 있습니다.
- 구간·코드·멜로디·옮김을 바꾸고 복제·이동·삭제를 비교합니다. 코드 `F G`는 한 마디를 반씩 나눕니다.
- 잘못된 코드는 편곡에 반영하지 않으며 입력을 마치면 마지막 유효한 값으로 복구합니다. 옮김은 -12~12 반음이고 결과 MIDI가 0~127을 벗어나면 반영하지 않습니다. 멜로디를 바꾸면 옮김은 0으로 초기화됩니다.
- `곡으로 열기`와 `내 파일로 열기`는 편곡 전체를 교체합니다. `라이브러리에 더하기`와 파일 추가는 멜로디 조각만 추가합니다.
- 실패한 파일은 현재 편곡을 바꾸지 않습니다. 파일 요청이 겹치면 마지막 요청만 반영합니다.
- 내보내기는 JSON 다운로드입니다. 서버에 저장하지 않습니다. 다운로드 파일을 다시 열어 제목·마디·멜로디가 같은지 확인합니다.

연주기에서 내보낸 곡을 사용하려면 파일을 이 폴더에 두고 `index.html`의 `#song` 선택 목록에 해당 파일명인 `<option>`을 추가합니다. 기존 `my_song.json`을 자기 곡으로 교체하는 방법도 있습니다.

## 데이터 형식과 소스

곡은 `track_info`와 `sections`로 구성합니다. 구간의 `progression` 배열에 마디별 `chord`와 선택적 `melody` 배열을 둡니다. `melody`를 생략하면 반주만 연주합니다. 음 하나는 `step`(1~16), `midi`(0~127), `duration_steps`(1~64)를 정수로 가집니다. `note` 문자열은 읽기용이며 실제 높이는 `midi`로 계산합니다.

| 파일 | 역할 |
|---|---|
| [index.html](index.html), [index.js](index.js) | 연주 화면·리듬·예약·JSON 불러오기 |
| [compose.html](compose.html), [compose.js](compose.js) | 라이브러리·편집·미리 듣기·JSON 다운로드 |
| [main.css](main.css) | 두 화면 공용 스타일 |
| [synth.js](synth.js) | 오디오 노드와 음색 |
| [song.js](song.js) | 데이터 검사·음 옮김·곡 변환·멜로디 태그 |
| [only_you.json](only_you.json), [my_song.json](my_song.json) | 참고 곡과 연습곡 |

같은 태그 글자는 같은 멜로디를 뜻합니다. 프라임(′) 표시는 음 데이터 차이가 작은 변형을 묶은 것으로 음악적 유사도 분석 결과는 아닙니다.
