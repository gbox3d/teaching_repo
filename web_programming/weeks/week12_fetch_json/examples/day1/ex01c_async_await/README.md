# ex01c · async 함수와 await

[화면](index.html)에서 **타이머 시작**을 누른다. [ex01b](../ex01b_wait/README.md)와 같이 ‘1. 시작’, 약 1초 뒤 ‘2. 1초 지남’, 다시 약 1초 뒤 ‘3. 2초 지남’이 나온다. 기다리는 동안 **클릭**을 누르면 클릭 수가 바로 올라간다.

[app.js](app.js)의 타이머 리스너는 `async function`이다. 이 함수는 `await wait(1000);`에서 약 1초 멈췄다가 다음 줄로 넘어간다. 화면은 멈추지 않으므로 **클릭** 버튼의 리스너는 그동안에도 실행된다. ex01b에서 `.then()`에 넘긴 함수 안에 있던 줄이 여기서는 `await` 다음 줄이 된다.

| 화면의 줄 | ex01b의 `then` | ex01c의 `await` |
|---|---|---|
| ‘2. 1초 지남’ | 첫 `then`의 함수 안 | 첫 `await wait(1000);` 다음 줄 |
| ‘3. 2초 지남’ | 두 번째 `then`의 함수 안 | 두 번째 `await wait(1000);` 다음 줄 |

1차시 실습에서는 이 폴더의 사본을 만든다. 사본의 `app.js`에서 ‘3. 2초 지남’ 출력 줄과 `button.disabled = false;` 사이에 `await wait(1000);`과 출력 한 줄을 더해 ‘4. 3초 지남’을 표시한다. 약 3초 뒤 네 번째 줄이 붙고, 그동안에도 **클릭**이 동작하면 된다.
