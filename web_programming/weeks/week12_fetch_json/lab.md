# 12주차 실습 · 접속 확인에서 서버 목록까지

양일 강의·시연 60분 뒤 30분씩 진행한다. 폴더 배부·저장소 준비·서버 실행은 사전에 끝내고 강의 첫 5분에 확인한다. 설정 패널과 오류 처리 틀은 제공 코드다.

## 1일차 실습

| 시간 | 학생 활동 | 확인 결과 |
|---|---|---|
| 0~5분 | 브라우저 API 설정과 REST Client의 `.env`를 각각 확인한다 | 기본 로컬 또는 배부 공용 값 적용 |
| 5~13분 | ex01 about, ex02 help의 **Send Request** 실행 | 200·정보 배열과 사용법 배열 |
| 13~23분 | ex03에서 BOOK_ID와 limit 1·2·5 비교 | 요청 필터와 최대 글 수의 관계 |
| 23~30분 | 브라우저 GET과 REST Client 응답의 이름·메시지 대조 | URL·apikey·상태·배열 설명 |

`.env.example`을 `.env`로 복사하고 실제 값은 이 로컬 파일에만 적는다. `requests.http`는 `{{$dotenv ...}}`로 읽는다. 브라우저에는 같은 값을 API 설정 패널로 따로 입력한다. 새로고침하면 패널은 기본 로컬 값으로 돌아간다. JSON 문자열과 객체 복습은 [11주 ex05](../week11_object_localstorage/examples/day2/ex05/)를 참고한다.

## 2일차 실습

| 시간 | 학생 활동 | 확인 결과 |
|---|---|---|
| 0~12분 | 제공 web-week12의 GET 함수에서 URL·response.json·showList 호출 3곳을 연결한다 | 서버 배열이 목록으로 표시 |
| 12~22분 | ex05에서 없는 필드→정상 필드, ex06에서 Offline→No throttling을 실행한다 | HTTP 400·통신 실패·복구 성공 |
| 22~30분 | 완성본 새로 불러오기, 375px 확인, 목록과 GET 200 캡처 | 중복 없는 목록·버튼 복구 |

강의자는 조립 틀의 세 줄을 표시한다. 학생이 전체 HTML·설정 패널·try/catch를 다시 쓰지는 않는다. [따라하기](walkthrough.md)의 완성 코드와 현재 파일을 대조한다. `guestbook.local.html`은 제공 11주 보관본이며 서버 화면의 GET과 저장 위치가 다르다.

## 오류 확인과 복구

| 증상 | 확인·조치 |
|---|---|
| about 401 | `.env` 또는 브라우저 공개 키 확인. 둘은 별개다 |
| about 404 | API 주소에 `/rest/v1`을 중복해서 넣지 않았는지 확인 |
| GET 200과 `[]` | 글이 없는 정상 응답. BOOK_ID와 서버 초기 글 확인 |
| Offline 실패 | No throttling으로 되돌리고 버튼 재시도. 버튼이 다시 활성화되어야 함 |
| REST Client 성공·브라우저 실패 | 브라우저 Network와 CORS·HTTP/HTTPS 조건을 강의자와 확인 |
| Pages에서 기본 로컬 API 실패 | API 설정에 배부받은 공용 HTTPS 값을 입력. 새로고침마다 재입력 |

실습에서는 서버에 글을 쓰거나 로컬 저장 값을 지우지 않는다. 11주 필수 과제는 폼 한 객체 저장·복원이고 객체 배열 방명록은 제공 시연본이다.

## 제출과 수업 뒤 정리

서버 목록·페이지 주소·Network의 GET 200을 한 장에 캡처한다. 키 입력칸과 Request Headers는 접는다. 로컬 리허설 결과도 인정하며 두 기기 공유 완료와 구별한다. 공용 HTTPS API를 쓸 수 있을 때만 두 브라우저의 같은 목록을 추가로 확인한다.

수업 뒤 `web-week12`을 업로드하되 `.env`와 실제 키가 포함되지 않았는지 확인한다. Pages 지연 시 로컬 캡처와 Commits 화면을 제출하고 다음 수업에 공개 URL을 확인한다. 공용 PC의 로그인·저장된 Git 자격 증명을 정리한다.

## 선택 연습

ex04의 name·message 표시 순서를 바꾸거나 서버 id를 앞에 표시한다. 제공 URL의 limit을 줄여 표시 개수를 비교한다. 선택 연습은 30분 기본 실습과 평가 범위에 추가하지 않는다.
