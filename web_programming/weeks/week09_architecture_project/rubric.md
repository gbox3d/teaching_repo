# 1차 과제 채점표 — 10점

채점 대상은 학생이 제출한 **공개 주소**와 **저장소 첫 화면(README)**, 그리고 2일차 2분 발표다.
채점자는 발표 중에 이 두 가지만 연다. 코드 파일은 구술 질문에 답할 때만 연다.

## 발표 5점

| 항목 | 배점 | 충족 기준 |
|---|---:|---|
| 공개 주소가 열린다 | 1 | `https://<아이디>.github.io/my-web/`을 발표자가 직접 열어 화면이 나온다 |
| 세 페이지 이동 | 1 | nav로 홈·내 정보·방명록을 오가고 404가 나지 않는다 |
| 버튼·폼 시연 | 2 | 버튼을 눌러 문장·횟수가 바뀌고(1), 폼에 글을 남겨 한 줄이 보인다(1). 빈값 안내까지 보이면 폼 1점을 채운 것으로 본다 |
| 시간 준수 | 1 | 2분 안에 위 세 가지를 마친다. 2분 20초까지는 감점하지 않는다 |

## 레포트 5점 — 저장소 `README.md`

| 항목 | 배점 | 충족 기준 |
|---|---:|---|
| 공개 주소 | 1 | Pages 주소가 링크로 있고 눌러서 열린다 |
| 페이지 | 1 | 세 페이지가 목록으로 있고 각 한 줄 설명이 있다 |
| 기능 | 1 | 버튼과 폼이 하는 일이 각각 한 줄로 적혀 있다 |
| 화면 | 1 | `screenshots/`의 캡처 2장이 링크로 있고 열린다. 두 캡처가 **동작한 뒤** 화면이다 |
| 이번에 배운 것 | 1 | 세 줄이 있고 이번 학기에 실제로 한 것과 맞다 |

제목(`# 사이트 이름`)은 다섯 항목이 모두 있는지 볼 때 함께 확인하며 따로 배점하지 않는다.

## 수준별 판단

### 완전 충족

채점자의 브라우저에서 공개 주소가 그대로 열리고, 발표한 동작이 재현되며, README 다섯 항목이 본인 사이트의 내용이다.

### 부분 충족

- 기능 하나가 멈췄지만 나머지가 동작한다 → 그 항목만 감점한다.
- README 항목이 있으나 내용이 예시 그대로다(`student01`이 남아 있다) → 해당 항목 0.5점.
- 캡처가 `클릭 0회`·`아직 남긴 글이 없습니다.` 상태다 → 화면 1점 중 0.5점.

### 미충족

공개 주소가 열리지 않고 대체 증거(로컬 화면 + **Commits** 탭)도 없거나, README가 저장소에 없다.

## 감점 적용 원칙

- 원인이 하나인데 증상이 여럿이면 한 번만 감점하고 그렇게 기록한다.
- 항목별 최대 배점을 넘겨 깎지 않는다.
- 색이 예쁘지 않은 것과 기능이 동작하지 않는 것을 같은 수준으로 보지 않는다.
- 본인 기능 1개(선택)는 가점하지 않는다. 그 때문에 필수 동작이 멈추면 해당 항목에서만 감점한다.
- Pages 반영 지연으로 공개 주소가 늦게 뜨는 경우는 감점하지 않는다. 로컬 화면과 **Commits** 탭으로 확인한다.
- 발표 순서가 밀려 생긴 지연은 시간 점수에 넣지 않는다.
- 8주차 `exam/` 폴더의 내용은 이번 과제에서 채점하지 않는다.
