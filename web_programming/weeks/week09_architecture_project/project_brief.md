# 1차 과제 — 프로젝트 설계와 walking skeleton

## 배점

- 발표: 5점
- 보고서: 5점
- 합계: 10점

개인 과제이며 제출 방식과 마감 시각은 해당 학기 LMS 공지를 따른다.

## 필수 산출물

1. repository URL과 실행 URL
2. 문제·핵심 사용자·Must 범위
3. 사용자 이야기와 acceptance scenario
4. entity/relationship/owner 표
5. architecture와 data-flow diagram
6. 여섯 UI 상태표
7. mock data 기반 walking skeleton
8. 구현 위험 하나와 다음 주 검증 계획

## 3분 발표 권장 구성

| 시간 | 내용 |
|---:|---|
| 0:00–0:30 | 사용자와 문제 |
| 0:30–1:30 | scope, entity, architecture |
| 1:30–2:30 | 실행 시연과 상태 |
| 2:30–3:00 | 위험, 다음 단계 |

## 보고서 권장 구조

```text
1. 문제와 사용자
2. Must/Should/Could
3. 사용자 흐름과 acceptance scenario
4. 데이터 모델과 권한
5. architecture/data flow
6. walking skeleton 실행·검증
7. 위험과 10–14주차 계획
8. 자료·asset 출처
```

## 제출 전 검사

- [ ] 발표와 보고서가 같은 scope를 설명한다.
- [ ] URL을 로그아웃/새 탭 조건에서 열었다.
- [ ] diagram의 상자·화살표가 실제 계획과 일치한다.
- [ ] mock임을 명확히 표시하고 실제 secret을 넣지 않았다.
- [ ] 캡처만이 아니라 재현 단계와 commit을 제공한다.
