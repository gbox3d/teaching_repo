# 1차 과제 — 내 사이트 2분 발표와 README

개인 과제다. 새로 만드는 프로젝트가 아니라 **3~7주에 만든 `my-web`을 그대로** 발표한다.
제출 방식과 마감은 수업 공지를 따른다. 배점은 10점(발표 5 + 레포트 5)이며 채점 기준은 [채점표](rubric.md)에 있다.

## 과제 범위

발표 대상은 `my-web` 본체다. 8주차 중간 실기를 본 `my-web/exam/` 폴더는 이번 과제와 관계가 없다.

| 갖춰야 할 것 | 어디서 만들었나 | 발표에서 |
|---|---|---|
| 공개 주소 `https://<아이디>.github.io/my-web/` | 2주차 | 첫 20초에 연다 |
| 세 페이지 `index.html`·`about.html`·`guestbook.html`과 nav | 3주차 | 오가며 보여 준다 |
| `styles.css` — 색·박스·`display: flex`·`@media` 1개 | 4주차 | 화면으로 보인다 |
| 버튼 클릭 기능 1개 — 문장이 바뀌고 횟수가 오른다 | 5·6주차 | 눌러서 보여 준다 |
| 폼 입력과 빈값 안내 1개 | 7주차 | 남겨 보고, 비우고 눌러 본다 |
| 저장소 `README.md` 1차판 5항목과 `screenshots/` 캡처 2장 | 9주차 | 마지막 20초 |

본인 기능 1개를 더 넣어도 된다(선택). 발표 소재로 쓸 수 있지만 **가산점은 없다.**
기능을 더 넣다가 위 표의 동작이 멈추면 그 항목에서 점수를 잃는다.

## 레포트 = 저장소 README.md 한 장

별도 보고서 파일(docx·pdf)은 받지 않는다. 채점자는 공개 주소와 저장소 첫 화면만 연다.

```text
# 사이트 이름
## 공개 주소        Pages 주소 링크
## 페이지           세 페이지와 한 줄 설명
## 기능             버튼 한 줄, 폼 한 줄
## 화면             screenshots/ 캡처 2장 링크
## 이번에 배운 것   3줄
```

- 마크다운은 `#`(제목)·`-`(목록)·`[보이는 글](https://주소)`(링크) 세 가지만 쓴다. 같은 저장소 안의 파일은 소괄호에 파일 이름만 적는다.
- 캡처 두 장은 **동작한 뒤의 화면**으로 찍는다(버튼을 누른 홈, 글을 남긴 방명록).
- 예시는 [examples/day1/README.md](examples/day1/README.md)에 있다. 그대로 베끼지 말고 본인 사이트 내용으로 바꾼다.

## 2분 발표 순서

| 시간 | 보여 줄 것 |
|---|---|
| 0:00–0:20 | 공개 주소를 열고 사이트 이름·한 줄 소개 |
| 0:20–0:50 | nav로 세 페이지 이동 |
| 0:50–1:30 | 버튼 한 번, 폼 한 번(빈값 안내까지) |
| 1:30–2:00 | GitHub **Commits** 탭과 README |

구술 질문은 한 문항이다. 예: "이 버튼을 누르면 어느 파일이 실행됩니까?"

## 제출물

1. **발표 2분** — 2일차 수업 시간
2. **공개 주소** `https://<아이디>.github.io/my-web/`
3. **저장소 주소** `https://github.com/<아이디>/my-web`
4. **캡처 1장** — 저장소 첫 화면(README 5항목과 캡처 2장이 보이게)

## 제출 전 확인

- [ ] 새 시크릿 창에서 공개 주소를 열어 세 페이지가 모두 열린다.
- [ ] 버튼과 폼이 공개 주소에서 동작한다(내 PC의 `file://`이 아니라 공개 주소에서 확인한다).
- [ ] 저장소 첫 화면에 README가 보이고 캡처 링크가 눌러진다.
- [ ] `git status`가 clean이고 마지막 commit이 push되어 있다.
- [ ] 저장소·공개 페이지·캡처에 실명·학번·전화번호·실제 이메일이 없다.
- [ ] 2분 안에 끝나는지 한 번 재 보았다.

## 장애가 났을 때

- 공개 주소 반영이 5분 넘게 늦으면 로컬 화면과 GitHub **Commits** 탭을 같은 점수로 인정한다.
- 발표 중 인터넷이 끊기면 차례를 뒤로 미루고 뒤 순서에 다시 발표한다.
- 기능 하나가 동작하지 않으면 되는 것부터 보여 준다. 남은 시간에 원인을 말하면 시간 점수는 유지된다.
