# ex01 객체와 점 표기

`index.html`을 localhost에서 열어 이름을 입력하고 이름 적용을 누른다. 화면의 `item.name`은 입력값이고, 오타가 있는 `item.nmae`는 `undefined`다. Console에는 전체 객체도 표시된다.

필수 수정은 `app.js` 첫 객체의 `name` 값을 바꾸고 저장·새로고침하는 것이다. 화면 출력과 버튼 연결은 제공 코드다. `name: name`에서 왼쪽은 속성 이름, 오른쪽은 변수다.

화면 스타일은 [W3.CSS 4.1.0 CDN](https://cdnjs.cloudflare.com/ajax/libs/w3-css/4.1.0/w3.min.css)에서 읽는다.
