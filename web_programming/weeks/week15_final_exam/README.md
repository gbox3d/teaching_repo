# 15주차 — 기말 개인 실기

## 평가 목표

- 제한시간 안에 기존 코드를 읽고 지정 변경을 구현한다.
- JavaScript·비동기·Auth·CRUD·RLS의 흐름을 개인 언어로 설명한다.
- 정상·실패 시나리오를 재현하고 작은 현장 수정에 대응한다.
- 프로젝트 완성도를 다시 채점하지 않고 개인 구현·진단 역량을 확인한다.

## 1일차 — 요구 분석과 1차 구현

| 구간 | 내용 |
|---|---|
| 안내 30분 | 시험 규칙, starter 구조, 완료 조건, 제출·장애 절차 |
| 개인 실기 60분 | 요구 분석, JavaScript·DOM·비동기 변경, 중간 commit |

## 2일차 — 권한 구현과 시연

| 구간 | 내용 |
|---|---|
| 안내 30분 | 공통 오류 분류, RLS·실패 시나리오, 시연 방식 |
| 개인 실기·시연 60분 | Auth/CRUD/RLS 변경, 최종 제출, 지정 설명·현장 수정 |

분반 인원에 따라 시연은 2일차 일부와 별도 지정 시간 또는 짧은 화면 녹화를 병행한다. 모든 학생에게 같은 구현 시간과 설명 기회를 보장한다.
