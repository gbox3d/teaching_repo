# 15주차 — 기말 개인 실기

1~14주 문제은행으로 연습하고 같은 문제를 다른 값으로 푼다. 12~14주의 범위는 서버 방명록 GET·POST·PATCH·DELETE다. 14주 레포트 검사는 없으며 레포트는 별도 공지를 따른다.

## 학습 목표

1. 요구 화면과 HTTP 요청을 읽고 필요한 코드를 스스로 작성한다.
2. 브라우저 저장과 서버 저장을 구분하고 새로고침 뒤 결과를 확인한다.
3. HTTP 상태뿐 아니라 서버를 다시 읽은 결과로 구현을 확인한다.
4. 공개 주소·저장소·커밋 기록을 제출하고 자신의 코드 한 줄을 설명한다.

## 2일 수업 흐름

| 일차 | 설명 30분 | 실습·시험 60분 |
|---|---|---|
| 1일차 | 은행 구조, REST 시험 환경, 문항 읽기, 확인 방법 | 영역이 다른 세 문항 연습, REST 문항 한 개 이상 포함 |
| 2일차 | 배부 파일·개인별 API 공간·시험 규칙·제출 | A~E 다섯 문항, 구현과 구술 확인 |

## 준비

- VS Code·Chrome·Git·Node.js와 [정적 서버](../../tools/static-server/README.md)를 준비한다.
- 1일차에 새 저장소 `web-week15`와 Pages를 만든다.
- REST 연습은 [공용 API 안내](../../tools/guestbook-api/README.md)의 로컬 서버 또는 강의자가 제공한 HTTPS 서버를 사용한다.
- 시험 시작 전에 개인별 시험 방명록 번호와 초기 데이터를 확인한다. 편집 키는 별도 배부받고 실행 화면에만 입력한다.
- 허용 자료·실제 배점·제출 경로는 강의자 공지를 따른다.

## 범위와 평가

| 영역 | 배점(안) | 내용 |
|---|---:|---|
| A 화면 | 3 | HTML·CSS·9주 README |
| B DOM | 3 | 클릭 이벤트·화면 변경 |
| C 폼·목록 | 4 | 입력·목록·삭제 또는 POST 폼 연결 |
| D 브라우저 저장 | 2 | localStorage 저장·복원 |
| E REST | 3 | GET·POST 또는 PATCH·DELETE |
| URL 재현·구술 | 5 | 공개 URL에서 결과 재현 3, 코드 설명 2 |

합계는 20점 안이며 확정은 수업 공지에 따른다. 문항별로 배운 기능 하나를 구현하며 필요한 나머지 코드는 시작 파일로 제공한다. REST 문항은 서버 장애와 구현 오류를 구별한다. 한 문항이 C와 E에 중복 출제되지 않는다.

## 완료 기준

- [ ] 1일차에 영역이 다른 세 문항을 연습했다.
- [ ] 2일차에 받은 `exam/` 폴더가 저장소 맨 위에 있고 목차에서 다섯 문제가 열린다.
- [ ] REST 문항은 배부된 자기 시험 공간만 사용하고 요청 후 다시 읽어 확인했다.
- [ ] 공개 주소·저장소 주소·Commits 캡처를 제출했다.
- [ ] 구술에서 코드 한 줄의 역할을 설명했다.
- [ ] 편집 키와 개인정보를 코드·캡처에 넣지 않았다.

## 수업 이후

성적 확인이 끝날 때까지 저장소와 공개 주소를 유지한다. 제출 마감 뒤 코드를 바꾸지 않는다. REST 채점용 서버 데이터의 초기 상태와 변경 기록은 강의자가 별도 보존한다.
