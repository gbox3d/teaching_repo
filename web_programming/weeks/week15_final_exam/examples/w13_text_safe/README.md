# w13_text_safe — 입력한 글을 글자 그대로

출처: [13주차 실습 제출](../../../week13_release_security/lab.md#제출--캡처-한-장) · 권장 9분 · 기말 B(DOM)

13주차에는 방명록에 태그가 든 글을 남겨 글자 그대로 보이는지 확인했다. 이 문제의 게시판은 남기기·삭제·저장이 모두 동작한다. 그런데 입력한 글을 `innerHTML` 로 넣는 자리가 남아 있어서, 태그를 적으면 꾸민 글씨로 바뀐다. 그 자리를 모두 찾아 입력한 글이 글자 그대로 보이게 고친다.

## 시작 파일

| 파일 | 지금 상태 |
|---|---|
| `index.html` | 완성본이다. 위쪽 인사 자리 `#thanks`, 이름·메시지 폼, 마지막 글 자리 `#last`, 목록 `#list`, 개수 자리 `#count`, **[전체 지우기]** 버튼이 있다. 고치지 않는다 |
| `styles.css` | 완성본이다(좁은 화면용 `@media` 포함). 고치지 않는다 |
| `app.js` | 남기기·줄마다 **[삭제]**·**[전체 지우기]**·저장(키 `talk-board`)·새로고침 뒤 복원이 모두 된다. 입력한 글을 `innerHTML` 로 넣는 자리가 3곳 있다 |

## 할 일

`app.js` 만 고친다.

1. 먼저 지금 화면을 본다. 이름 `<b>student02</b>`, 메시지 `<b>안녕</b>` 로 한 줄을 남기고, 태그가 글자로 보이지 않고 꾸민 글씨로 바뀌는 자리를 찾는다.
2. 입력한 글(이름·메시지)을 `innerHTML` 로 넣는 3곳을 모두 찾아, 13주에 배운 대로 글자 그대로 넣게 바꾼다. 어느 줄인지는 직접 찾는다.
3. 목록을 비우는 `list.innerHTML = '';` 는 그대로 둔다. 입력한 글이 들어가지 않는 줄이다.
4. 줄마다 붙는 **[삭제]** 버튼은 그대로 있어야 한다. 남기기·삭제·저장·새로고침 뒤 복원도 지금처럼 동작해야 한다.

## 확인할 것

- [ ] **[전체 지우기]** 를 누른 뒤 이름 `guest03`·메시지 `첫 글이에요` 로 한 줄, 이어서 이름 `<b>student02</b>`·메시지 `<b>안녕</b>` 로 한 줄을 남긴다. 목록이 두 줄이고 줄마다 **[삭제]** 버튼이 하나씩 있다. 개수 자리는 `2개` 다.
- [ ] 목록 둘째 줄에 `<b>student02</b>: <b>안녕</b>` 가 태그까지 글자 그대로 보인다.
- [ ] 위쪽 인사 자리에 `<b>student02</b>님, 고맙습니다!` 가 글자 그대로 보인다.
- [ ] 마지막 글 자리에 `마지막 글: <b>안녕</b>` 가 글자 그대로 보인다.
- [ ] F12 › Console 에 `document.querySelectorAll('b').length` 를 치면 `0` 이 나온다.
- [ ] 새로고침해도 두 줄과 마지막 글 자리가 글자 그대로 보인다. F12 › Application › Local Storage 에서 `talk-board` 키의 값에 `<b>student02</b>`·`<b>안녕</b>` 가 태그째 들어 있다.
- [ ] F12 › 기기 모드 폭 `375` 에서 가로 스크롤이 생기지 않는다.
- [ ] 첫째 줄의 **[삭제]** 를 누르면 `<b>student02</b>: <b>안녕</b>` 한 줄만 남고 개수 자리는 `1개` 다. 새로고침해도 그 한 줄이 남는다.
- [ ] 위 순서를 하는 동안 F12 › Console 에 빨간 줄이 없다.

## 이 문제의 값

| 값 | 이 문제에서 |
|---|---|
| 페이지 제목(h1) | `이야기 게시판` |
| 저장 키 | `talk-board` |
| innerHTML 로 넣는 자리 수 | `3` |
| 첫 줄로 남길 글(이름 · 메시지) | `guest03` · `첫 글이에요` |
| 둘째 줄로 남길 시험 글(이름 · 메시지) | `<b>student02</b>` · `<b>안녕</b>` |
| Console 로 셀 태그 | `b` |
| 글자 모양(목록 한 줄 · 위쪽 인사 · 마지막 글) | `이름: 메시지` · `이름님, 고맙습니다!` · `마지막 글: 메시지` |
| 보여야 할 글자(목록 둘째 줄 · 위쪽 인사 · 마지막 글) | `<b>student02</b>: <b>안녕</b>` · `<b>student02</b>님, 고맙습니다!` · `마지막 글: <b>안녕</b>` |
| 확인 폭(px) | `375` |

시험에서는 같은 문제를 이 표의 값만 바꿔서 낸다. 문장·할 일·확인하는 방법은 그대로다.

## 받기와 올리기

- 이번 주 저장소(`web-week15`) 맨 위에 [server.mjs](../../../../tools/static-server/server.mjs) 가 없으면 먼저 **Raw** 로 받아 둔다.
- 저장소 안에 `w13_text_safe/` 폴더를 만든다. 교재의 이 문제 폴더에 있는 시작 파일을 하나씩 열어 **Raw** 를 누르고 Ctrl+S(macOS ⌘+S)로 같은 이름으로 저장한다. 그림도 Raw 를 누르면 그림만 보이는 화면이 열리고, 거기서 같은 방법으로 저장한다. 하위 폴더(그림·데이터)는 GitHub 에서 그 폴더를 눌러 들어가 받고, 내 폴더에도 같은 이름으로 만든다. 저장한 이름 끝에 `.txt` 가 붙었으면 지운다. 이 `README.md`(지금 읽는 문제 문장)는 받지 않는다.
- 저장소 맨 위에서 `node server.mjs` 로 열면 주소는 `http://localhost:8000/w13_text_safe/` 이다. Node 가 없는 PC 는 두 번 눌러 연다.
- `node server.mjs` 로 연 주소나 공개 주소에서는 `favicon.ico` 404 한 줄이 Console·Network 에 보여도 괜찮다(빨간 줄로 세지 않는다). 공개 주소에서 새로고침하면 Status 가 `304` 로 보일 수 있다. 이미 받은 파일을 다시 쓴다는 뜻이다.
- 올린 뒤 공개 주소는 `https://student01.github.io/web-week15/w13_text_safe/`이다.
- 해답은 공개하지 않는다. 위 "확인할 것"이 모두 맞으면 된 것이다.
