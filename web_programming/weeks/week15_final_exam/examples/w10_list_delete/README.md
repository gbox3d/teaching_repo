# w10_list_delete · 배열 추가와 삭제

출처: [10주](../../../week10_array_list/lab.md) · 권장 8분 · C 폼·목록 4점.

## 제공 파일

이름·메시지 폼과 showList()의 반복·화면 출력·삭제 버튼·개수·빈 목록 표시를 제공한다. W3.CSS는 cdnjs 4.1.0이며 보조 스타일은 shared/examples.css다. app.js만 수정한다.

## 할 일

- TODO ADD에서 이름: 메시지 문자열을 items 뒤에 추가한다.
- TODO DELETE에서 i 위치의 값 한 개를 삭제한다.

제공된 showList() 호출과 for 문을 다시 작성하지 않는다. 문자열 배열과 push·splice가 필수 범위다. map·filter·reduce는 출제하지 않는다.

## 확인할 것

student01: 안녕하세요, student02: 고맙습니다, student03: 반갑습니다 세 줄을 순서대로 등록한다. 가운데 삭제 후 첫째·셋째가 남고 개수가 2개다. 모두 삭제하면 0개와 빈 목록 안내가 나온다. 공백 입력은 등록되지 않는다. `<b>` 모양을 입력해도 태그가 아니라 글자로 나온다. 새로고침하면 목록이 사라지는 것이 이 문제의 동작이다.

폴더는 수업 전에 준비하고 정적 서버 http://localhost:8000/w10_list_delete/ 에서 확인한다. 1일차 업로드는 수업 뒤 진행한다. 실제 시험은 제공된 값으로 같은 두 기능을 작성한다.
