# w10_list_delete — 목록 쌓기와 줄마다 삭제

출처: [10주차 실습 제출](../../../week10_supabase_data/lab.md#제출--캡처-한-장) · 권장 11분 · 기말 C(폼·목록)

10주차에 만든 방명록 목록을 다른 값으로 다시 만든다. 남긴 글이 목록에 한 줄씩 쌓이고, 줄마다 붙은 버튼을 누르면 그 줄만 지워진다. 목록 아래에는 개수가 보이고, 목록이 비면 안내 문장이 보인다.

## 시작 파일

| 파일 | 지금 상태 |
|---|---|
| `index.html` | 완성본이다. 이름·메시지 폼, 빈 목록(`#list`), 빈 목록 안내(`#empty`), 개수 문단(`#count`)이 있다. 고치지 않는다 |
| `styles.css` | 완성본이다. 고치지 않는다 |
| `app.js` | 요소를 찾아 둔 줄, `let items = [];`, submit 리스너(새로고침 막기·빈칸 안내·폼 비우기)가 있다. `showList()` 는 비어 있고, submit 리스너 안에서 값을 넣을 자리는 주석 한 줄뿐이다. 마지막 줄은 `showList();` 다 |

## 할 일

`app.js` 만 고친다. `items` 는 이름과 `let` 을 그대로 둔다.

1. `showList()` 를 채운다. 부를 때마다 `items` 를 보고 목록을 처음부터 다시 그린다.
   - 목록 변수 `list`(`#list`)를 먼저 비운다.
   - `items` 를 처음부터 끝까지 돌며 값마다 `<li>` 를 만들어 `list` 에 붙인다. 글자는 입력한 그대로 보이게 넣는다(태그를 넣어도 글자로 보인다).
   - 줄마다 글자가 `삭제` 인 버튼을 그 `<li>` 안에 붙인다. 버튼을 누르면 그 줄의 값을 `items` 에서 하나 빼고 목록을 다시 그린다.
   - 개수 문단 변수 `count`(`#count`)에는 `N개` 꼴로 쓴다. N 은 `items` 에 든 값의 개수다.
   - `items` 가 비었으면 안내 문단 변수 `empty`(`#empty`)에 `아직 남긴 글이 없습니다.` 가 보이고, 한 줄이라도 있으면 안내가 보이지 않게 한다.
2. submit 리스너의 주석 자리에서 입력한 이름·메시지로 `이름: 메시지` 꼴의 한 줄을 만들어 `items` 맨 뒤에 넣고 `showList()` 를 부른다. 이름 `student01`, 메시지 `안녕하세요` 이면 `student01: 안녕하세요` 이다.

## 확인할 것

- [ ] 페이지를 열면 목록이 비어 있고 `아직 남긴 글이 없습니다.` 가 보인다. 개수는 `0개` 이다.
- [ ] 이름·메시지를 `student01`·`안녕하세요`, `student02`·`고맙습니다`, `student03`·`반갑습니다` 순서로 남기면 목록이 `student01: 안녕하세요`, `student02: 고맙습니다`, `student03: 반갑습니다` 세 줄이고 줄마다 **[삭제]** 버튼이 하나씩 있다. 개수는 `3개` 이고 `아직 남긴 글이 없습니다.` 는 보이지 않는다.
- [ ] 가운데 줄의 **[삭제]** 를 누르면 `student01: 안녕하세요`, `student03: 반갑습니다` 두 줄이 남고 개수는 `2개` 이다.
- [ ] 남은 두 줄도 지우면 목록이 비고 개수는 `0개` 이다. `아직 남긴 글이 없습니다.` 가 다시 보인다.
- [ ] 남기거나 지울 때마다 F12 › Console 에 `items.length` 를 치면 화면의 줄 수와 같다.
- [ ] 이어서 이름이 `student01`, 메시지가 `<b>굵게</b>` 인 글을 남기면 목록에 `student01: <b>굵게</b>` 한 줄이 태그까지 글자 그대로 보이고 개수는 `1개` 이다.
- [ ] F12 › Console 에 빨간 줄이 없다.

## 이 문제의 값

| 값 | 이 문제에서 |
|---|---|
| 페이지 제목(h1) | `방명록` |
| 목록 ul id | `list` |
| 빈 목록 안내 id | `empty` |
| 개수 문단 id | `count` |
| 한 줄 모양 | `이름: 메시지` |
| 버튼 글자 | `삭제` |
| 개수 문장(N = 개수) | `N개` |
| 빈 목록 안내 문장 | `아직 남긴 글이 없습니다.` |
| 확인 때 넣을 이름 셋 | `student01` · `student02` · `student03` |
| 확인 때 넣을 메시지 셋 | `안녕하세요` · `고맙습니다` · `반갑습니다` |
| 목록에 나올 세 줄 | `student01: 안녕하세요` · `student02: 고맙습니다` · `student03: 반갑습니다` |
| 태그 확인용 메시지 | `<b>굵게</b>` |

시험에서는 같은 문제를 이 표의 값만 바꿔서 낸다. 문장·할 일·확인하는 방법은 그대로다.

## 받기와 올리기

- 이번 주 저장소(`web-week15`) 맨 위에 [server.mjs](../../../../tools/static-server/server.mjs) 가 없으면 먼저 **Raw** 로 받아 둔다.
- 저장소 안에 `w10_list_delete/` 폴더를 만든다. 교재의 이 문제 폴더에 있는 시작 파일을 하나씩 열어 **Raw** 를 누르고 Ctrl+S(macOS ⌘+S)로 같은 이름으로 저장한다. 그림도 Raw 를 누르면 그림만 보이는 화면이 열리고, 거기서 같은 방법으로 저장한다. 하위 폴더(그림·데이터)는 GitHub 에서 그 폴더를 눌러 들어가 받고, 내 폴더에도 같은 이름으로 만든다. 저장한 이름 끝에 `.txt` 가 붙었으면 지운다. 이 `README.md`(지금 읽는 문제 문장)는 받지 않는다.
- 저장소 맨 위에서 `node server.mjs` 로 열면 주소는 `http://localhost:8000/w10_list_delete/` 이다. Node 가 없는 PC 는 두 번 눌러 연다.

- 올린 뒤 공개 주소는 `https://student01.github.io/web-week15/w10_list_delete/`이다.
- 해답은 공개하지 않는다. 위 "확인할 것"이 모두 맞으면 된 것이다.
