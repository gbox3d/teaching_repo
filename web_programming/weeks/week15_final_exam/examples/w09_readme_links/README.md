# w09_readme_links · README 링크

출처: [9주](../../../week09_readme_presentation/lab.md) · 권장 8분 · A 화면 3점.

## 제공 파일

9주의 홈·내 정보·방명록과 실행에 필요한 JS·CSS·이미지, 홈·방명록 캡처를 제공한다. 방명록은 작성자·시각·본문을 표시하고 새 글을 맨 위에 놓는다. 새로고침하면 글이 사라진다. 학생은 제공 화면을 확인하고 README를 작성한다.

이 파일은 문제 설명이다. 시험 배부 시 설명은 별도 제공하고 README.start.md를 학생 작업 폴더의 README.md로 복사한다. 시작 틀의 TODO를 채우며 다섯 절을 처음부터 타이핑하지 않는다.

## 할 일

- 제목을 나의 웹 연습장으로 바꾼다.
- 공개 주소에 자기 https://아이디.github.io/web-week15/w09_readme_links/ 링크를 넣는다.
- 페이지 절에 index.html·about.html·guestbook.html 상대 링크와 설명을 한 줄씩 넣는다.
- 기능 두 줄, 배운 것 세 줄을 실제 페이지 동작과 수업 내용으로 채운다.
- 화면 절에 screenshots/home.png·screenshots/guestbook.png 링크를 넣는다.

이번 문항은 제목·목록·링크만 평가한다. SVG·Mermaid·새 화면 캡처 제작은 필수가 아니다.

## 확인할 것

VS Code Markdown 미리보기에서 다섯 절과 페이지 링크 세 개·그림 링크 두 개를 확인한다. 공개 주소는 실제 시험 저장소로 바꾼다. 홈의 인사·다크 모드, 방명록 입력과 새로고침 시 초기화를 읽고 기능 설명과 비교한다. 수업 전 준비·수업 뒤 업로드는 [실습지](../../lab.md)를 따른다.
