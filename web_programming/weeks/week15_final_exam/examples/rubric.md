# 기말 개인 실기 루브릭

## 구현 15점

| 기준 | 점수 | 완전 충족 |
|---|---:|---|
| JavaScript·DOM·module | 4 | 요구 데이터 변환과 DOM 상태가 module 책임에 맞게 동작 |
| 비동기·오류 | 3 | loading, 성공, 실패와 retry가 재현됨 |
| Auth·session | 2 | 사용자 상태와 session 복구가 요구대로 동작 |
| CRUD·RLS | 5 | 지정 mutation과 owner/other 권한을 DB에서 강제·검증 |
| 제출·commit | 1 | 마감 압축본·SHA·실행 결과 일치 |

## 시연 5점

| 기준 | 점수 | 완전 충족 |
|---|---:|---|
| 정상·실패 시나리오 | 2 | 지정 장면을 재현하고 결과 증거 제시 |
| 흐름 설명 | 1.5 | 지정 함수·데이터·policy를 현재 코드에서 설명 |
| 현장 수정·디버깅 | 1.5 | 작은 변경을 수행하거나 오류 범위를 증거로 축소 |

## 공통 수준

- 100%: 요구가 재현되고 설명·증거 일치
- 75%: 핵심 동작, 작은 예외·표준 누락
- 50%: 핵심 일부 동작, 중요한 조건 누락
- 25%: 관련 시도 흔적, 실행 결과 검증 불가
- 0%: 미제출 또는 관련 구현 없음

RLS 누락이나 secret 노출은 해당 보안 기준을 0점 처리하고 즉시 수정하게 한다. 전체 답안을 자동 0점 처리하는 부정행위 판단과는 분리한다.
