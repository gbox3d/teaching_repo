# 15주차 문제은행 — 1~14주 누적

1~7주는 [8주 문제은행](../../week08_midterm/examples/README.md), 9~14주는 아래 새 문항을 사용한다. 현재 문항은 13개다. 이전 경로 `w12_fetch_cards`·`w13_text_safe`·`w14_readme_images`는 교체 안내만 남긴다.

| 영역 | 문항 | 출처 |
|---|---|---|
| A 화면 3점 | [w01_first_page](../../week08_midterm/examples/w01_first_page/) | 1주 |

| A 화면 3점 | [w09_readme_links](w09_readme_links/) | 9주 |
| B DOM 3점 | [w06_click_text](../../week08_midterm/examples/w06_click_text/) | 6주 |

시험은 A~E에서 한 문제씩 총 다섯 문제다. `w13_rest_post`를 C에 넣으면 E는 GET 또는 수정·삭제로 정하며, 같은 문항을 두 번 내지 않는다. 값만 바꿔 출제하고 해답은 비공개로 둔다. REST 문항의 서버·개인별 시험 공간·데이터·편집키는 강의자가 준비한다.
