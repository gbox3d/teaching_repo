# w13_rest_post — POST로 서버 방명록 저장

출처: [13주차 실습](../../../week13_release_security/lab.md) · 권장 12분 · 기말 C 폼·목록 또는 E REST

서버 설정은 강의자가 준비한다. 학생은 `app.js`의 TODO를 완성한다. 코드의 해답은 제공하지 않는다.

## 시작 파일

| 파일 | 상태 |
|---|---|
| `index.html`·`styles.css` | 화면·입력칸·버튼 제공 |
| `config.example.js` | 강의자 제공 API 주소·공개 키·BOOK_ID로 변경 |
| `view.js` | 화면 그리기 제공. 쓰기 문제에는 재조회 함수도 제공 |
| `app.js` | 이 문제의 요청 구현이 비어 있음 |

모든 파일을 같은 폴더에 두고 정적 서버로 연다. 로컬 연습 API는 [강의자 안내](../../../../tools/guestbook-api/README.md)를 따른다. 실제 시험은 개인별 시험 공간과 준비된 데이터를 사용한다.

## 할 일

1. 빈 별칭이나 메시지이면 요청을 보내지 않는다.
2. `/rest/v1/guestbook`에 POST한다. `apikey`, `Content-Type: application/json`, `Prefer: return=representation` 헤더를 넣는다.
3. 본문에는 자기 `book_id`, 입력한 `name`, `message`를 JSON으로 보낸다.
4. 성공 후 GET으로 다시 읽어 목록을 갱신한다. 실패하면 입력값을 유지하고 안내한다.

## 확인할 것

- [ ] 공백만 있는 입력으로는 글이 추가되지 않는다.
- [ ] Network에서 POST의 JSON 본문과 201 응답을 확인한다.
- [ ] 지정한 별칭·메시지가 GET 목록에 표시되고 새로고침 후에도 남는다.
- [ ] 요청 실패 때 저장 완료라고 표시하지 않는다.

## 이 문제의 값

| 값 | 연습값 |
|---|---|
| API 주소 | 로컬 `http://127.0.0.1:8787`, 공용 실습은 강의자 제공 HTTPS 주소 |
| 공개 키 | 로컬 `classroom-local`, 공용 실습은 강의자 제공 publishable key |
| 방명록 번호 | `student01` (시험은 개인별 배부값) |
| 별칭 | `연습별칭` |
| 메시지 또는 수정 메시지 | `REST 연습 중입니다.` |
| 대상 ID | 자기 방명록 GET 응답에서 확인한 ID; 수정·삭제 문제는 서로 다른 두 ID |
| 편집 키 | 14주 문항에서만 강의자가 별도 배부; 파일에 기록하지 않음 |

시험에서는 위 값과 대상 글이 바뀐다. 시험값·편집 키·해답은 이 공개 문제은행에 넣지 않는다.

## 받기와 올리기

연습 폴더는 `web-week15/w13_rest_post/`다. add·commit·push 후 Pages에서 확인한다. 공개 페이지는 공용 HTTPS API를 사용해야 한다. 로컬 리허설 주소를 그대로 올려 다른 PC에서 동작한다고 판단하지 않는다.
