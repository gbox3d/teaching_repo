# w11_local_storage — 새로고침해도 남는 목록

출처: [11주차 실습 제출](../../../week11_auth_rls/lab.md#제출--캡처-한-장) · 권장 10분 · 기말 D(저장(localStorage))

11주차 방명록처럼 목록을 브라우저 저장 칸(localStorage)에 남긴다. 시작 파일은 항목 추가·줄마다 삭제·개수 문장까지 되지만 새로고침하면 목록이 사라진다. 저장·되살리기·모두 지우기를 붙여 새로고침해도 목록이 남게 한다.

## 시작 파일

| 파일 | 지금 상태 |
|---|---|
| `index.html` | 완성본이다. 칸 둘(`제목`·`내용`)과 **[추가]** 버튼이 있는 폼, 목록(`#memos`), 개수 문단(`#memo-count`), **[모두 지우기]** 버튼(`#clear-memos`)이 있다. 고치지 않는다 |
| `styles.css` | 완성본이다. 고치지 않는다 |
| `app.js` | 항목 추가, 목록 그리기 `showList()`, 줄마다 **[삭제]**, 개수 문장은 된다. 항목은 `{ title: …, memo: … }` 꼴의 객체다. `saveList()` 는 비어 있고 고칠 곳마다 `// 할 일` 주석이 있다 |

## 할 일

`app.js` 만 고친다. 저장 키는 `'memo-list'` 하나다.

1. `saveList()` 안에서 배열 `items` 전체를 JSON 문자열로 바꿔 `'memo-list'` 키에 저장한다.
2. 항목을 추가한 뒤와 삭제한 뒤, 두 곳에서 `saveList()` 를 부른다. 배열이 바뀐 다음에 부른다.
3. `let items = [];` 줄을 고쳐 페이지를 열 때 `'memo-list'` 키에 저장된 목록으로 시작하게 한다. 저장된 값이 없으면 빈 배열로 시작하고, 이때도 Console 에 빨간 줄이 없어야 한다.
4. **[모두 지우기]** 버튼을 누르면 배열을 비우고, `'memo-list'` 키 하나만 지우고, 목록을 다시 그린다. 다른 키는 지우지 않는다. 같은 아이디의 `github.io` 페이지는 저장 칸을 함께 쓴다.

## 확인할 것

- [ ] F12 › Application › Local Storage 에서 지금 주소를 고르고 `memo-list` 키를 지운다(없으면 그대로). 새로고침하면 목록이 비어 있고 `저장된 메모가 없습니다.` 가 보인다. Console 에 빨간 줄이 없다.
- [ ] 항목 셋(`장보기`·`우유 사기`, `과제`·`보고서 제출`, `운동`·`저녁 산책`)을 차례로 추가하고 새로고침해도 세 줄(`장보기: 우유 사기` · `과제: 보고서 제출` · `운동: 저녁 산책`)과 개수 문장(`메모 3개`)이 그대로 보인다.
- [ ] Application › Local Storage 에서 `memo-list` 키의 값이 `[{"title":"장보기","memo":"우유 사기"},{"title":"과제","memo":"보고서 제출"},{"title":"운동","memo":"저녁 산책"}]` 이다.
- [ ] 둘째 줄의 **[삭제]** 를 누르고 새로고침하면 두 줄(`장보기: 우유 사기` · `운동: 저녁 산책`)과 개수 문장(`메모 2개`)만 보인다. 저장 값은 `[{"title":"장보기","memo":"우유 사기"},{"title":"운동","memo":"저녁 산책"}]` 이다.
- [ ] Application › Local Storage 표의 빈 줄을 두 번 눌러 키 `other-key`, 값 `keep` 을 하나 만든다. 그다음 **[모두 지우기]** 를 누르면 목록이 바로 비고 `저장된 메모가 없습니다.` 가 보인다. `memo-list` 키는 사라지고 `other-key` 는 남는다. 새로고침해도 목록은 비어 있다.
- [ ] 위 순서를 하는 동안 F12 › Console 에 빨간 줄이 없다.

## 이 문제의 값

| 값 | 이 문제에서 |
|---|---|
| 저장 키 | `memo-list` |
| 객체 이름표(첫 칸 · 둘째 칸) | `title` · `memo` |
| 칸 이름표 글자(첫 칸 · 둘째 칸) | `제목` · `내용` |
| id(폼 · 첫 칸 · 둘째 칸) | `memo-form` · `title-input` · `memo-input` |
| id(목록 · 개수 문단 · 지우기 버튼) | `memos` · `memo-count` · `clear-memos` |
| 버튼 글자(추가 · 지우기) | `추가` · `모두 지우기` |
| 페이지 제목 | `메모장` |
| 빈칸 안내 문장 | `제목과 내용을 모두 입력하세요.` |
| 빈 목록 문장 | `저장된 메모가 없습니다.` |
| 개수 문장 | `메모 ${items.length}개` |
| 확인 입력 셋(목록 한 줄 모양) | `장보기: 우유 사기` · `과제: 보고서 제출` · `운동: 저녁 산책` |

시험에서는 같은 문제를 이 표의 값만 바꿔서 낸다. 문장·할 일·확인하는 방법은 그대로다.

## 받기와 올리기

- 이번 주 저장소(`web-week15`) 맨 위에 [server.mjs](../../../../tools/static-server/server.mjs) 가 없으면 먼저 **Raw** 로 받아 둔다.
- 저장소 안에 `w11_local_storage/` 폴더를 만든다. 교재의 이 문제 폴더에 있는 시작 파일을 하나씩 열어 **Raw** 를 누르고 Ctrl+S(macOS ⌘+S)로 같은 이름으로 저장한다. 그림도 Raw 를 누르면 그림만 보이는 화면이 열리고, 거기서 같은 방법으로 저장한다. 하위 폴더(그림·데이터)는 GitHub 에서 그 폴더를 눌러 들어가 받고, 내 폴더에도 같은 이름으로 만든다. 저장한 이름 끝에 `.txt` 가 붙었으면 지운다. 이 `README.md`(지금 읽는 문제 문장)는 받지 않는다.
- 저장소 맨 위에서 `node server.mjs` 로 열면 주소는 `http://localhost:8000/w11_local_storage/` 이다. Node 가 없는 PC 는 두 번 눌러 연다.
- `node server.mjs` 로 연 주소나 공개 주소에서는 `favicon.ico` 404 한 줄이 Console·Network 에 보여도 괜찮다(빨간 줄로 세지 않는다). 공개 주소에서 새로고침하면 Status 가 `304` 로 보일 수 있다. 이미 받은 파일을 다시 쓴다는 뜻이다.
- 올린 뒤 공개 주소는 `https://student01.github.io/web-week15/w11_local_storage/`이다.
- 해답은 공개하지 않는다. 위 "확인할 것"이 모두 맞으면 된 것이다.
