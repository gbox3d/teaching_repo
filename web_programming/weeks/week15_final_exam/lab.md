# 15주차 개인 실기 진행지

이 문서는 실제 시험 문제가 아니라 학생이 제한시간 작업을 관리하기 위한 공통 진행지다.

## 1일차

### 1. baseline — 5분

- [ ] starter 버전 확인
- [ ] 로컬 실행
- [ ] Console/Network 초기 상태 기록
- [ ] git status 확인

### 2. 요구 분해 — 10분

| 요구 | 입력 | 기대 결과 | 실패·경계 | 수정 파일 | 검증 |
|---|---|---|---|---|---|
| A |  |  |  |  |  |
| B |  |  |  |  |  |
| C |  |  |  |  |  |

### 3. 구현 — 35분

- [ ] 핵심 정상 흐름
- [ ] validation
- [ ] 비동기 loading/error
- [ ] 작은 단위 실행 확인

### 4. 중간 검증·commit — 10분

- [ ] 실행 가능한 상태
- [ ] 실패 항목과 증거 기록
- [ ] 중간 commit SHA

## 2일차

### 1. 기준 복구 — 5분

- [ ] 중간 commit에서 실행
- [ ] 남은 요구 우선순위

### 2. 구현·권한 — 30분

- [ ] Auth/session
- [ ] CRUD
- [ ] owner/other RLS
- [ ] 실패 뒤 DB 불변

### 3. 최종 검증·제출 — 10분

- [ ] 정상 시나리오
- [ ] 실패 시나리오
- [ ] git status/diff
- [ ] 최종 commit SHA
- [ ] 압축본과 LMS 제출

### 4. 시연 — 분반별 지정

- [ ] 지정 정상·실패 장면
- [ ] 함수·데이터·policy 설명
- [ ] 작은 현장 수정 또는 디버깅

## 장애 발생 시

즉시 손을 들고 시간과 증상을 감독 확인받는다. 임의로 다른 계정·장비·외부 도움을 사용하지 않는다.
