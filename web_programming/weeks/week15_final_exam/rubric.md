# 기말 개인 실기 채점표 — 20점

실습 페이지: https://github.com/gbox3d/teaching_repo/tree/main/web_programming/weeks/week15_final_exam

> 배점은 강의계획 비중 승인 전까지 **안**이다. 확정 공지는 수업 공지를 따른다.
> 13주차 2일차에 이 문서와 [공개 starter](examples/rehearsal_starter)를 함께 공개했다. 실제 시험 문항과 값은 여기에 없다.

## 구현 15점

| 항목 | 배점 | 완전 충족 |
|---|---:|---|
| HTML·CSS | 3 | 문항이 지정한 자리에 태그를 넣고, 색·`flex`·`@media` 중 지정한 것을 고쳤다. 375px에서 가로로 넘치지 않는다 |
| DOM 이벤트 | 3 | 버튼 클릭으로 글자나 class가 바뀐다(`textContent`·`classList`). Console 오류가 없다 |
| 폼·목록 추가·삭제 | 4 | 빈값이면 안내 문구가 나오고, 값이 있으면 목록에 한 줄이 늘고, [지우기]로 그 줄만 사라진다 |
| localStorage | 2 | 새로고침해도 목록이 남는다. 키 이름이 문항이 지정한 것과 같다 |
| fetch·오류 안내 | 3 | 공개 주소에서 JSON을 불러와 목록으로 그린다. 못 찾았을 때의 안내 문구 처리(`if (!response.ok)` 또는 `catch`)가 제출 코드에 있고 화면이 멈추지 않는다 |

## 시연 5점

| 항목 | 배점 | 완전 충족 |
|---|---:|---|
| URL 재현 | 3 | 채점자가 제출한 공개 주소를 열어 위 기능이 그대로 동작한다 |
| 구술 | 2 | 시험 후반 좌석 순회에서 지정한 한 줄이 하는 일을 본인 코드에서 설명한다(1분) |

## 수준별 공통 판단

| 수준 | 뜻 |
|---|---|
| 100% | 요구한 동작이 공개 주소에서 그대로 재현되고 설명과 화면이 일치한다 |
| 75% | 핵심 동작이 되고 작은 예외(안내 문구 누락, 좁은 화면 넘침 등)만 남았다 |
| 50% | 핵심의 일부만 동작한다. 예를 들어 추가는 되는데 삭제가 안 된다 |
| 25% | 관련 코드를 쓴 흔적이 있으나 실행 결과로 확인되지 않는다 |
| 0% | 미제출이거나 해당 항목과 관련 없는 결과다 |

## 감점 적용 원칙

- 원인이 하나인데 증상이 여러 개면 중복 감점하지 않고 한 항목에서만 깎는다.
- 항목별 최대 배점을 넘겨 깎지 않는다.
- 화면이 덜 예쁜 것과 기능이 안 되는 것을 같은 수준으로 보지 않는다.
- 제출 장애(Pages 지연·자격 증명 충돌)는 학생의 구현 오류와 기록상 구분한다.
- **구현 시도 흔적이 있으면 구현 15점에서 최소 5점을 준다**(강의자 공지로 확정). 미제출에는 적용하지 않는다.
- 실명·학번·전화번호·실제 이메일이 공개 페이지나 캡처에 있으면 점수와 별개로 즉시 고치게 한다.

## 장애 대체

| 상황 | 대체 |
|---|---|
| Pages 반영이 5분 넘게 늦다 | 로컬 화면 캡처 + 마지막 commit 번호(SHA)로 인정한다. 채점자는 다음 날 공개 주소를 다시 연다 |
| 공용 PC의 자격 증명 충돌로 push가 막힌다 | 자격 증명 관리자에서 `git:https://github.com`을 지우고 다시 로그인한다. 그래도 막히면 폴더를 압축해 제출하고 감독이 시각을 기록한다 |
| 네트워크·GitHub 자체가 끊겼다 | 그때에 한해 `fetch` 문항을 `app.js` 안의 배열로 대체 구현해도 같은 배점으로 채점한다. 로컬 미리보기 수단이 없다는 것만으로는 대체하지 않는다 |
| 개인 PC 고장 | 손을 들어 감독 확인을 받고 예비 PC에서 `git clone`으로 이어 간다 |

## 제출 세 가지

1. 공개 주소 `https://<아이디>.github.io/web-final/`
2. 저장소 주소 `https://github.com/<아이디>/web-final`
3. 마지막 commit 번호 — `git log -1 --format=%H` 출력

캡처 1장(주소창이 보이는 완성 화면)을 함께 낸다. 제출 위치와 마감은 수업 공지를 따른다.
