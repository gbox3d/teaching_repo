# 기말 개인 실기 채점표 — 20점 안

배점은 승인 전 안이며 확정은 수업 공지를 따른다. 공개 주소·저장소 `exam/`·코드 설명을 확인한다. 문제 조합·시험값·해답·편집 키는 공개하지 않는다.

## 구현 15점

| 영역 | 배점 | 문항 후보 | 확인 |
|---|---:|---|---|
| A 화면 | 3 | w01·w02·w03·w04·w05·w09 | HTML·CSS·링크·README |
| B DOM | 3 | w06_click_text | 버튼과 화면 변경 |
| C 폼·목록 | 4 | w07_form_line·w10_list_delete·w13_rest_post | 입력 검증·목록 또는 POST 저장 |
| D 브라우저 저장 | 2 | w11_local_storage | localStorage 저장·복원 |
| E REST | 3 | w12_rest_get·w13_rest_post·w14_rest_edit | HTTP 요청과 서버 결과 재조회 |
| 합계 | 15 | | |

A~E에서 한 문제씩 다섯 문제를 낸다. POST를 C에 냈으면 E에는 다른 문항을 낸다. 동일 기능을 중복 채점하지 않는다. 같은 결과를 내는 다른 표준 API 사용도 인정한다. 문제의 확인할 것을 전부 충족하면 해당 배점 전부, 일부면 충족한 부분만, 실행되지 않거나 관련 없는 결과면 0점으로 본다.

REST는 GET 응답·POST 후 저장된 값·PATCH 후 수정값·DELETE 후 부재를 확인한다. HTTP 200·201·204만으로 전체 점수를 주지 않는다. 204 뒤 JSON 파싱 오류, 빈 PATCH 배열을 성공이라고 표시하는 경우는 해당 확인 항목에서 판정한다.

## URL 재현과 구술 5점

| 항목 | 배점 | 확인 |
|---|---:|---|
| URL 재현 | 3 | 새 창에서 공개 목차와 다섯 문항이 열리고 요구 동작을 재현한다 |
| 구술 | 2 | 본인 코드 한 줄이 요청·응답·화면에서 하는 일을 설명한다 |

구현에서 판정한 같은 결함을 URL 재현에서 다시 감점하지 않는다. 구술 1분은 그 학생의 마감에서 보정한다. 편집 키는 채점자가 별도로 보관한 값을 입력한다. 소스 제출에 키가 없어야 한다.

## 서버와 시험 데이터

- 학생별 시험 공간과 초기 글을 시험 전에 준비한다. 실습 공간을 재사용하지 않는다.
- 채점 전에 초기 상태와 학생의 제출 시점 결과를 별도 보존한다. 채점 재현은 복제한 데이터로 진행해 제출 결과를 훼손하지 않는다.
- 시험용 API 주소와 공개 키는 시작 파일로 제공하고 편집 키는 따로 배부한다.
- API 장애는 구현 오류로 감점하지 않는다. 동일 계약·데이터의 로컬 대체 서버와 시간 보정을 사용한다. 대체 환경이 없으면 REST 영역 평가를 보류한다.
- Pages 지연은 로컬 화면·Commits 시각을 기록한 뒤 공개 주소를 다시 확인한다.

## 하한과 운영값

구현 시도만으로 최소 5점을 보장하는 규칙은 이 채점표에서 확정하지 않는다. 적용 여부·허용 자료·제출 기한·실제 배점은 강의자 공지로 정한다. 14주 레포트·발표 배점은 이 기말 채점표와 무관하다.
