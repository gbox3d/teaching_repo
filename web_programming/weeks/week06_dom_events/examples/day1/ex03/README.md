# ex03 클릭 횟수: 변수는 함수 밖에

[index.html](index.html)을 연다. [styles.css](styles.css)는 모양, [app.js](app.js)는 동작이다. 별도 설치나 외부 CSS가 없다.

버튼을 세 번 누르면 화면은 `클릭 3회`다. 함수 밖 count는 1·2·3, 함수 안 inside는 매번 1이다. 새로고침하면 0회다. 필수 실습은 `app.start.js`를 개인 사본의 `app.js`로 복사하고 주석 자리에 여섯 줄을 작성한다. 제공 app.js의 inside 비교와 로그는 강의자 시연이다.

실습 범위와 시간은 [주차 실습지](../../../lab.md)를 따른다.
