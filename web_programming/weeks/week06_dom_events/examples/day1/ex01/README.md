# ex01 HTML 파일과 DOM

[index.html](index.html)을 연다. [styles.css](styles.css)는 모양, [app.js](app.js)는 동작이다. 별도 설치나 외부 CSS가 없다.

화면의 `#message`는 JS 실행 뒤의 글자다. Elements에서 같은 글자를 확인하고 페이지 소스의 원래 글자와 비교한다. Elements에서 임시로 고친 글자는 새로고침하면 사라진다. `#message`를 잘못 쓰면 `null`을 얻고 textContent 대입에서 오류가 난다.

실습 범위와 시간은 [주차 실습지](../../../lab.md)를 따른다.
