# ex04 classList: class 를 붙이고 떼기

[index.html](index.html)을 연다. [styles.css](styles.css)는 모양, [app.js](app.js)는 동작이다. 별도 설치나 외부 CSS가 없다.

add를 두 번 눌러도 on은 하나다. remove를 두 번 눌러도 없는 상태를 유지한다. toggle은 누를 때마다 on을 붙이거나 뗀다. Elements의 class와 노란 배경을 비교한다. classList에는 점 없는 on을 쓰고 CSS에서는 .on을 쓴다.

실습 범위와 시간은 [주차 실습지](../../../lab.md)를 따른다.
