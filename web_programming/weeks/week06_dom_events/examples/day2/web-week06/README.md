# 6주차 개인 홈 완성본

[index.html](index.html)은 5주 인사말과 개인 소개를 이어 쓰며 두 버튼과 횟수 카드를 추가한다. [styles.css](styles.css)는 자체 CSS이며 어두운 모드의 제목·메뉴·푸터 색도 지정한다. [app.js](app.js)는 완성 비교본이다.

수업 전 개인 사본에서 [app.start.js](app.start.js)를 app.js로 복사한다. HTML·선택자·greet·hello·countUp·리스너 틀은 제공하며 학생은 TODO 세 줄과 CSS 색 두 값만 작성한다. [실습지](../../../lab.md)의 2차시 30분 순서를 따른다. 시작 틀을 추가 script로 연결하지 않는다.

인사·다크·인사 클릭은 3회, 다크 버튼을 다시 누르면 4회와 밝은 화면이다. 새로고침은 초기 인사·0회·밝은 화면으로 돌아간다. 375px·1280px에서 버튼과 제목·메뉴·푸터를 확인한다.

[about.html](about.html)과 [guestbook.html](guestbook.html)은 5주에서 이어 쓴다. 정적 방명록의 잘못된 이메일은 브라우저가 막고, 유효한 입력은 같은 페이지로 GET 탐색한다. 입력 name 속성이 없으므로 값은 URL이나 저장소에 남지 않는다. 이 과정은 글 등록 기능이 아니다.

7주는 이 폴더의 홈·소개를 유지하고 방명록을 W3.CSS로 바꾼다. 입력 검사·글 추가는 7주 제공 JS로 연결하며 JavaScript가 쓰는 ID를 보존한다.
