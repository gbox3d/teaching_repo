# ex05 다크 모드: body 에 class 하나

[index.html](index.html)을 연다. [styles.css](styles.css)는 모양, [app.js](app.js)는 동작이다. 별도 설치나 외부 CSS가 없다.

다크 모드를 누르면 body의 dark 클래스가 바뀐다. CSS의 body.dark는 배경·상속 글자색, body.dark .card는 카드 배경을 정한다. 카드 규칙을 임시로 지우면 카드만 흰색으로 남으므로 비교 뒤 복원한다. 제목이나 링크가 자기 color를 갖는 개인 홈에서는 별도 어두운 모드 규칙이 필요하다.

실습 범위와 시간은 [주차 실습지](../../../lab.md)를 따른다.
