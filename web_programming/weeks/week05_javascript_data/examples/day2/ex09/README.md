# ex09 강의자 시연

[index.html](index.html)을 열고 버튼을 누른다. [app.js](app.js)에서 값을 수정한 뒤 저장·새로고침한다. Console은 코드 실행과 오류를 확인하는 보조 도구다.

## 원리와 기대 결과

querySelector로 요소를 찾고 textContent로 글자를 바꾼다.

버튼 뒤 1·2번은 변경 완료, 3번은 <b>까지 글자 그대로, 입력 값은 value 변경 완료다.

## 수정과 비교

없는 #out9의 textContent를 쓰면 null 오류가 난다. 추가한 줄을 지우면 복구된다. getElementById와 innerText는 선택 비교이며 필수 구현·평가에서 제외한다. 두 방식이 일반적으로 항상 같은 것은 아니다. 출력 1곳의 필수 수정은 시작 app.js에서 한다.

화면 출력과 버튼 연결은 제공 코드다. 학생이 새로 구현하지 않는다. 전체 필수 수정량은 [실습지](../../../lab.md)에 따른다.
