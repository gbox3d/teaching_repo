# ex07 강의자 시연

[index.html](index.html)을 열고 버튼을 누른다. [app.js](app.js)에서 값을 수정한 뒤 저장·새로고침한다. Console은 코드 실행과 오류를 확인하는 보조 도구다.

## 원리와 기대 결과

if 사슬은 처음 참인 갈래 하나만 실행한다.

20시는 오후/오후/저녁/오후, 9시는 (담긴 것 없음)/오전/아침/아침이다.

## 수정과 비교

hour를 9·12·15·20으로 바꾼다. 12·15시는 모두 오후다. 4번은 >=12를 먼저 검사해 >=18 갈래에 도달하지 못한다. 조건 1곳의 필수 수정은 시작 app.js에서 한다.

화면 출력과 버튼 연결은 제공 코드다. 학생이 새로 구현하지 않는다. 전체 필수 수정량은 [실습지](../../../lab.md)에 따른다.
