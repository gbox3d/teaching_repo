# ex10 강의자 시연·선택

[index.html](index.html)을 열고 버튼을 누른다. [app.js](app.js)에서 값을 수정한 뒤 저장·새로고침한다. Console은 코드 실행과 오류를 확인하는 보조 도구다.

## 원리와 기대 결과

new Date()는 실행 순간을 담고 getHours()는 0~23시를 반환한다.

출력 버튼은 페이지를 읽을 때 담은 날짜·시각을 보여 준다. 다시 재려면 새로고침한다.

## 수정과 비교

Console은 시·분·연도·0부터 센 월·월+1·요일을 출력한다. getDay()의 0은 일요일이다. 날짜 함수 추가는 선택이다.

화면 출력과 버튼 연결은 제공 코드다. 학생이 새로 구현하지 않는다. 전체 필수 수정량은 [실습지](../../../lab.md)에 따른다.
