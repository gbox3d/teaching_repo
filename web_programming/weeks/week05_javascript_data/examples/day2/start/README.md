# 2일차 제공 시작 파일

수업 전에 4주 완성 폴더를 `web-week05`로 준비하고, 이 `app.js`를 맨 위에 배치한다. 기존 카운터 코드는 이 파일로 교체한다. 홈의 `<head>`에 `<script src="app.js" defer></script>`, `<main>` 첫 줄에 `<div class="card" id="greeting">인사말을 준비 중입니다.</div>`도 강의자가 미리 넣는다.

학생은 `greet`의 반환 문장, `hello`의 조건, 마지막 출력 줄의 세 곳만 수정한다. 날짜·변수·함수 호출·로그는 제공 코드다. 상세 순서는 [실습지](../../../lab.md#2일차-30분-실습)에 있다. 이 폴더는 교체용 JS만 제공하며 독립 웹 페이지가 아니다.
