# ex06 강의자 시연·선택

[index.html](index.html)을 열고 버튼을 누른다. [app.js](app.js)에서 값을 수정한 뒤 저장·새로고침한다. Console은 코드 실행과 오류를 확인하는 보조 도구다.

## 원리와 기대 결과

===는 타입과 값이 같아야 참이다. >=는 같은 수도 포함한다.

결과 순서는 true·false·true·false·false·true다.

## 수정과 비교

12 > 12를 12 > 11로 비교한다. ==와 문자열 사전식 비교는 선택이며 필수 구현·평가에서 제외한다. ==는 필요한 타입 변환 뒤 비교하므로 단순히 값만 비교한다고 일반화하지 않는다.

화면 출력과 버튼 연결은 제공 코드다. 학생이 새로 구현하지 않는다. 전체 필수 수정량은 [실습지](../../../lab.md)에 따른다.
