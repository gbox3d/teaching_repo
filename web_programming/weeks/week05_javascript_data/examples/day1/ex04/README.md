# ex04 강의자 시연·선택

[index.html](index.html)을 열고 버튼을 누른다. [app.js](app.js)에서 값을 수정한 뒤 저장·새로고침한다. Console은 코드 실행과 오류를 확인하는 보조 도구다.

## 원리와 기대 결과

입력 value는 문자열이다. +는 숫자끼리 더하고 문자열이 있으면 연결한다.

입력 1·2는 문자열 연결 12, 숫자 덧셈 3이다. 입력 10·5는 105와 15다.

## 수정과 비교

Console의 1~5번 식도 비교한다. parseInt('12px')는 12, Number('12px')는 NaN이다. parseInt 비교는 선택이며 필수 구현·평가에서 제외한다. 빈 문자열을 Number로 바꾸면 0이다.

화면 출력과 버튼 연결은 제공 코드다. 학생이 새로 구현하지 않는다. 전체 필수 수정량은 [실습지](../../../lab.md)에 따른다.
