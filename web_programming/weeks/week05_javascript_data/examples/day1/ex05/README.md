# ex05 1일차 필수

[index.html](index.html)을 열고 버튼을 누른다. [app.js](app.js)에서 값을 수정한 뒤 저장·새로고침한다. Console은 코드 실행과 오류를 확인하는 보조 도구다.

## 원리와 기대 결과

백틱의 ${}는 식을 계산한다. 작은따옴표의 ${}는 글자 그대로다.

출력 버튼을 누르면 안녕하세요, student01님! 지금은 9시입니다.가 나온다.

## 수정과 비교

name을 student02, hour를 15로 수정하면 출력은 student02와 15시다. Console의 작은따옴표 예제는 ${name} 그대로이며 한 시간 뒤는 16시다.

화면 출력과 버튼 연결은 제공 코드다. 학생이 새로 구현하지 않는다. 전체 필수 수정량은 [실습지](../../../lab.md)에 따른다.
