# 14주차 발표 실습

## 1일차 60분 — rehearsal

### 1단계: 5분 시나리오 작성 — 10분

examples/demo_outline.md를 복사해 화면·발화·증거를 한 줄씩 적는다.

### 2단계: 첫 발표 녹화 — 10분

중단 없이 녹화하고 실제 시간을 기록한다. 실패해도 다시 시작하지 않는다.

### 3단계: 자기 점검 — 10분

- 30초 안에 문제와 사용자가 보였는가?
- row를 즉석에서 만들었는가?
- A/B 권한을 DB 증거로 보였는가?
- 실패 상태와 focus를 조작했는가?
- 시간이 넘었는가?

### 4단계: 짝 rehearsal — 20분

각자 5분 발표 + 3분 질문을 수행한다. 동료는 점수를 주지 않고 질문·시간·재현 실패만 기록한다.

### 5단계: 수정 녹화 — 10분

불필요한 화면 이동을 줄이고 최종 사전 영상을 만든다.
