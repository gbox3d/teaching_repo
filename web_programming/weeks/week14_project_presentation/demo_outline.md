# 3분 시연 흐름 표

발표 순서를 미리 적어 두는 종이다. 아래는 예시이며, **말할 것** 칸은 본인 사이트의 문장으로 바꾼다.
화면은 공개 주소 `https://student01.github.io/my-web/`에서만 연다. 코드 파일은 띄우지 않는다.

| 시간 | 화면·동작 | 말할 것 |
|---|---|---|
| 0:00–0:20 | 공개 주소를 열어 홈을 보인다 | "`student01`의 웹 연습장입니다. 네 페이지가 있고, 방명록에 남긴 글이 새로고침해도 남습니다." |
| 0:20–0:40 | nav로 홈 → 내 정보 → 방명록 → 프로젝트 → 홈 | "메뉴 네 개로 오갑니다. 내 정보 표 맨 아래에 이 공개 주소를 적어 두었습니다." |
| 0:40–0:55 | 홈에서 **[다크 모드]**를 누른다 | "버튼을 누르면 배경색이 바뀌고 클릭 횟수가 1씩 오릅니다." |
| 0:55–1:15 | 방명록에서 칸을 비운 채 **[남기기]** | "이름이나 메시지가 비면 저장하지 않고 안내 문장을 보여 줍니다." |
| 1:15–1:45 | 이름·메시지를 넣고 **[남기기]**, 한 줄을 **[삭제]** | "남기면 목록에 쌓이고 개수가 늘어납니다. 삭제를 누르면 그 줄만 빠집니다." |
| 1:45–2:05 | 같은 페이지를 **새로고침**한다 | "새로고침해도 목록이 그대로입니다. 글이 브라우저에 저장되기 때문입니다." |
| 2:05–2:35 | 프로젝트 페이지를 연다 | "카드 세 장은 제가 쓴 `data/projects.json` 파일을 불러와 그린 것입니다." |
| 2:35–3:00 | GitHub **Commits** 탭과 저장소 첫 화면의 README | "한 학기 동안 이만큼 나누어 만들었습니다. 설명은 README에 있습니다." |

## 쓰는 법

1. 이 표를 종이에 옮겨 적거나 새 문서로 복사한다. 저장소에 넣지 않아도 된다.
2. **말할 것** 칸을 본인 문장으로 바꾼다. 한 칸에 한 문장이면 충분하다.
3. 시계를 보며 한 번 읽어 본다. 넘치면 0:20–0:40과 2:05–2:35를 줄인다. 첫 줄과 마지막 줄은 줄이지 않는다.
4. 여덟 줄의 순서를 홈 화면의 "이 사이트에서 할 수 있는 것" 목록과 같게 둔다. 발표 중에 다음에 할 일을 화면에서 볼 수 있다.

- 말하면서 누른다. 누르고 나서 설명하면 3분을 넘긴다.
- 0:55–1:15의 빈값 안내를 건너뛰지 않는다. 채점표에서 폼 점수가 걸린 자리다.
- 1:45–2:05의 새로고침은 실제로 F5를 누른다. 말로만 하면 점수가 되지 않는다.
- 동작하지 않는 기능이 있으면 그 줄을 지우고 남은 줄로 3분을 채운다. 되는 것부터 보여 준다.
