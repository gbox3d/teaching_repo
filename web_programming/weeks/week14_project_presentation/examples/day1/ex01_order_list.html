ex01 순서 목록: 차례가 뜻을 가지면 ol

같은 다섯 줄을 두 목록에 넣었다. 1번은 줄 앞에 번호가, 2번은 점이 붙는다.

번호는 파일에 쓰지 않았다. 브라우저가 줄 순서대로 붙인다. F12 › Elements 에서 두 목록을 펼쳐 본다.

1. ol — 번호 목록

  1. 위 메뉴로 네 페이지를 오갑니다.
  2. 버튼으로 인사말과 배경색을 바꿉니다.
  3. 방명록에 글을 남기고 지웁니다.
  4. 남긴 글은 새로고침해도 그대로 있습니다.
  5. 프로젝트 카드는 JSON 파일에서 읽어 옵니다.

2. ul — 점 목록

  • 위 메뉴로 네 페이지를 오갑니다.
  • 버튼으로 인사말과 배경색을 바꿉니다.
  • 방명록에 글을 남기고 지웁니다.
  • 남긴 글은 새로고침해도 그대로 있습니다.
  • 프로젝트 카드는 JSON 파일에서 읽어 옵니다.
