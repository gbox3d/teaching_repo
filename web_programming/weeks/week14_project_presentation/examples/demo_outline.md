# 5분 시연 개요

| 시간 | 화면·동작 | 말할 핵심 | 증거 |
|---:|---|---|---|
| 0:00~0:30 | 첫 화면 | 문제, 사용자, 한 줄 가치 | 공개 URL |
| 0:30~1:30 | 로그인·session | 로그인 전후 상태와 복구 | 새로고침 |
| 1:30~2:30 | core CRUD | 즉석 row 작성·수정 | DB 재조회 |
| 2:30~3:15 | relation | 댓글·즐겨찾기·이력 | FK row |
| 3:15~4:00 | RLS | B가 A row 변경 시도 | Network·DB 불변 |
| 4:00~4:30 | 오류·접근성 | 지정 상태와 키보드 | focus·message |
| 4:30~5:00 | 구조·회고 | 선택 이유, 한계, 다음 단계 | 구조도·issue |
