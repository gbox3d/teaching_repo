# 11주차 — Auth와 소유자 RLS

## 주간 목표

- 인증(authentication)과 인가(authorization)를 구분한다.
- 회원가입·로그인·로그아웃과 새로고침 후 세션 복구를 구현한다.
- auth.uid()와 owner_id를 사용해 소유자 기반 정책을 작성한다.
- 익명·사용자 A·사용자 B의 권한을 교차 검증한다.

## 1일차 — 인증과 세션

| 구간 | 내용 |
|---|---|
| 설명·시연 30분 | Auth/JWT/session 흐름, 가입·로그인·로그아웃, auth state change |
| 직접 해결 60분 | 인증 UI 구현, 세션 복구, 로그인 전후 화면 상태 분리 |

## 2일차 — 소유자 권한과 RLS

| 구간 | 내용 |
|---|---|
| 설명·시연 30분 | 인증과 인가의 차이, USING/WITH CHECK, UI 숨김과 DB 강제의 차이 |
| 직접 해결 60분 | A/B 계정으로 insert/update/delete 교차 테스트와 권한 행렬 작성 |

## 완료 기준

- 새로고침 후에도 로그인 상태가 복구된다.
- 로그인 사용자가 자신의 글을 작성·수정·삭제한다.
- 다른 사용자의 수정·삭제 요청은 DB에서 거부된다.
- 익명/A/B의 select·insert·update·delete 결과를 표로 기록한다.
