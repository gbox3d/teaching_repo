# ex01 · JSON 요청 본문

수업 구분: 강의자 시연.

메시지를 입력하고 JSON 변환을 누르면 JSON 문자열이 화면에 표시된다. 네트워크 요청은 보내지 않는다. `JSON.stringify(item)`과 객체의 필드를 비교한다.

정적 서버에서 [index.html](index.html)을 연다. [app.js](app.js)의 객체 → JSON 문자열을 읽는다. 이 예제는 API를 호출하지 않으므로 `.http`와 API 설정 파일이 없다.

W3.CSS는 https://cdnjs.cloudflare.com/ajax/libs/w3-css/4.1.0/w3.min.css 이며 추가 스타일은 `shared/examples.css`다. 화면에는 입력과 결과만 두고 설명은 이 문서에서 읽는다.
