# 중간 개인 실기 구조

이 문서는 공개 가능한 공통 구조다. 실제 시험 문항, fixture, 정답과 학생별 정보는 별도 비공개 공간에서 관리한다.

## 평가 범위

| 영역 | 확인 역량 |
|---|---|
| Git·실행 | 지정 starter, 변경 상태, commit, 필요 시 Pages URL |
| HTML | landmark, heading, form label, button/list 의미 |
| CSS | box model, Flex/Grid, 좁은 viewport, focus |
| JavaScript | 배열·함수, selector, event, 상태 변경 |
| DOM | 상태 기반 render, id 대상 식별, 안전한 문자열 출력 |
| 검증 | normal, empty, validation과 Console 확인 |

ES Module·fetch의 포함 깊이는 학기별 실제 시험 공지에서 명시한다.

## 권장 운영

### 1일차

- 30분: 구조·규정·모의 진단 설명
- 60분: 공개 동형 모의 실기

### 2일차

- 30분: 환경·제출·검증 안내
- 60분: 개인 실기

기관 시험 시간표가 다르면 총 평가 시간과 안내 시간을 분리해 LMS에 사전 공지한다.

## 시험 패킷

실제 학기에는 다음을 비공개로 준비한다.

1. 요구사항 문서와 정확한 완료 조건
2. 동일 checksum 또는 release tag의 starter
3. 필요한 이미지·JSON fixture와 사용 허가
4. 제출 경로·파일명·마감 시각
5. 네트워크·참고 자료·AI 도구 허용 범위
6. 장애 발생 시 대체 제출 절차
7. 비공개 채점 테스트와 정답 기준

## 학생 산출물

- 지정 source 파일
- 실행 방법 또는 공개 URL
- 마지막 commit id
- 요구한 정상·경계 상태
- 시험 규정에서 요구한 캡처나 짧은 설명

## 시작 전 감독 체크

- 모든 PC에서 starter가 같은 방식으로 열린다.
- 로컬 서버·브라우저·Git이 동작한다.
- starter에 답안 또는 이전 학생 정보가 없다.
- 상대 경로와 대소문자가 배포 환경에서도 유효하다.
- 제출 시스템에 테스트 파일을 업로드·재다운로드했다.
- 장애 기록 시각과 대체 제출 창구가 준비됐다.

## 공정성 경계

- 문구·환경·제출 장애는 모든 학생에게 같은 수준으로 안내한다.
- 구현 로직이나 정답에 해당하는 개별 힌트는 제공하지 않는다.
- 추가 시간·대체 평가는 대학 규정과 공식 기록을 따른다.
- 학생 코드·점수·개인정보는 공개 저장소에 올리지 않는다.

## 공개 저장소 제외 항목

- 실제 문제의 고유 값과 숨은 경계 조건
- 모범 답안과 부분 답안
- 채점 자동화의 비공개 testcase
- 수험생 명단, 제출 URL, 점수와 이의신청 기록
