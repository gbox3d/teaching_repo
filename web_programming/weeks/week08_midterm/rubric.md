# 중간 개인 실기 채점표 — 20점

이 rubric은 공개 가능한 공통 기준이다. 학기별 문항의 배점 매핑은 시험 전에 고지하며, 실제 정답과 비공개 testcase는 포함하지 않는다.

| 영역 | 배점 | 충족 기준 |
|---|---:|---|
| Git·실행·제출 | 3 | 지정 구조, 실행 가능, 최신 commit/URL 확인 |
| 시맨틱 HTML·접근성 | 4 | landmark·heading·label·button 의미, 키보드·focus |
| CSS·반응형 | 3 | 요구 layout, 좁은 viewport, 가로 넘침 없음 |
| JavaScript 상태·DOM | 6 | event → 검증 → state → render, id 기반 정확한 대상 |
| 경계·오류 처리 | 3 | empty·validation과 문항이 요구한 실패 경로 |
| 검증·설명 | 1 | 정상/경계 증거와 구현 흐름 설명 |
| 합계 | 20 | |

## 수준별 공통 판단

### 완전 충족

요구한 경로를 독립적으로 재현할 수 있고, 관련 없는 데이터나 기능에 부작용이 없다. Console 오류가 없고 코드와 제출 증거가 일치한다.

### 부분 충족

핵심 구조 또는 일부 경로가 동작하지만 특정 입력·viewport·대상 식별에서 실패한다. 시도 흔적만이 아니라 실행 가능한 부분 결과가 있어야 한다.

### 미충족

실행되지 않거나 요구사항과 무관한 결과이며, 채점 가능한 파일·URL이 없거나 본인 구현임을 확인할 수 없다.

## 감점 적용 원칙

- 같은 원인으로 여러 증상이 생긴 경우 중복 감점 여부를 기록한다.
- 문항별 최대 배점을 넘겨 감점하지 않는다.
- 미세한 시각 차이와 기능 불능을 같은 수준으로 취급하지 않는다.
- 접근성 항목은 단순 색상 취향이 아니라 의미 구조와 실제 키보드 동작으로 판단한다.
- 제출 장애는 학생 구현 오류와 시스템 장애를 기록상 구분한다.
