# 8주차 — 중간 개인 실기

중간 실기는 1–7주차의 공개 배포, 시맨틱 HTML·반응형 CSS, JavaScript 데이터 처리와 DOM event를 개인이 통합하는지 확인한다. 이 폴더는 공개 가능한 시험 구조, 중립 starter, 연습 절차와 채점 기준만 담는다. 학기별 실제 요구사항·입력값·정답은 포함하지 않는다.

## 학습 목표

1. 요구사항을 HTML·CSS·JavaScript·Git 검증 항목으로 분해한다.
2. 입력 → 검증 → 상태 변경 → render 흐름을 제한 시간 안에 구현한다.
3. 정상 경로와 최소 하나의 실패·경계 경로를 재현한다.
4. Git commit, 실행 URL, 화면과 Console로 제출 상태를 확인한다.
5. 동작하지 않을 때 HTML → selector → event → state → render 순으로 진단한다.

## 운영 흐름

| 일차 | 30분 설명·시연 | 60분 활동 |
|---|---|---|
| 1일차 | 시험 구조, 요구사항 분해, 시간 배분 | 공개용 모의 실기와 자기 진단 |
| 2일차 | 제출·검증·오류 복구 절차 | 개인 실기 또는 동형 모의 제출 |

실제 시험 운영 시간과 배포 방식은 해당 학기 LMS 공지를 최종 기준으로 한다.

## 공개 자료와 비공개 자료의 경계

이 저장소에 포함:

- 역량 영역, 시간 관리, 제출 구조
- 중립 DOM starter와 공개용 연습 요구사항
- 항목별 채점 기준과 검증 질문

별도 비공개 공간에서 관리:

- 학기별 실제 문제 문구와 fixture
- 정답·모범 구현·채점용 테스트
- 학생별 결과와 점수

## 완료 기준

- 시험 시작 전 환경·저장 위치·제출 경로를 확인했다.
- 요구사항별 완료 여부를 직접 체크할 수 있다.
- starter의 `TODO`를 찾고 구현 순서를 말할 수 있다.
- 공백 입력, empty 상태, 좁은 화면을 검증했다.
- 마지막 commit과 제출물의 파일이 동일함을 확인했다.
