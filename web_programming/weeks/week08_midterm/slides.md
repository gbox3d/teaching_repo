# 중간 개인 실기

1~7주 실습 제출을 한 문제씩 모은 **문제 은행**으로 연습하고, 2일차에 혼자 60분 동안 시험을 봅니다.

```text
1일차  문제 은행 연습 60분 + 새 저장소 web-week08 · Pages 켜기
2일차  중간 실기 60분 — 은행 문제를 값만 바꿔 낸다
```

- 시험 문제는 은행 문제와 **문장·할 일·확인하는 방법이 같고**, 값만 다릅니다.
- 해답은 공개하지 않습니다. 문제마다 있는 **"확인할 것"** 이 모두 맞으면 된 것입니다.
- 배점은 **20점(안)** 입니다. 주차별 실습 점수가 아닙니다.

## 1일차 · 8–16분 — 문제 하나 읽는 법: w05_greeting_card

[w05_greeting_card 문제 문장](examples/w05_greeting_card/README.md) — 절은 다섯, 모든 문제가 같은 순서다

```text
시작 파일      받는 파일과 지금 상태. "고치지 않는다" 파일은 그대로 둔다
할 일          고칠 파일과 자리, 쓸 것. 적힌 순서대로 한다
확인할 것      화면·F12 로 스스로 맞춰 보는 목록. 해답 대신이다
이 문제의 값   시험에서 바뀌는 값. w05 는 guest07 · 15 · welcome …
받기와 올리기  web-week08/w05_greeting_card/ 에 Raw 로 받는다
```

- 확인할 것 예: 카드에 `반가워요, guest07님. 즐거운 오후예요.`, Console 에 `15` 와 같은 문장.
- 값은 표에서 **복사해 붙여 넣습니다.** 한 글자만 달라도 확인할 것이 맞지 않습니다.

**문장·할 일·확인할 것은 시험에서도 그대로다. "이 문제의 값" 표만 바뀐다.**

## 1일차 · 16–24분 — 확인하는 법: 서버로 열기와 F12

[server.mjs](../../tools/static-server/server.mjs) 는 `web-week08` 맨 위 → `node server.mjs` → `http://localhost:8000/<문제 id>/`

```text
Console      빨간 줄(Uncaught) · console.log · 식 쳐 보기 hello(12)
Network      파일마다 Status 200 / 404 — 서버·공개 주소에서만 보인다
Elements     태그·class·href, Styles · Computed · 상자 그림
기기 모드    Ctrl+Shift+M — 문제에 적힌 폭(w04 는 1280 · 500 · 480 · 375)
Application  저장된 값 — 11주에 배운다. 8주 은행 문제에는 없다
```

- "확인할 것"마다 볼 곳이 적혀 있습니다. 그곳을 열고 글자 하나까지 맞춰 봅니다.
- Node 가 없는 PC 는 두 번 눌러 엽니다. 그때는 Status 번호가 보이지 않습니다.

**확인할 것은 화면과 F12 로 보는 결과다. 결과가 같으면 코드 모양은 달라도 된다.**

# 2일차 — 중간 실기

`30분 설명·시연 → 60분 시험`

1. 시험 규칙 — 볼 수 있는 것, 범위, 막히면 넘어가기, 60분 시간표
2. exam 폴더 받기 → 저장소 맨 위에 넣기 → 목차 열기 → 시작 올리기
3. 영역·배점·채점 — "확인할 것"으로 본다
4. 끝내기 전 — 마지막 올리기와 제출 세 가지

---

## 2일차 · 0–8분 — 시험 규칙: 볼 수 있는 것, 범위, 시간표

```text
0–5 읽기 · 5–15 A · 15–27 B · 27–39 C · 39–50 D
50–55 마지막 올리기 · 55–60 예비(Pages 반영 · 다시 로그인)
```

- 볼 수 있는 것: 교재 사이트, 본인 저장소, MDN. 그 밖은 강의자 공지를 따릅니다.
- 범위는 1~7주 은행 문제입니다. 범위 밖 기능은 가점이 없습니다.
- 문제끼리 이어지지 않습니다. **한 문제에 5분 넘게 막히면 다음 문제로 갑니다.**
- 질문은 문장의 뜻·파일 위치·제출 방법·장애만 받습니다. 코드가 맞는지는 답하지 않습니다.

**시간표 한 칸 = 문제 하나. 막히면 넘기고, 남는 시간에 돌아온다.**

---

## 2일차 · 8–16분 — exam 폴더 받기와 시작 올리기

```text
web-week08/
  server.mjs   w05_greeting_card/ …   ← 1일차 연습 폴더. 그대로 둔다
  exam/                                ← 받은 폴더를 통째로
    index.html   README.md   a/  b/  c/  d/
```

1. 시험 시작 때 받은 `exam` 폴더를 `web-week08` 맨 위에 **그대로** 넣습니다. 풀었더니 `exam/exam/` 이면 안쪽 것을 넣습니다.
2. 서버로 `http://localhost:8000/exam/` 을 열어 목차가 보이는지 봅니다.
3. 바로 올립니다: `git add .` → `git commit -m "중간 실기 시작"` → `git push`
4. 문제 문장은 `exam/README.md` 에 있습니다. 문제마다 그 폴더의 파일만 고칩니다.

**시작하자마자 한 번 올린다. 시험 중에 저장소를 만들거나 Pages 를 켜지 않는다.**

---

## 2일차 · 16–24분 — 영역·배점·채점: "확인할 것"으로 본다

[채점표](rubric.md)

```text
제출·공개 3   A HTML 4   B CSS 4   C JavaScript·DOM 5   D 폼 3
Console 오류 없음 1                             합계 20점(안)
제출·공개 3 = 제출 세 가지 · 목차·문제 페이지가 열린다 · 시작과 끝 두 번 올림
```

- 채점자가 공개 주소를 열어 문제마다 **"확인할 것"** 으로 봅니다.
- 완전 충족(전부) · 부분 충족(실행되는 부분 결과) · 미충족(열리지 않음·무관·없음).
- 원인이 하나면 한 번만 깎습니다. Console 1점은 `Uncaught` 빨간 줄만 봅니다.
- Pages 지연은 감점하지 않습니다. 5점 하한(시도하면 최소 5점)은 아직 정하지 않았습니다.

**코드 모양이 아니라 "확인할 것"이 맞는지를 본다.**

## 2일차 · 24–30분 — 끝내기 전: 마지막 올리기와 제출

[2일차 실습](lab.md#2일차--중간-실기-60분) · [따라하기](walkthrough.md#2일차) · [실습 페이지](https://github.com/gbox3d/teaching_repo/tree/main/web_programming/weeks/week08_midterm)

```text
50분  git add .  →  git commit -m "중간 실기 끝"  →  git push
      공개 주소 …/web-week08/exam/ 새로고침 → 목차에서 문제마다 확인
      GitHub 저장소 › Commits 탭 캡처 — 맨 위 commit 의 번호와 시각
```

- 제출본 = 마감 전 마지막 commit 을 공개 주소에서 연 화면. 저장하지 않은 파일은 올라가지 않습니다.
- Pages 가 5분 넘게 옛 화면이면 로컬 화면 캡처 + Commits 탭 캡처로 냅니다.
- 공용 PC면 자격 증명을 지우고 나갑니다.

**설명 합계: 8+8+8+6 = 30분**

## 제출하기

2일차 시험이 끝나면 **세 가지**를 제출합니다. [제출 — 세 가지](lab.md#제출--세-가지)

```text
① 공개 주소    https://student01.github.io/web-week08/exam/
② 저장소 주소  https://github.com/student01/web-week08
③ Commits 탭 캡처 1장 — 맨 위 commit 의 번호와 시각이 보이게
```

맨 위 commit 은 마감 전 마지막으로 올린 `중간 실기 끝` 입니다.
채점은 `exam/` 폴더만 봅니다. 1일차 연습 폴더는 그대로 두어도 됩니다.
캡처에 실명·학번·실제 이메일이 보이지 않게 합니다. 제출 위치와 기한은 수업 공지를 따릅니다. commit 마감은 시험이 끝나는 시각입니다.
