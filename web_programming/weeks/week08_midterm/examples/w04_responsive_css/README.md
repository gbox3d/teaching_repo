# w04_responsive_css — 반응형 메뉴와 카드

출처: [4주차 실습 제출](../../../week04_responsive_css/lab.md#제출--캡처-한-장) · 권장 12분 · 중간 B(CSS) · 기말 A(화면(HTML·CSS·README))

4주차에 조립한 `styles.css` 를 다른 값으로 다시 만든다. 넓은 화면에서는 메뉴가 가로 한 줄로 서고, 좁은 화면에서는 세로로 선다. 소개 문단과 취미 목록은 테두리 있는 카드로 보여야 한다.

## 시작 파일

| 파일 | 지금 상태 |
|---|---|
| `index.html`·`about.html`·`guestbook.html` | 완성본이다. 세 페이지 모두 `styles.css` 를 연결했다. `index.html` 의 소개 문단 두 개와 취미 목록에는 class 가 `panel` 로 붙어 있다. 고치지 않는다 |
| `images/profile.png` | `index.html` 의 프로필 그림이다 |
| `styles.css` | 색·글꼴·`h1`·`h2`·`nav a`·입력 칸·`footer` 규칙이 있다. 할 일 1~4 자리에는 주석만 있다 |

## 할 일

`styles.css` 의 주석 네 자리에 쓴다. HTML 은 고치지 않는다.

1. 할 일 1(`body` 규칙 안): 본문의 최대 폭을 560px 로 하고 화면 가운데에 둔다. 안쪽 여백은 네 방향 모두 12px 로 한다. 창이 좁으면 본문도 같이 좁아져야 한다.
2. 할 일 2: 메뉴 링크 세 개를 가로 한 줄로 세우고 링크 사이 간격을 24px 로 한다. 한 줄에 다 들어가지 않으면 다음 줄로 넘긴다.
3. 할 일 3: class `panel` 규칙을 만든다.
   - 배경색: `#fffbea`
   - 안쪽 여백: 네 방향 모두 20px
   - 바깥 여백: 위아래 10px, 좌우 0
   - 테두리: 두께 2px, 모양 `solid`, 색 `#e0c060`
4. 할 일 4(파일 맨 끝): 화면 폭이 480px 이하일 때만 메뉴 링크가 위에서부터 한 줄씩 세로로 선다.

## 확인할 것

- [ ] F12 › 기기 모드(**Ctrl+Shift+M**) 폭 `1280` 에서 메뉴 `홈`·`내 정보`·`방명록` 이 왼쪽부터 가로 한 줄로 서고, 링크 사이가 24px 떨어져 있다.
- [ ] 폭 `500` 에서도 메뉴가 가로 한 줄이다. 폭 `480` 에서는 위에서부터 한 줄씩 세로로 선다.
- [ ] 폭 `375` 에서 메뉴가 위에서부터 `홈`·`내 정보`·`방명록` 차례로 한 줄씩 선다. 가로 스크롤 막대가 없다.
- [ ] 폭 `1280` 에서 F12 › Elements 로 `body` 를 고른다. Styles 맨 아래 상자 그림의 내용 폭은 `560`, padding 은 네 방향 모두 `12` 이고, 좌우 margin 은 같은 값이다.
- [ ] 소개 문단 두 개와 취미 목록이 배경 `#fffbea`, 테두리 색 `#e0c060` 인 카드로 보인다. 셋 중 하나를 고르면 상자 그림의 padding 은 `20`, border 는 `2`, margin 은 위아래 `10`·좌우 `-`(0)이다.
- [ ] F12 › Console 에 빨간 줄이 없다.

## 이 문제의 값

| 값 | 이 문제에서 |
|---|---|
| 본문 최대 폭(px) | `560` |
| 본문 안쪽 여백(px) | `12` |
| 메뉴 링크 사이 간격(px) | `24` |
| 카드 class | `panel` |
| 카드 배경색 | `#fffbea` |
| 카드 안쪽 여백(px) | `20` |
| 카드 바깥 여백 위아래(px) | `10` |
| 카드 테두리 두께(px) | `2` |
| 카드 테두리 색 | `#e0c060` |
| 메뉴가 세로로 서는 폭(이하, px) | `480` |
| 가로 한 줄을 다시 볼 폭(기준+20) | `500` |

시험에서는 같은 문제를 이 표의 값만 바꿔서 낸다. 문장·할 일·확인하는 방법은 그대로다.

## 받기와 올리기

- 이번 주 저장소(8주는 `web-week08`, 15주는 `web-week15`) 맨 위에 [server.mjs](../../../../tools/static-server/server.mjs) 가 없으면 먼저 **Raw** 로 받아 둔다.

- 저장소 맨 위에서 `node server.mjs` 로 열면 주소는 `http://localhost:8000/w04_responsive_css/` 이다. Node 가 없는 PC 는 두 번 눌러 연다.
- `node server.mjs` 로 연 주소나 공개 주소에서는 `favicon.ico` 404 한 줄이 Console·Network 에 보여도 괜찮다(빨간 줄로 세지 않는다). 공개 주소에서 새로고침하면 Status 가 `304` 로 보일 수 있다. 이미 받은 파일을 다시 쓴다는 뜻이다.
- 올린 뒤 공개 주소는 `https://student01.github.io/web-week08/w04_responsive_css/`(15주에 풀었다면 `web-week15`)이다.
- 해답은 공개하지 않는다. 위 "확인할 것"이 모두 맞으면 된 것이다.
