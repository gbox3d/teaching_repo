# w07_form_line — 입력 칸을 읽어 한 줄로 보여 주기

출처: [7주차 실습 제출](../../../week07_async_modules/lab.md#제출--캡처-한-장) · 권장 10분 · 중간 D(폼) · 기말 C(폼·목록)

7주차 실습(폼 제출을 한 줄로, 빈값 안내)을 다른 값으로 다시 만든다. 이름과 메시지를 넣고 버튼을 누르면 페이지가 다시 열리지 않고, 아래 문단에 `이름: 메시지` 한 줄이 보인다. 이름이 비어 있으면 안내 문구를 보인다.

## 시작 파일

| 파일 | 지금 상태 |
|---|---|
| `index.html` | 폼(`id="guest-form"`) 안에 이름 칸(`id="name"`)·메시지 칸(`id="message"`)·버튼 **남기기** 가 있고, 폼 아래에 결과 문단(`id="result"`)이 있다. `app.js` 를 `defer` 로 연결했다. 고치지 않는다 |
| `app.js` | 주석 한 줄뿐이다 |

## 할 일

`app.js` 에 차례로 쓴다.

1. `document.querySelector` 로 폼, 이름 칸, 메시지 칸, 결과 문단을 찾아 `const` 에 담는다.
2. 폼에 `addEventListener('submit', (event) => { … })` 을 건다. 안에서 맨 먼저 `event.preventDefault()` 로 페이지가 다시 열리는 것을 막는다.
3. 이름 칸과 메시지 칸의 `value` 를 `trim()` 해서 읽는다.
4. 이름이 빈 글자(`''`)면 결과 문단에 `이름을 입력하세요.` 를 보이고 이름 칸에 `focus()` 한 뒤 끝낸다(`return`).
5. 이름이 있으면 결과 문단에 `이름: 메시지` 한 줄을 보이고, `form.reset()` 으로 두 칸을 비운다.
6. 저장 → 새로고침 → 이름 `student01`, 메시지 `안녕하세요` 를 넣고 버튼을 눌러 본다.

## 확인할 것

- [ ] 페이지를 열면 결과 문단이 `아직 남긴 글이 없습니다.` 다.
- [ ] 이름 `student01`, 메시지 `안녕하세요` 를 넣고 **남기기** 를 누르면 페이지가 다시 열리지 않고(주소창에 `?` 가 붙지 않는다) 결과 문단이 `student01: 안녕하세요` 이 된다. 두 칸은 비워진다.
- [ ] 이름을 비운 채 메시지만 넣고 누르면 결과 문단이 `이름을 입력하세요.` 가 되고 커서가 이름 칸에 들어간다.
- [ ] F12 › Console 에 빨간 줄이 없다.

## 힌트

- 폼은 `click` 이 아니라 `submit` 이벤트다. 버튼을 눌러도, 칸에서 Enter 를 쳐도 폼의 `submit` 이 일어난다.
- `event.preventDefault()` 가 없으면 버튼을 누른 순간 페이지가 다시 열려 결과가 사라지고 주소 끝에 `?` 가 붙는다.
- 한 줄 만들기: `name + ': ' + message`. 안내 문구와 결과는 모두 `textContent` 로 넣는다.

## 이 문제의 값

| 값 | 이 문제에서 |
|---|---|
| 페이지 제목 h1 | `방명록` |
| 폼 id | `guest-form` |
| 이름 칸 id | `name` |
| 메시지 칸 id | `message` |
| 결과 문단 id | `result` |
| 결과 문단의 처음 글자 | `아직 남긴 글이 없습니다.` |
| 버튼 글자 | `남기기` |
| 이름과 메시지 사이 글자 | `: ` |
| 이름이 비었을 때 안내 | `이름을 입력하세요.` |
| 확인 때 넣는 이름 | `student01` |
| 확인 때 넣는 메시지 | `안녕하세요` |
| 확인 때 보여야 할 한 줄 | `student01: 안녕하세요` |

시험에서는 같은 문제를 이 표의 값만 바꿔서 낸다. 문장·할 일·확인하는 방법은 그대로다.

## 받기와 올리기

- 이번 주 저장소(8주는 `web-week08`, 15주는 `web-week15`) 맨 위에 [server.mjs](../../../../tools/static-server/server.mjs) 가 없으면 먼저 **Raw** 로 받아 둔다.
- 저장소 안에 `w07_form_line/` 폴더를 만든다. 교재의 이 문제 폴더에 있는 시작 파일을 하나씩 열어 **Raw** 를 누르고 Ctrl+S(macOS ⌘+S)로 같은 이름으로 저장한다. 그림도 Raw 를 누르면 그림만 보이는 화면이 열리고, 거기서 같은 방법으로 저장한다. 하위 폴더(그림·데이터)는 GitHub 에서 그 폴더를 눌러 들어가 받고, 내 폴더에도 같은 이름으로 만든다. 저장한 이름 끝에 `.txt` 가 붙었으면 지운다. 이 `README.md`(지금 읽는 문제 문장)는 받지 않는다.
- 저장소 맨 위에서 `node server.mjs` 로 열면 주소는 `http://localhost:8000/w07_form_line/` 이다. Node 가 없는 PC 는 두 번 눌러 연다.
- `node server.mjs` 로 연 주소나 공개 주소에서는 `favicon.ico` 404 한 줄이 Console·Network 에 보여도 괜찮다(빨간 줄로 세지 않는다). 공개 주소에서 새로고침하면 Status 가 `304` 로 보일 수 있다. 이미 받은 파일을 다시 쓴다는 뜻이다.
- 올린 뒤 공개 주소는 `https://student01.github.io/web-week08/w07_form_line/`(15주에 풀었다면 `web-week15`)이다.
- 해답은 공개하지 않는다. 위 "확인할 것"이 모두 맞으면 된 것이다.
