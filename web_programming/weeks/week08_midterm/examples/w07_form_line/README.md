# w07_form_line — W3.CSS로 방명록 꾸미기

출처: [7주차 실습 제출](../../../week07_form_input/lab.md#제출--캡처-한-장) · 권장 10분 · 중간 D(W3.CSS) · 기말 A(화면)

동작하는 방명록에 W3.CSS를 연결하고 카드·입력·버튼·목록의 모양을 바꾼다. 폴더 이름은 기존 링크를 유지하기 위해 그대로 둔다. 폼 동작은 제공 코드이며 이번 문제는 HTML의 CDN 연결과 클래스 적용을 평가한다.

## 시작 파일

| 파일 | 상태 |
|---|---|
| index.html | 폼·안내·목록이 있다. CDN 연결과 카드·입력·목록 클래스는 학생이 추가한다 |
| app.js | 입력 검사·글 추가·폼 초기화가 동작한다. 수정하지 않는다 |

## 할 일

1. index.html의 head에 아래 CDN을 스타일시트로 연결한다.
2. 페이지를 가운데에 놓고 좌우 여백을 준다. 폼에는 흰색 카드와 안쪽 여백을 적용한다.
3. 이름과 메시지 입력을 부모 영역의 너비에 맞추고 테두리를 적용한다.
4. 남기기 버튼에 W3.CSS 버튼 모양과 청록색 배경을 적용한다.
5. 남긴 글 목록에 W3.CSS 목록 스타일을 적용한다. 기존 id·label·script 연결과 긴 글을 스크롤하는 w3-responsive 클래스는 유지한다.

CDN 주소: https://cdnjs.cloudflare.com/ajax/libs/w3-css/4.1.0/w3.min.css

## 확인할 것

- [ ] Network에서 CDN CSS 요청이 성공한다(200 또는 캐시 응답). 인터넷 연결이 필요하다.
- [ ] 페이지에 좌우 여백, 폼에 카드·안쪽 여백, 두 입력에 전체 너비·테두리가 적용된다.
- [ ] 남기기 버튼이 청록색이고, 남긴 글에 목록 스타일이 적용된다.
- [ ] 너비 375px에서 입력과 버튼이 화면 밖으로 나가지 않는다.
- [ ] 이름 student01과 메시지를 바꾸어 두 번 남기면 두 줄이 표시된다. 빈 이름은 안내를 표시한다.
- [ ] 영문 120자를 입력해도 375px에서 가로로 넘치지 않는다. 새로고침하면 글이 사라진다.
- [ ] Console에 실행 오류가 없다. id 변경으로 제공 동작을 깨뜨리지 않는다.

## 힌트

[7주차 변환 예제](../../../week07_form_input/examples/day2/ex05/README.md)에서 class와 id가 맡는 역할을 확인한다. [W3.CSS 입력](https://www.w3schools.com/w3css/w3css_input.asp)과 [카드](https://www.w3schools.com/w3css/w3css_cards.asp) 문서에서 필요한 클래스를 찾는다. 직접 CSS를 새로 작성하는 문제는 아니다.

## 이 문제의 값

| 값 | 이 문제에서 |
|---|---|
| 페이지 제목·버튼 글자 | 방명록 · 남기기 |
| 버튼 배경 | 청록색(teal) |
| 폼 id | guest-form |
| 이름·메시지·안내·목록 id | name · message · notice · list |
| 확인할 너비 | 375px |
| 확인 입력 | student01 / 안녕하세요, student02 / 반갑습니다 |

시험에서는 색·글자 등 이 표의 값만 바꾼다. JavaScript 구현을 새로 요구하지 않는다.

## 받기와 올리기

index.html과 app.js를 같은 w07_form_line 폴더에 준비한다. [정적 서버](../../../../tools/static-server/README.md)를 부모 폴더에서 실행하면 http://localhost:8000/w07_form_line/ 으로 연다. CDN 연결을 위해 인터넷이 필요하다.

제출 방식은 분반 공지를 따른다. 공개 주소를 제출할 때는 web-week08 또는 web-week15 저장소의 w07_form_line 폴더에 올린다. 화면과 주소창이 보이는 캡처를 남긴다.

연습 파일은 수업 전에 준비한다. 1일차 공개 업로드는 수업 뒤에 한다. 시험의 제출 시간과 형식은 분반 공지를 따른다.
