# w02_about_page — 새 페이지와 상대 링크

출처: [2주차 실습 제출](../../../week02_github_pages/lab.md#제출--캡처-네-장) · 권장 10분 · 중간 A(HTML) · 기말 A(화면(HTML·CSS·README))

2주차에 만든 소개 페이지를 다른 값으로 다시 만든다. 첫 페이지의 링크로 새 페이지를 열고, 새 페이지의 링크로 첫 페이지에 돌아온다. 올린 뒤 공개 주소에서도 두 링크가 똑같이 동작해야 한다.

## 시작 파일

| 파일 | 지금 상태 |
|---|---|
| `index.html` | 카드 한 장(제목·문장·**방문 버튼**·`<p id="status">`)이 있다. 새 페이지로 가는 링크는 없다 |
| `styles.css` | 완성본이다(`.card` 규칙이 있다). 고치지 않는다 |
| `app.js` | 완성본이다. 버튼을 누를 때마다 클릭 횟수를 올리고 Console 에 준비 문구를 찍는다. 고치지 않는다 |

## 할 일

1. `index.html` 과 같은 폴더에 새 파일 `about.html` 을 만든다. 파일 이름은 모두 소문자다. 공개 주소(GitHub Pages)는 대소문자를 구분해서 한 글자만 달라도 404 가 된다.
2. `about.html` 의 `<head>` 는 `index.html` 과 같게 쓰되 두 곳이 다르다.
   - `<title>` 은 `소개 페이지` 이다.
   - `styles.css` 만 연결한다. 이 페이지에는 버튼이 없으므로 `app.js` 는 연결하지 않는다.
3. `about.html` 의 본문은 첫 페이지처럼 `<main class="card">` 하나 안에 차례로 쓴다.
   - 제목 `<h1>`: `소개`
   - 문단 `<p>` 하나: `웹프로그래밍 수업에서 만든 연습 페이지입니다.`
   - 링크 하나: 글자는 `첫 페이지로 돌아가기`, 누르면 `index.html` 로 돌아간다.
4. `index.html` 의 `<p id="status">` 줄 바로 아래에 문단 하나를 넣고 그 안에 링크를 만든다. 글자는 `소개 페이지 보기`, 누르면 `about.html` 이 열린다.
5. 두 링크의 `href` 에는 같은 폴더의 파일 이름만 쓴다. 앞에 `/` 나 폴더 이름을 붙이지 않는다.

## 확인할 것

- [ ] 첫 페이지의 `클릭 횟수: 0` 아래에 `소개 페이지 보기` 링크가 보인다. 누르면 주소창 끝이 `/about.html` 로 바뀌고 제목이 `소개` 인 새 페이지가 열린다.
- [ ] 새 페이지의 탭 제목이 `소개 페이지` 이고 카드에 `웹프로그래밍 수업에서 만든 연습 페이지입니다.` 가 보인다. 배경색과 흰 카드가 첫 페이지와 같다.
- [ ] 새 페이지에서 `첫 페이지로 돌아가기` 를 누르면 주소창 끝이 `/index.html` 로 바뀌고 첫 페이지가 다시 열린다.
- [ ] F12 › Elements 에서 두 링크의 `href` 가 각각 `about.html`·`index.html` 이다. 글자 하나까지 같고 앞에 `/` 가 없다.
- [ ] `node server.mjs` 로 연 주소나 공개 주소에서 새 페이지를 열고, F12 › Network 를 켠 채 새로고침하면 `about.html`·`styles.css` 가 `200` 이고 `app.js` 줄은 없다.
- [ ] 첫 페이지에서 **방문 버튼**을 세 번 누르면 `클릭 횟수: 3` 이 된다. F12 › Console 에 `my-web ready` 가 찍히고 두 페이지 모두 빨간 줄이 없다.

공개 주소에서 새로고침하면 `about.html` 줄의 Status 가 `304` 로 보일 수 있다. 브라우저가 이미 받은 파일을 그대로 다시 쓴다는 뜻이라 괜찮다.

## 이 문제의 값

| 값 | 이 문제에서 |
|---|---|
| 새 파일 이름 | `about.html` |
| 새 페이지 title | `소개 페이지` |
| 새 페이지 h1 | `소개` |
| 새 페이지 문장 | `웹프로그래밍 수업에서 만든 연습 페이지입니다.` |
| 돌아가는 링크 글자(새 페이지) | `첫 페이지로 돌아가기` |
| 가는 링크 글자(첫 페이지) | `소개 페이지 보기` |
| Console 준비 문구 | `my-web ready` |

시험에서는 같은 문제를 이 표의 값만 바꿔서 낸다. 문장·할 일·확인하는 방법은 그대로다.

## 받기와 올리기

- 이번 주 저장소(8주는 `web-week08`, 15주는 `web-week15`) 맨 위에 [server.mjs](../../../../tools/static-server/server.mjs) 가 없으면 먼저 **Raw** 로 받아 둔다.
- 저장소 안에 `w02_about_page/` 폴더를 만든다. 교재의 이 문제 폴더에 있는 시작 파일을 하나씩 열어 **Raw** 를 누르고 Ctrl+S(macOS ⌘+S)로 같은 이름으로 저장한다. 그림도 Raw 를 누르면 그림만 보이는 화면이 열리고, 거기서 같은 방법으로 저장한다. 하위 폴더(그림·데이터)는 GitHub 에서 그 폴더를 눌러 들어가 받고, 내 폴더에도 같은 이름으로 만든다. 저장한 이름 끝에 `.txt` 가 붙었으면 지운다. 이 `README.md`(지금 읽는 문제 문장)는 받지 않는다.
- 저장소 맨 위에서 `node server.mjs` 로 열면 주소는 `http://localhost:8000/w02_about_page/` 이다. Node 가 없는 PC 는 두 번 눌러 연다.
- `node server.mjs` 로 연 주소나 공개 주소에서는 `favicon.ico` 404 한 줄이 Console·Network 에 보여도 괜찮다(빨간 줄로 세지 않는다). 공개 주소에서 새로고침하면 Status 가 `304` 로 보일 수 있다. 이미 받은 파일을 다시 쓴다는 뜻이다.
- 올린 뒤 공개 주소는 `https://student01.github.io/web-week08/w02_about_page/`(15주에 풀었다면 `web-week15`)이다.
- 해답은 공개하지 않는다. 위 "확인할 것"이 모두 맞으면 된 것이다.
