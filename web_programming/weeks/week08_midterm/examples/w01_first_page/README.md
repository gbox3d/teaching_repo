# w01_first_page — 첫 페이지 만들기

출처: [1주차 실습 제출](../../../week01_web_git/lab.md#제출--캡처-두-장) · 권장 8분 · 중간 A(HTML) · 기말 A(화면(HTML·CSS·README))

1주차에 한 것처럼 HTML 파일 하나로 첫 페이지를 만든다. 큰 제목·문단·목록 세 가지를 쓰고, 두 번 눌러 열어 본 뒤 서버로도 연다.

## 시작 파일

| 파일 | 지금 상태 |
|---|---|
| `index.html` | `<head>` 에 탭 제목(`<title>`)만 있고, `<body>` 는 주석 한 줄뿐이다 |

## 할 일

1. `<body>` 의 주석 자리에 차례로 쓴다.
   - 큰 제목 `<h1>`: `student01의 첫 페이지`
   - 문단 `<p>` 하나: `웹프로그래밍 수업에서 처음 만든 페이지입니다.`
   - 목록 `<ul>` 과 항목 `<li>` 세 개: `음악`, `농구`, `커피` 순서로
2. 저장하고 파일을 두 번 눌러 연다. 주소가 `file://` 로 시작한다.
3. 수업에서 한 것처럼 서버로도 연다(`node server.mjs` 또는 수업에서 쓴 서버). 주소가 `http://` 로 시작한다.
4. F12 › Elements 에서 `h1`·`p`·`ul` 이 `body` 안에 이 순서로 있는지 본다.

## 확인할 것

- [ ] 화면 맨 위에 `student01의 첫 페이지` 가 큰 글자로 보이고, 그 아래 문단, 그 아래 점 세 개짜리 목록이 보인다.
- [ ] 목록 항목이 위에서부터 `음악` · `농구` · `커피` 순서다. F12 › Console 에 `document.querySelectorAll('li').length` 를 치면 `3` 이 나온다.
- [ ] 탭 제목이 `첫 페이지` 다.
- [ ] 서버로 연 주소에서 F12 › Network 를 켠 채 새로고침하면 `index.html` 의 Status 가 `200` 이다. Console 에 빨간 줄이 없다.

## 힌트

- 태그는 열고 닫는다. `<h1>글자</h1>`, `<p>글자</p>`, `<ul><li>항목</li></ul>`. `<li>` 는 꼭 `<ul>` 안에 둔다.
- 글자는 이 문장에서 **복사해 붙인다.** 빈칸·마침표 하나가 다르면 확인할 것이 맞지 않는다.
- `file://` 은 브라우저가 내 PC 파일을 바로 읽은 것이고, `http://` 는 서버가 파일을 보내 준 것이다. Status 번호는 서버로 열 때만 보인다.

## 이 문제의 값

| 값 | 이 문제에서 |
|---|---|
| 탭 제목 title | `첫 페이지` |
| 큰 제목 h1 | `student01의 첫 페이지` |
| 문단 한 문장 | `웹프로그래밍 수업에서 처음 만든 페이지입니다.` |
| 목록 항목(차례로) | `음악` · `농구` · `커피` |

시험에서는 같은 문제를 이 표의 값만 바꿔서 낸다. 문장·할 일·확인하는 방법은 그대로다.

## 받기와 올리기

- 이번 주 저장소(8주는 `web-week08`, 15주는 `web-week15`) 맨 위에 [server.mjs](../../../../tools/static-server/server.mjs) 가 없으면 먼저 **Raw** 로 받아 둔다.
- 저장소 안에 `w01_first_page/` 폴더를 만든다. 교재의 이 문제 폴더에 있는 시작 파일을 하나씩 열어 **Raw** 를 누르고 Ctrl+S(macOS ⌘+S)로 같은 이름으로 저장한다. 그림도 Raw 를 누르면 그림만 보이는 화면이 열리고, 거기서 같은 방법으로 저장한다. 하위 폴더(그림·데이터)는 GitHub 에서 그 폴더를 눌러 들어가 받고, 내 폴더에도 같은 이름으로 만든다. 저장한 이름 끝에 `.txt` 가 붙었으면 지운다. 이 `README.md`(지금 읽는 문제 문장)는 받지 않는다.
- 저장소 맨 위에서 `node server.mjs` 로 열면 주소는 `http://localhost:8000/w01_first_page/` 이다. Node 가 없는 PC 는 두 번 눌러 연다.
- `node server.mjs` 로 연 주소나 공개 주소에서는 `favicon.ico` 404 한 줄이 Console·Network 에 보여도 괜찮다(빨간 줄로 세지 않는다). 공개 주소에서 새로고침하면 Status 가 `304` 로 보일 수 있다. 이미 받은 파일을 다시 쓴다는 뜻이다.
- 올린 뒤 공개 주소는 `https://student01.github.io/web-week08/w01_first_page/`(15주에 풀었다면 `web-week15`)이다.
- 해답은 공개하지 않는다. 위 "확인할 것"이 모두 맞으면 된 것이다.
