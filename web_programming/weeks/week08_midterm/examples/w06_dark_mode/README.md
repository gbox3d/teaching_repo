# w06_dark_mode — 문구 바꾸기·다크 모드·클릭 횟수

출처: [6주차 실습 제출](../../../week06_dom_crud/lab.md#제출--캡처-한-장) · 권장 12분 · 중간 C(JavaScript·DOM) · 기말 B(DOM)

6주차에 만든 버튼 두 개·클릭 횟수·다크 모드를 다른 값으로 다시 만든다. 문구 버튼을 누르면 인사 카드의 글자가 바뀌고, 모드 버튼을 누를 때마다 화면이 어두워졌다 밝아진다. 두 버튼을 누른 횟수는 횟수 문단 하나에 합쳐서 센다.

## 시작 파일

| 파일 | 지금 상태 |
|---|---|
| `index.html` | 인사 카드·버튼 두 개·횟수 문단이 있고 `app.js` 가 `defer` 로 연결돼 있다. 인사 카드의 처음 글자는 시각과 상관없이 정해 두었다. 고치지 않는다 |
| `styles.css` | 완성본이다. 맨 아래에 다크 규칙 `body.dark`·`body.dark .card`(배경 `#222222`, 글자 `#eeeeee`)와 다크일 때 제목 글자색 규칙이 있다. 고치지 않는다 |
| `app.js` | 주석 한 줄뿐이다 |

## 할 일

`app.js` 에 차례로 쓴다.

1. 인사 카드 `#greeting`, 횟수 문단 `#clicks`, 문구 버튼 `#swap-button`, 모드 버튼 `#theme-button` 넷을 찾아 `const` 에 담는다.
2. 누른 횟수를 셀 값을 `let` 으로 만들고 0 을 담는다. 리스너 밖에 둔다.
3. 횟수를 올리는 함수를 하나 만든다. 부를 때마다 횟수를 1 올리고, 횟수 문단의 글자를 `클릭 N회` 꼴로 바꾼다. N 자리에 지금까지 누른 횟수가 들어간다.
4. 문구 버튼 `[문구 바꾸기]` 를 누르면 인사 카드의 글자를 `방문해 주셔서 감사합니다!` 로 바꾸고 3 의 함수를 부른다.
5. 모드 버튼 `[다크 모드]` 를 누를 때마다 `<body>` 에 class `dark` 를 붙였다 뗀다. 없으면 붙이고 있으면 뗀다. 그리고 3 의 함수를 부른다.

## 확인할 것

- [ ] 페이지를 열면 인사 카드 글자는 `안녕하세요, guest07님! 좋은 오후입니다.`, 횟수 문단 글자는 `클릭 0회` 이다. `<body>` 에는 class `dark` 가 없다.
- [ ] 새로고침한 뒤 `[문구 바꾸기]` 를 2번, `[다크 모드]` 를 1번 누르면 인사 카드 글자는 `방문해 주셔서 감사합니다!`, 횟수 문단 글자는 `클릭 3회` 이다.
- [ ] 그때 F12 › Elements 의 `<body>` 에 class `dark` 가 붙어 있다. Elements › Computed 에서 `<body>` 와 인사 카드의 `background-color` 가 둘 다 `rgb(34, 34, 34)` 로 나온다.
- [ ] 이어서 `[다크 모드]` 를 한 번 더 누르면 `<body>` 에서 class `dark` 가 빠지고 `<body>` 의 `background-color` 는 다시 `rgb(238, 242, 255)` 이다. 횟수 문단 글자는 `클릭 4회` 이다.
- [ ] 이어서 `[문구 바꾸기]` 를 한 번 더 누르면 인사 카드 글자는 그대로 `방문해 주셔서 감사합니다!` 이고, 횟수 문단 글자는 `클릭 5회` 이다.
- [ ] 열 때와 누르는 동안 F12 › Console 에 빨간 줄이 없다.

## 이 문제의 값

| 값 | 이 문제에서 |
|---|---|
| 페이지 제목 h1 | `버튼 연습장` |
| 인사 카드 id | `greeting` |
| 인사 카드의 처음 글자 | `안녕하세요, guest07님! 좋은 오후입니다.` |
| 인사 카드의 바뀐 글자 | `방문해 주셔서 감사합니다!` |
| 문구 버튼 id | `swap-button` |
| 문구 버튼 글자 | `문구 바꾸기` |
| 모드 버튼 id | `theme-button` |
| 모드 버튼 글자 | `다크 모드` |
| 횟수 문단 id | `clicks` |
| 횟수 문장 꼴(N 은 횟수) | `클릭 N회` |
| 다크 class | `dark` |
| 다크 배경색(styles.css) | `#222222` |
| 다크일 때 배경 계산값 | `rgb(34, 34, 34)` |
| 다크 글자색(styles.css) | `#eeeeee` |
| 밝은 배경색(styles.css) | `#eef2ff` |
| 밝을 때 배경 계산값 | `rgb(238, 242, 255)` |
| 확인 때 문구 버튼을 누르는 수 | `2` |
| 확인 때 모드 버튼을 누르는 수 | `1` |
| 처음 횟수 문장 | `클릭 0회` |
| 누른 뒤 횟수 문장 | `클릭 3회` |
| 모드 버튼을 한 번 더 누른 뒤 횟수 문장 | `클릭 4회` |
| 이어서 문구 버튼을 한 번 더 누른 뒤 횟수 문장 | `클릭 5회` |

시험에서는 같은 문제를 이 표의 값만 바꿔서 낸다. 문장·할 일·확인하는 방법은 그대로다.
