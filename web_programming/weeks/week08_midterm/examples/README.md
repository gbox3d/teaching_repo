# 8주차 중립 starter

`starter`는 form, status, empty 영역과 list를 가진 빈 통합 골격이다. JavaScript의 `TODO`에는 실제 시험 답안이나 특정 학기 요구사항이 없다.

## 실행

```bash
cd starter
python -m http.server 8000
```

`http://localhost:8000`을 열고 Console을 확인한다.

## 사용 원칙

- 공개용 [모의 실기](../lab.md)에서 복사본을 만들어 사용한다.
- 실제 시험 starter는 별도 release/tag로 배포하고 checksum 또는 commit을 기록한다.
- 이 폴더에는 완성 답안이나 실제 시험 fixture를 추가하지 않는다.
- CSS의 기본 layout은 제공하지만 반응형·focus 보완은 모의 실습에서 직접 한다.
