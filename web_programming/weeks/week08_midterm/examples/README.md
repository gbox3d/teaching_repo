# 8주차 문제 은행 — 1~7주 실습 제출

1~7주 실습의 제출을 한 문제씩으로 정리했다. 문제마다 그 주에 배운 것만 쓰고, 나머지 파일은 다 주어진다. 문제끼리는 이어지지 않는다.

- 2일차 중간 실기는 이 은행에서 영역(A~D)마다 한 문제씩 낸다. 시험 문제는 문장·할 일·확인하는 방법이 같고, "이 문제의 값" 표의 값만 바뀐다.
- 해답은 공개하지 않는다. 문제 문장의 "확인할 것"이 모두 맞으면 된 것이다.
- 연습은 문제 폴더의 시작 파일을 `web-week08/<문제 id>/` 폴더에 받아서 한다. 받는 법과 올리는 법은 문제 문장 끝의 "받기와 올리기"와 [따라하기](../walkthrough.md)에 있다.
