# w07_form_result — 폼 제출을 한 줄로, 빈값 안내

출처: [7주차 실습 제출](../../../week07_async_modules/lab.md#제출--캡처-한-장) · 권장 11분 · 중간 D(폼) · 기말 C(폼·목록)

7주차에 만든 방명록 폼 제출을 다른 값으로 다시 만든다. **[올리기]** 버튼을 누르면 페이지가 다시 열리지 않고, 두 칸에 적은 글이 결과 카드에 한 줄로 나와야 한다. 칸이 비어 있으면 그 칸의 안내 문장을 보이고 커서를 그 칸으로 옮긴다. 확인은 `comment.html` 을 열어서 한다(주소 끝에 파일 이름까지 붙인다).

## 시작 파일

| 파일 | 지금 상태 |
|---|---|
| `comment.html` | 폼(`#comment-form`) 안에 이름표가 붙은 닉네임 칸(`input`)·한마디 칸(`textarea`)과 **[올리기]** 버튼이 있다. 폼 아래에 빈 안내 자리(`#hint`)와 결과 카드(`#latest`)가 있다. `app.js` 는 HTML 을 끝까지 읽은 뒤 실행되게 연결해 두었다. 고치지 않는다 |
| `styles.css` | 완성본이다. 고치지 않는다 |
| `app.js` | 주석 한 줄뿐이다 |

## 할 일

`app.js` 에만 쓴다.

1. 맨 위에서 폼(`#comment-form`), 닉네임 칸(`#nickname`), 한마디 칸(`#comment`), 안내 자리(`#hint`), 결과 카드(`#latest`)를 찾아 둔다.
2. 폼이 제출될 때 실행할 함수를 폼에 맡긴다. 그 함수는 맨 먼저 페이지가 다시 열리지 않게 막는다. 버튼을 누를 때와 닉네임 칸에서 Enter 를 칠 때 모두 이 함수가 실행된다.
3. 함수 안에서 두 칸의 값을 읽어 앞뒤 빈칸을 뗀다. 빈칸만 적은 칸은 빈 칸으로 본다.
4. 닉네임 칸이 비었으면 안내 자리에 `닉네임을 적어 주세요.` 문장을 쓰고 커서를 닉네임 칸으로 옮긴 뒤 멈춘다.
5. 한마디 칸이 비었으면 안내 자리에 `한마디를 적어 주세요.` 문장을 쓰고 커서를 한마디 칸으로 옮긴 뒤 멈춘다. 두 칸이 다 비었으면 4의 안내만 나온다.
6. 두 칸이 모두 채워졌으면 안내 자리를 비우고, 결과 카드의 글자를 `[닉네임] 한마디` 꼴의 한 줄로 바꾼다. 닉네임·한마디 자리에는 앞뒤 빈칸을 뗀 값이 들어간다. 기호와 빈칸은 이 꼴과 글자 하나까지 같게 쓴다. 예: 닉네임 `guest07`, 한마디 `반갑습니다` 이면 `[guest07] 반갑습니다` 이다.
7. 결과를 쓴 뒤 두 칸을 비우고 커서를 닉네임 칸에 둔다.

## 확인할 것

- [ ] 한마디 칸에는 `반갑습니다`, 닉네임 칸에는 빈칸만 넣고 **[올리기]** 버튼을 누르면 안내 자리에 `닉네임을 적어 주세요.` 문장이 보이고 커서가 닉네임 칸에 있다. 결과 카드는 `아직 남긴 한마디가 없습니다.` 그대로다.
- [ ] 닉네임 칸에는 `guest07`, 한마디 칸에는 빈칸만 넣고 누르면 `한마디를 적어 주세요.` 문장이 보이고 커서가 한마디 칸에 있다. 결과 카드는 그대로다.
- [ ] 두 칸을 모두 비우고 누르면 `닉네임을 적어 주세요.` 문장이 보인다.
- [ ] 두 칸에 각각 `guest07`·`반갑습니다` 앞뒤로 빈칸을 붙여 넣고 누르면 결과 카드에 `[guest07] 반갑습니다` 한 줄이 보인다. 주소 끝에 물음표(`?`)가 붙지 않고, 두 칸이 비고, 안내 자리가 비고, 커서가 닉네임 칸에 있다.
- [ ] 새로고침한 뒤 두 칸에 각각 `guest07`·`반갑습니다` 만 넣고 닉네임 칸에서 Enter 를 쳐도 결과 카드에 `[guest07] 반갑습니다` 한 줄이 보이고 주소 끝에 `?` 가 붙지 않는다.
- [ ] 위 확인을 하는 동안 F12 › Console 에 빨간 줄이 없다.

## 이 문제의 값

| 값 | 이 문제에서 |
|---|---|
| 페이지 파일 이름 | `comment.html` |
| 페이지 제목(h1) | `한마디 게시판` |
| 폼 id | `comment-form` |
| 첫 칸(input) id | `nickname` |
| 첫 칸 이름표 | `닉네임` |
| 둘째 칸(textarea) id | `comment` |
| 둘째 칸 이름표 | `한마디` |
| 버튼 글자 | `올리기` |
| 안내 자리 id | `hint` |
| 결과 카드 id | `latest` |
| 결과 카드 위 제목(h2) | `방금 남긴 한마디` |
| 결과 카드의 처음 글자 | `아직 남긴 한마디가 없습니다.` |
| 첫 칸이 비었을 때 안내 | `닉네임을 적어 주세요.` |
| 둘째 칸이 비었을 때 안내 | `한마디를 적어 주세요.` |
| 결과 한 줄의 꼴 | `[닉네임] 한마디` |
| 확인 입력 — 첫 칸 | `guest07` |
| 확인 입력 — 둘째 칸 | `반갑습니다` |
| 결과 카드에 나올 한 줄 | `[guest07] 반갑습니다` |

시험에서는 같은 문제를 이 표의 값만 바꿔서 낸다. 문장·할 일·확인하는 방법은 그대로다.

## 받기와 올리기

- 이번 주 저장소(8주는 `web-week08`, 15주는 `web-week15`) 맨 위에 [server.mjs](../../../../tools/static-server/server.mjs) 가 없으면 먼저 **Raw** 로 받아 둔다.
- 저장소 안에 `w07_form_result/` 폴더를 만든다. 교재의 이 문제 폴더에 있는 시작 파일을 하나씩 열어 **Raw** 를 누르고 Ctrl+S(macOS ⌘+S)로 같은 이름으로 저장한다. 그림도 Raw 를 누르면 그림만 보이는 화면이 열리고, 거기서 같은 방법으로 저장한다. 하위 폴더(그림·데이터)는 GitHub 에서 그 폴더를 눌러 들어가 받고, 내 폴더에도 같은 이름으로 만든다. 저장한 이름 끝에 `.txt` 가 붙었으면 지운다. 이 `README.md`(지금 읽는 문제 문장)는 받지 않는다.
- 저장소 맨 위에서 `node server.mjs` 로 열면 주소는 `http://localhost:8000/w07_form_result/comment.html` 이다. Node 가 없는 PC 는 두 번 눌러 연다.
- `node server.mjs` 로 연 주소나 공개 주소에서는 `favicon.ico` 404 한 줄이 Console·Network 에 보여도 괜찮다(빨간 줄로 세지 않는다). 공개 주소에서 새로고침하면 Status 가 `304` 로 보일 수 있다. 이미 받은 파일을 다시 쓴다는 뜻이다.
- 올린 뒤 공개 주소는 `https://student01.github.io/web-week08/w07_form_result/comment.html`(15주에 풀었다면 `web-week15`)이다.
- 해답은 공개하지 않는다. 위 "확인할 것"이 모두 맞으면 된 것이다.
