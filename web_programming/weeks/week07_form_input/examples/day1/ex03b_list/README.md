# ex03b 수업 타임라인

[실행 화면](index.html)에는 수업 중에 쓴 글 세 개가 최신순으로 보인다. **새 글 1개 보기**를 누르면 김민서의 10:42 글이 맨 위에 나타난다. 새로고침하면 처음 상태로 돌아간다.

## 글 한 개의 구조

`ol` 안에 글을 `li` 하나씩 담는다. 각 `article`은 이름 한 글자를 넣은 원과 본문을 나란히 배치한다. 작성자 이름과 `time`은 같은 줄에 놓고, 글 내용은 그 아래에 둔다.

| 적용할 곳 | 클래스 또는 속성 | 화면에서 확인할 점 |
| --- | --- | --- |
| 글 목록 | `w3-ul` | 순번을 숨기고 글 사이에 구분선을 긋는다. |
| 작성자 표시 | `w3-circle`, `w3-pale-blue` 등 | 원의 모양은 유지하고 작성자마다 배경색을 다르게 준다. |
| 글 본문 | `grid-template-columns`, `overflow-wrap` | 화면을 좁혀도 원의 폭이 유지되고 긴 글은 본문 안에서 줄이 바뀐다. |

## 확인 순서

1. 화면 너비를 375px로 줄인다. 박준호의 글에서 두 번째 줄이 시작하는 위치를 작성자 이름의 왼쪽 끝과 비교한다.
2. `Tab`으로 **새 글 1개 보기**에 이동한 뒤 `Enter`를 누른다. 새 글 작성자 이름에 초점이 표시되고, 기존 세 글은 그 아래에 남는다. 터치로 버튼을 눌러도 같은 글이 나타난다.
3. `shared/examples.css`에서 `.post`의 `padding-block`을 `0.5rem`에서 `1rem`으로 바꾸고 새로고침한다. 375px와 1280px에서 글 위아래 여백과 본문 줄 수를 비교한다.

고정 CDN 주소는 `https://cdnjs.cloudflare.com/ajax/libs/w3-css/4.1.0/w3.min.css`이다. 글 배치와 줄바꿈은 [추가 CSS](shared/examples.css)에 있다. [제공 스크립트](app.js)는 HTML에 미리 넣은 글을 표시하고 작성자 이름으로 초점을 옮긴다.
