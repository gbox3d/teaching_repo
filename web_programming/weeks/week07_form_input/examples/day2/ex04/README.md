# ex04 변환 전 방명록

`index.html`을 열고 이름과 메시지를 입력한 뒤 **남기기**를 누른다. 작성자·작성 시각·본문이 목록에 나오고 입력 칸이 비워진다. 글을 하나 더 남기면 맨 위에 나타난다.

이 예제는 W3.CSS를 연결하지 않는다. `../web-week07/styles.css`는 이전 방명록에서 직접 작성한 CSS다. 비교를 위해 그대로 참조하며 라이브러리 사본이 아니다. 폴더를 옮길 때 `examples/day2` 내부의 상대 위치를 유지한다.

`app.js`는 완성본 `../web-week07/guestbook.js`와 같다. 다음 동작을 확인한 뒤 ex05와 비교한다.

- 이름 또는 메시지를 비우거나 공백만 입력하면 안내가 표시되고 목록에 추가되지 않는다.
- 이름이나 메시지를 다시 입력하면 안내가 지워진다.
- 첫 글을 남기면 빈 목록 안내가 사라진다. 작성자와 본문 앞뒤의 공백은 사라지고 본문의 줄바꿈은 남는다.
- 추가 후 폼을 초기화하고 이름 칸으로 초점을 이동한다.

JavaScript는 `guestbook-form`, `name`, `message`, `notice`, `list`의 `id`를 사용한다. 이메일 칸은 기존 화면을 유지한 항목이며 현재 코드가 목록에 넣지 않는다. 새로고침하면 남긴 글은 사라진다.

이메일은 선택 입력이다. `abc`를 입력하면 브라우저가 형식 오류로 제출을 막는다. 이메일을 비우거나 `student01@example.com`으로 바꾸면 이름·메시지를 목록에 추가할 수 있다. 이 검사는 JS의 submit 처리보다 먼저 실행된다.

- CDN: 사용하지 않음
- 기존 CSS: `../web-week07/styles.css`
- 추가 CSS는 `shared/examples.css`다. `example-output`은 긴 입력을 줄바꿈하고 `.post-body`는 본문 안의 줄바꿈을 유지한다. ex05에서 목록에 `feed-list`를 더하면 글 왼쪽에 작성자의 첫 글자가 나타난다.
