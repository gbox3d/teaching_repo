# W3.CSS 실습 파일 정리

웹 교재 HTML 172개와 실습 순서를 유지하고 CSS 파일 60개를 제거했다. W3.CSS 화면 72개 중 67개는 CDN 하나를 사용한다. 나머지 5개는 이교수님이 직접 수정하고 보존을 요청한 7주 타임라인·방명록과 그 화면을 이어 쓰는 9·15주 예제다. 추가 CSS 사용 조건은 [과목 지침](../../AGENTS.md)에 있다.

| 수업 | 확인한 동작 |
|---|---|
| 7·8주 | 입력 미리보기와 방명록 제출, 긴 글 표시. 8주 시작 파일에는 학생이 CDN을 연결한다. |
| 10·11주 | 배열 추가·삭제·개수, 문자열·JSON·폼 저장과 복원 |
| 12주 | 소개·도움말·목록 GET, HTTP 400 응답, 빈 목록 |
| 13주 | 글 등록 후 재조회, 폼 초기화, 긴 글 표시 |
| 14주 | 등록·수정·삭제, 마지막 글을 지운 뒤 빈 목록 표시 |
| 15주 | 문제은행의 제공 화면과 학생용 TODO 보존 |
| 배열·SPA·Supabase 특강 | 배열 연산, hash 이동·키보드 초점, 글 등록·수정·삭제 |

375px와 1280px에서 바뀐 화면을 확인했다. REST 동작은 임시 로컬 API에서 검증했다. 사이트 빌드와 자동 시험 54개가 통과했다.
