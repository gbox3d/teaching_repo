# 12·13주 수업 구성 검토

## 12주 비동기 GET

필수 예제는 타이머의 실행 순서, JSONPlaceholder에서 같은 할 일을 읽는 두 방식, Open-Meteo 기온 조회 순서다. 첫날 학생은 `.then()` 체인을 두 번의 `await`로 바꾸고 같은 제목이 표시되는지 확인한다. 둘째 날에는 잘못된 위도를 보냈을 때 받은 HTTP 400과 오프라인 통신 실패를 비교하고 선택한 도시의 기온을 다시 조회한다. 수업용 방명록의 접속·도움말·목록 요청은 선택 예제에 있다. [12주 실습지](../../weeks/week12_fetch_json/lab.md)

## 13주 방명록 POST

첫 필수 요청은 배부받은 키와 번호로 글을 등록하는 POST다. 학생은 201 응답의 글 번호를 제공된 GET으로 확인한다. 초기 예제의 중복 목록 코드를 줄이고 ex04의 폼 전송, ex05의 대기·실패 처리, ex06의 저장 후 재조회를 구분했다. [13주 예제](../../weeks/week13_release_security/examples/README.md)

## 독립 검토

| 검토 대상 | 점수 | 확인한 내용 |
|---|---|---|
| 12주 첫날과 13주 연결 | 9/10 | 타이머 실행 순서, 동일한 GET을 작성하는 두 방식, 각 주 결과물 |
| 12주 날씨와 13주 쓰기 예제 | 9/10 | 위도 오류와 통신 실패, 폼 입력·중복 클릭·저장 후 조회 |
| 강의안·실습지·예제 일치 | 9/10 | 키 없는 12주 필수 실습, 13주 첫 POST, 차시당 강의 60분과 실습 30분 |

공개 API에서 할 일과 서울·부산 기온의 GET 200, 잘못된 위도의 400을 확인했다. 13주 쓰기는 로컬 모의 API에서 확인했다. 초보자가 첫날 코드 전환 실습을 12분 안에 마치는지는 수업에서 측정해야 한다. 비공개 대본·해답의 차시 구성은 공개 교재 개편에 맞춰 별도로 갱신할 항목이다.
