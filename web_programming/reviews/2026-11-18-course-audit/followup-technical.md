## 검증 환경과 범위

Playwright에서 실제 Chrome `157.0.8103.38`을 실행했다. 직접 시작한 정적 서버의 임시 포트를 사용했고 다른 검증 서버를 재사용하지 않았다. 브라우저 시간대는 `Asia/Seoul`, 화면 폭은 375px와 1280px다. 종료 후 브라우저와 서버를 정리했다.

7·9주의 파일 76개에서 HTML 15개, Markdown 33개를 집계했다. 두 단원의 HTML·Markdown 로컬 참조 322개는 모두 존재했다. 코드 블록·인라인 코드·HTML 주석의 링크 문법 예시는 실제 링크에서 제외했다. 실제 인증 정보나 환경 파일은 읽지 않았다.

7·9주 HTML 15개를 두 화면 폭에서 실행했다. 15주 `w09_readme_links`의 홈·내 정보·방명록도 두 폭에서 추가 실행했다. 예제 설명·README·실습지·따라하기·한영 슬라이드의 관련 부분과 소스를 대조했다.

## 인접 단원 확인과 수정 종결

처음 확인했을 때 10주는 9주 파일을 복사하라고 안내하면서 타임라인에서 문자열 목록으로 바뀌는 경로가 명확하지 않았다. 최신순이 등록순으로 바뀌는 이유도 빠져 있었다. 이 상태를 총괄에게 알렸고 문서가 보완됐다.

현재 9주 다음 수업 안내와 10주 README·따라하기는 10주 제공 폴더를 준비하고 `guestbook.start.html`·`guestbook.start.js`로 시작하도록 구분한다. 홈·내 정보는 이어 쓰며 방명록 HTML·JS와 보조 CSS는 10주 제공본을 쓴다. 등록순의 첫 줄을 `items[0]`과 비교한다는 이유도 명시했다. 문자열 배열·고전 for·등록 2줄·삭제 2줄이라는 정규 범위를 늘리지 않았다. 이 문서 공백은 종결했다.
