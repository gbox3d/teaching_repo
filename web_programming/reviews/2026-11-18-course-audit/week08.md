## 수정 내용

1차시는 C01의 강의·시연 60분과 실습 30분으로 통일했다. 필수 활동은 선택 문항 10분, w06 또는 w07 10분, 재현·캡처·설명·미완료 기록 10분이다. 은행 전체를 수업 시간에 풀도록 하던 표를 제거했다. 파일과 저장소는 사전 준비, 연습 결과 업로드는 수업 뒤 활동으로 옮겼다. w02를 고르면 실습 중 로컬 수정·commit을 연습하고 push는 수업 뒤 확인한다.

2차시는 안내 30분과 실기 60분으로 통일했다. 읽기 3분, 구현 42분, 확인 10분, 제출 5분이다. 30~60분·2~4문항 안내와 영역별 네 문항 안내가 충돌하던 부분을 고쳤다. A HTML 4점, B CSS 4점, C DOM 5점, D W3.CSS 3점, E 제출·Console 4점으로 기존 합계 20점을 유지했다. 같은 누락이나 오류를 문항과 E에서 중복 감점하지 않도록 적었다. 문제에 지정한 속성·클래스 조건도 평가한다는 문장을 맞췄다.

시험용 빈 구현은 유지했다. w01의 본문, w03의 링크, w04·w05의 CSS, w06의 JS, w07의 W3 CDN·클래스를 학생이 작성한다. w07의 app.js는 제공 코드다. 긴 영문 입력이 화면을 넘지 않도록 공통 `shared/examples.css` 사본과 `example-output`만 제공했고, 해당 클래스와 하위 폴더를 보존하도록 문서에 적었다. 1~6주 복습 CSS를 W3.CSS로 치환하지 않았다.

w02·w03 HTML의 학습 절차 문장을 README로 옮겼다. w04에 남아 있던 6주차 출처를 4주차로 바로잡았다. Pages 반영 시간을 고정하지 않고 배포 완료 확인과 로컬 증거 제출을 안내했다. 시험 폴더는 7주차 사이트와 분리하며 9주차는 7주차 완성 사이트를 그대로 인계한다.

## 실행 검증

Chrome 157.0.8103.38에서 자체 임시 HTTP 서버를 사용했다. 문항의 완성 답안은 메모리 응답으로만 구성했고 공개 시작 파일에는 쓰지 않았다.

| 확인 | 결과 |
|---|---|
| 시작 HTML 일곱 개 × 375/1280px | 14회 문서 200, 가로 넘침 없음, 실행 오류 없음. w01 빈 본문·w06 미구현·w07 CDN 빈칸 확인 |
| 임시 완성 문항 일곱 개 × 375/1280px | 14회 기대 결과 일치, 실행 오류 없음 |
| w01 | h1·문단·세 목록 항목 순서와 탭 제목 일치 |
| w02 | note 문구 변경 확인. 실제 GitHub push/Pages 배포는 수행하지 않음 |
| w03 | profile.html 왕복, title·목록·상대 href, 양쪽 화면 넘침 없음 |
| w04 | 내용 크기 300×300, 배경 black·글자 lightgreen·4px solid gold·padding 8px 확인. 세 문단의 가로·세로 가운데 기하 확인 |

| file:// | 원본 w07 제공 JS가 직접 파일 열기에서도 글 추가 수행 |

정상 실행 `pageerror`는 0건이다. 오류 재현 단계에서는 의도한 두 오류만 별도로 수집했다. 375px 완성 방명록 캡처를 열어 입력·목록·긴 문자열의 표시를 확인했다. 마우스가 놓인 W3 버튼의 회색 hover 상태는 라이브러리 기본 동작이다.

정적 검사에서 JavaScript 2개 구문 검사, Markdown/HTML 상대 경로 135건, 한국어 UI·문서 문체 검사가 통과했다. 완성 프로그램 전문을 문서에 복제한 블록은 없으며 문제의 값 표와 실행 결과를 대조했다. Markdown의 이전 시간 제목으로 연결되던 앵커는 별도 id로 유지했다.

한영 슬라이드는 각 13장이다. 공통 Marp 테마·deck.css·deck.js로 임시 렌더한 26장을 Chrome에서 전환하며 확인했고 본문 하단 넘침은 없었다. 자동 맞춤 후 글자 크기는 25~29px였다. 이 검사는 전체 사이트 빌드 결과 검증과 구분한다.

## 남은 통합 확인

실제 GitHub 로그인·push·Pages 게시, LMS 제출, 학생의 30분 실습/60분 시험 소요시간은 이번 작업에서 실측하지 않았다. 전체 빌드·배포 자산·렌더된 덱의 링크 검사는 총괄 검증에서 수행한다. 수업 전 감독은 CDN 접속과 제출 창구를 확인한다. 자체 통과 점수는 부여하지 않는다.
