Git 자체가 학습 목표이므로 초기화·설정·commit을 수업 뒤 작업으로 넘기지 않았다. 2주에는 `.git`을 복사하지 않고 새 저장소의 작성자 설정과 push·Pages를 이어 배운다.

## 수정한 결함

- 두 페이지의 카드 너비에 padding이 추가되어 375px 화면에서 카드가 407px, 왼쪽 -16px, 문서 가로폭 391px이었다. `box-sizing: border-box` 한 줄로 카드가 지정 너비 안에 여백을 포함하도록 고쳤다. 예제 README에 제공 코드임을 설명하고 박스 모델 학습을 4주와 연결했다.
- 기존 30분 설명·60분 실습 표기를 모두 60분 강의·시연·30분 실습으로 바꾸면서 직접 수정량도 줄였다. 첫날 CSS 고의 오류와 Elements·Console 조작을 필수 제출에서 제외했다.
- 이름·이메일 설정 없이 commit이 항상 된다는 설명을 수정했다. 환경에 따라 작성자 오류가 나거나 PC 정보가 추정될 수 있음을 설명한다. 로컬 연습의 예시 이메일과 다음 주 공개 저장소의 비공개 이메일 설정을 구분했다.
- 작성자 복구 예시는 강의자 시연으로 두고 `--no-edit`를 붙여 처음 보는 편집기에 진입하지 않게 했다.
- 따라하기의 초기 HTML 전문을 실제 제공 파일과 맞췄다. CSS 한 줄 추가에 따른 commit 출력 예시는 44줄로 갱신하고 변경 줄 수가 달라질 수 있음을 설명했다.

## 남은 검증 범위

학생이 실제로 30분 안에 마치는지는 실측하지 않았다. Git commit 3회는 문서·파일 조립·명령 순서를 검토했으며 이번 작업의 커밋 금지에 따라 새 commit을 만들지는 않았다. GitHub 계정 생성·push·Pages 배포도 1주 실행 검증에 포함하지 않는다.

한영 덱의 전체 사이트 빌드·최종 브라우저 표시·공통 테스트는 총괄의 통합 검증 대상이다. 이 담당자는 다른 주차·공통 파일·다른 과목·tools를 수정하지 않았으며 커밋·푸시는 수행하지 않았다. 독립 평가자의 구현 평가는 별도로 진행한다.
