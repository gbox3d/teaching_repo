# C01 교재 개편과 독립 심사 결과

독립 기획자 9명의 제안 중 C01을 선정하고 정규 15주·30차시와 특강 6개에 반영했다. 기획 심사는 평균 9.10점, 구현의 최종 독립 심사는 9.0·8.9·9.3점이다. 세 구현 점수가 각각 8점 이상이며 평균으로 미달 점수를 상쇄하지 않았다.

위 점수는 2026-11-18 20:36:44 KST의 기준본과 이후 11·12주 저장 실패 보완에 해당한다. 7주 타임라인이 완성된 뒤 별도 커밋 `5f701e7`과 작업 폴더의 보완을 포함해 7주 및 연계 단원을 다시 심사했다. 후속 심사에서도 총괄 9.0·학습 8.9·기술 9.6점으로 각각 통과했다.

## 선정안과 수업 구성

[9개 안의 비교·선정 근거와 전체 수업표](winner.md), [30차시의 시간과 학생 작성 범위](proposal-C01.md#30차시-운영과-학생-수정량)를 기준으로 구현했다. 주차마다 별도 담당 에이전트를 배치했고 세 최종 평가자는 교재를 수정하지 않고 심사했다.

| 주차 | 수업의 진행 |

| 3~4 | 시맨틱 HTML·폼, CSS·반응형 |

일반 27차시는 강의·시연 60분과 실습 30분이다. 시험 2차시는 안내 30분과 실기 60분, 9주 발표는 안내 5분·발표 75분·피드백 10분으로 구분했다. 필수 수정, 제공 코드, 선택 연습을 명시하고 시험의 저장·REST 문항도 필수 범위에 맞췄다.

**SPA 결정: 14주 이후 선택 특강으로 전환한다.** 근거는 정규 과정의 저장·REST 작성량과 선수학습이다. 중간 전환안도 9개 제안에서 비교했다. 정규 수업은 세 HTML 페이지를 유지하며 특강에서는 MPA → 두 화면 → hash 경로 → REST 통합을 직접 비교한다. 실제 수업 완료 시간을 확보한 뒤 정규 편입 여부를 재검토한다.

기존 배열 심화·Supabase 구축·HTTP 홈 IoT·Kakao 지도·신시사이저와 새 SPA까지 특강 6개를 조사했다. 연구 수업에는 분량 상한을 두지 않고 선수학습·실행 환경·선택 활동을 안내한다.

## 실행 검증

- 주차 15개와 특강 6개 담당자의 실제 예제·문서 조사 결과는 [보고서 색인](README.md)에 있다.
- 자동 시험 54개와 사이트 빌드·내부 링크 검사를 통과했다. 전체 사이트는 언어별 58개 덱·1175장이다.
- 웹 교재의 한영 42개 덱·742장을 실제 뷰어에서 이동하며 검사했고, 마지막 수정 덱 6개·90장을 다시 확인했다. 검사 시점의 본문 넘침은 0건이다.
- 기준본의 공개 파일 889개 중 외부 JS 199개, HTML 171개의 로컬 자산 462개, API 설정 사본 22개에 구문·누락·불일치가 없었다.
- 브라우저에서 입력·등록·삭제·새로고침·잘못된 키·통신 실패·늦은 응답·설정 교체·SPA 탐색을 확인했다. 오류와 경쟁 조건의 주입은 실제 공용 데이터와 구분했다.
- 공용 Supabase는 읽기 about/help 200과 잘못된 열 400, localhost에서 HTTPS로 읽는 CORS를 확인했다. 실제 공용 글은 이번 작업에서 추가·수정·삭제하지 않았다.

공통 검증과 증거 파일은 [통합 기록](common.md)에 연결했다. 현재 폴더의 파일별 해시는 [현재 파일 목록](inventory-final.json)에 있으며, 심사 이후 동시 변경을 포함할 수 있으므로 심사 기준본의 완전한 보관 사본으로 사용하지 않는다.

7주 타임라인 추가분을 브라우저에서 다시 실행했다. 375px와 1280px에서 새 글이 맨 위에 나타났으며 키보드로 열면 새 작성자 이름에 초점이 갔다. 방명록에서는 작성 시각, 본문 줄바꿈, 입력 초기화와 새로고침을 확인했다. 7주 완성 폴더의 공통 파일 9개가 9주 발표 폴더와 바이트 단위로 일치했다.

인계 과정에서 두 곳을 고쳤다. 9·10주의 실습 안내와 한영 슬라이드에 10주 제공 시작 파일의 위치를 명시했다. 9주는 작성자·시각·본문을 최신순으로 보여 주고, 10주는 같은 W3.CSS 폼으로 `이름: 메시지`를 등록순으로 그려 첫 줄을 `items[0]`와 비교한다. 15주 README 문항은 9주의 방명록 HTML·JS·CSS와 홈·방명록 캡처를 제공한다.

작업 폴더의 사이트 빌드와 자동 시험 54개를 통과했다. [7·9·10·15주 한영 슬라이드 134장](evidence/followup-decks.json)은 실제 뷰어에서 본문 넘침이 없었다. [소스 검사](evidence/followup-source.json)는 공개 파일 894개 중 외부 JS 200개, HTML 172개의 로컬 자산 연결 464개, API 설정 사본 22개를 확인했다. [이전 목록과의 차이](evidence/followup-changes.json)는 20:46의 작업 폴더를 기준으로 계산했다.

## 실행 환경과 확인 한계

갱신된 정적 서버가 실제 .env·.git·localfiles 접근을 차단하는지 다시 확인했다. Node 기반 IoT·지도 API는 별도 서버이며 정적 Pages만으로 서버 부분을 실행하지 않는다.

실제 학생의 완료 시간, 공개 Pages 배포, VS Code REST Client 확장 UI 직접 조작, 실제 Kakao 연결과 오디오 청취는 이번 검증 범위 밖이다. 오디오 노드의 실행과 사람이 들은 결과도 구분했다. 이번 개편에서는 커밋·푸시를 수행하지 않았다.
