# 웹프로그래밍 예제 작성 지침

- HTML 실습 화면에는 제목, 입력, 버튼, 결과와 필요한 짧은 상태만 둔다. 수업 설명, 따라하기 절차, 개념 해설을 화면에 길게 넣지 않는다.
- 설명과 실습 순서는 예제 폴더의 README에 작성한다. 코드 주석은 해당 줄을 이해하는 데 필요한 내용만 남긴다.
- 기본 예제는 학생이 입력하고 버튼을 눌러 결과를 화면에서 확인할 수 있게 만든다. 콘솔 출력만으로 사용자 동작을 대신하지 않는다.
- 예제를 기본 동작부터 단계별 폴더로 나누고, 확장 기능은 기본 예제와 구분한다.
- W3.CSS는 cdnjs의 버전 고정 CDN 주소로 연결한다. 별도 요청 없이 라이브러리 사본을 저장소에 내려받지 않는다. 예제별 추가 스타일만 `shared/examples.css`에서 관리하고 HTML의 `<style>`에 반복하지 않는다. CDN 주소와 추가 CSS 경로를 README에 명시한다.
- 11주차 정규 수업은 한 회 강의·시연 60분과 실습 30분이다. 기본 저장 예제 3개를 실습하고 배열 심화는 별도 보강 특강으로 편성한다.
- REST API 예제에는 VS Code REST Client용 `.http` 요청을 함께 제공한다. 접속 확인과 API 정보·도움말을 CRUD보다 먼저 다루며 실제 인증 정보는 추적 파일에 넣지 않는다.
