# 모바일프로그래밍 특강

기존 11~15주차의 연락처·BLE 수업을 선택 특강으로 보존한다. 정규 수업은 [11주차 LAN 연결](../weeks/week11_lan_connection/README.md)부터 WlEno 시뮬레이터와 TCP·UDP를 사용한다.

| 특강 | 내용 | 자료 |
|---|---|---|
| 목록·저장·연락처 | ListView, SharedPreferences, ContentProvider, 연락처 권한과 실기기 준비 | [기존 11주차](legacy_week11_content_provider/README.md) |
| BLE 검색·연결 | BLE 권한, GATT, 실제 보드와 Fake 클라이언트 | [기존 12주차](legacy_week12_ble_gatt/README.md) |
| BLE 출력 제어 | LED 명령과 JSON 응답, 기존 과제 안내 | [기존 13주차](legacy_week13_ble_output/README.md) |
| BLE 입력·재연결 | 온습도, 입력 이력, 연결 오류 처리 | [기존 14주차](legacy_week14_ble_input_project/README.md) |
| BLE 종합 연습 | 기존 기말 연습 시작 코드·완성 코드·채점표 | [기존 15주차](legacy_week15_final_exam/README.md) |

각 폴더에는 이전 교재의 README, 실습지, 따라하기, 한국어·영어 슬라이드와 예제 전체가 들어 있다. 본문의 주차 번호와 평가 일정은 원본 수업의 기록이다. 현재 정규 수업의 필수 과제·채점 기준은 [주차 색인](../weeks/README.md)을 따른다.

연락처 특강은 가상 연락처를 넣은 에뮬레이터로 진행한다. BLE 특강은 [기존 bleuno 라이브러리](../bleuno/README.md)와 해당 실습 장비를 준비한다. 특강을 수강하지 않아도 정규 11~15주차를 수행할 수 있다.
