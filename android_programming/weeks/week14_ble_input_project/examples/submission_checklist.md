# 14주차 제출 체크리스트

## 정책·식별

- [ ] 개인/팀 제출 단위를 공식 공지에서 확인했다. 미확정이면 `COURSE_POLICY_TBD`로 남겼다.
- [ ] 팀 허용 시 역할과 commit 근거를 사실대로 적었다.
- [ ] 모든 학생의 개인 구술 증거가 있다.
- [ ] 최종 commit SHA와 제출 파일의 내용이 일치한다.

## 기능

- [ ] 버전 인식 권한 거절 UX가 있다.
- [ ] scan은 대상 발견 또는 제한 시간에 끝난다.
- [ ] 전체 연결 상태가 화면과 로그에 보인다.
- [ ] 필수 계약·입력 구독 뒤에만 Ready가 된다.
- [ ] Ready에서만 출력이 가능하다.
- [ ] 입력 notification의 값·수신 시각·currentness가 보인다.
- [ ] disconnect 뒤 출력 금지·입력 stale가 된다.
- [ ] reconnect 뒤 새 epoch 입력으로 현재화된다.

## 테스트·증거

- [ ] fake 정상·경계·실패·복구를 재현했다.
- [ ] real 정상과 실패/복구를 시도하고 결과를 사실대로 기록했다.
- [ ] 장비 이상과 앱 결함을 구분했다.
- [ ] 로그에서 기기 주소·개인정보를 마스킹했다.
- [ ] 화면, event log, 테스트표가 같은 시나리오를 가리킨다.

## 범위·문서

- [ ] firmware 코딩·빌드·플래싱을 학생 결과로 제출하지 않았다.
- [ ] UUID·GPIO·message 값은 확정본을 인용하거나 `TBD`로 두었다.
- [ ] 보고서 주장에 근거를 연결했다.
- [ ] 공식 출처와 protocol revision을 기록했다.
- [ ] LMS의 실제 마감·파일명·제출 성공 화면을 확인했다.
