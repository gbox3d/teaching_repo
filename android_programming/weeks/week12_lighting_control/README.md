# 12주차 · 내 방 조명 선택과 밝기 제어

`RoomControl`의 연결 화면에서 [제어 시작]을 누르면 제어 화면이 열린다. 이번 주에는 책상 조명과 침대 조명을 선택하고 밝기를 바꾼다. 방의 상황에 맞게 조명을 조절하는 것이 이번 실습의 결과다.

11주차부터 새로 만든 독립 앱을 사용한다. 10주차 이전 프로젝트는 필요하지 않다. 이전 자료는 [BLE 특강](../../specials/legacy_week12_ble_gatt/README.md)에 보존되어 있다.

## 학습 목표

- 선택한 조명을 명령의 LED 번호에 대응시킨다.
- 버튼에서 켜기·끄기 명령을 전송한다.
- 슬라이더 값으로 선택한 조명의 밝기를 조절한다.
- 서버의 응답을 확인한 뒤 결과를 표시한다.

## 수업 흐름

| 일차 | 설명·시연 30분 | 실습 60분 | 결과물 |
|---|---|---|---|
| 1일차 | 두 조명의 선택과 켜기·끄기 | 책상·침대 조명 선택 구현 | 조명 선택 제어 화면 |
| 2일차 | 밝기 값과 응답 표시 | 밝기 슬라이더와 전체 끄기 | 방 조명 조절 화면 |

## 준비

[공통 설정](../../../tools/wleno/android/README.md)대로 만든 RoomControl 프로젝트와 [WlEno](../../../tools/wleno/README.md)를 준비한다. 연결 화면은 11주차 2일차 완성본을 그대로 사용한다. 프로젝트가 없으면 새 Empty Views Activity에 [예제 파일](examples/README.md)을 배치한다.

WlEno와 같은 PC의 에뮬레이터는 `10.0.2.2:8266`, 다른 PC의 에뮬레이터와 실기기는 `WlEno 실행 PC의 LAN IPv4:8266`으로 연결한다. [주소와 방화벽 조건](../../iot_sim/lab.md#2-앱에-넣을-주소-결정)을 확인한다. 교실에서 기기 간 통신이 막히면 같은 PC의 에뮬레이터와 WlEno로 진행한다.

## 완료 기준

- 연결 성공 뒤 제어 화면이 열린다.
- 책상 조명과 침대 조명을 각각 켜고 끈다.
- 슬라이더의 왼쪽·중간·오른쪽에서 밝기 차이를 확인한다.
- 서버 응답 뒤 `조명 설정 완료`가 표시된다.
- [방 조명 모두 끄기]로 모든 조명이 꺼진다.

TCP 소켓 구현과 UDP 검색은 제공 코드의 역할이다. 이번 주 학생 과제는 제어 화면에 집중한다.
