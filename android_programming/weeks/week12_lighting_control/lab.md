# 12주차 실습 · 상황에 맞는 방 조명

학생이 수정하는 파일은 `ControlActivity.kt`와 `activity_control.xml`이다. 연결 화면과 통신 클래스는 제공 코드를 사용한다. 각 일차는 설명·시연 30분 뒤 아래 60분 실습을 진행한다.

## 1일차 · 두 조명 선택

| 시간 | 할 일 | 확인 |
|---|---|---|
| 0~10분 | 시뮬레이터 시작과 제어 화면 진입 | 내 방 제어 화면 |
| 10~25분 | 책상·침대 선택 UI 추가 | 둘 중 하나만 선택 |
| 25~40분 | 선택값으로 켜기·끄기 | 선택한 조명만 변경 |
| 40~50분 | 전송과 응답 확인 | 응답 뒤 설정 완료 |
| 50~60분 | 캡처와 코드 설명 | 선택과 LED 번호 대응 |

1. 책상 조명을 켠 뒤 침대 조명을 켠다.
2. 책상 조명만 끈다. 침대 조명은 켜진 채인지 확인한다.
3. `selectedLamp()`가 각 선택에서 무슨 값을 돌려주는지 적는다.

## 2일차 · 공부 준비와 취침 준비

| 시간 | 할 일 | 확인 |
|---|---|---|
| 0~15분 | 밝기 슬라이더 추가 | 범위 0~255, 시작 128 |
| 15~30분 | 밝기 적용과 전체 끄기 | 선택한 조명 밝기 변경 |
| 30~45분 | 두 상황 재현 | 공부·취침 조명 차이 |
| 45~60분 | 동료 점검과 제출 | 같은 순서 재현 |

| 상황 | 조작 | WlEno에서 확인 |
|---|---|---|
| 공부 준비 | 책상 조명 최대 밝기, 침대 조명 끄기 | LED 0 밝음, LED 1 꺼짐 |
| 취침 준비 | 책상 조명 끄기, 침대 조명 약한 밝기 | LED 0 꺼짐, LED 1 어두움 |
| 외출 | 방 조명 모두 끄기 | 모든 원 꺼짐 |

## 막혔을 때

| 증상 | 확인 |
|---|---|
| 제어 화면이 열리지 않는다 | 11주차의 주소·포트·시뮬레이터 실행 확인 |
| `Unresolved reference: deskRadio` | XML id와 Kotlin 이름 비교 |
| 침대 조명을 선택했는데 책상이 켜진다 | `selectedLamp()` 반환값 확인 |
| 슬라이더를 움직여도 바뀌지 않는다 | [밝기 적용]을 눌렀는지 확인 |
| 밝기 버튼 이름에서 빌드 오류가 난다 | Kotlin과 XML 모두 day2인지 확인 |
| 화면으로 돌아오니 연결이 해제되어 있다 | 연결 화면에서 다시 제어 시작 |

## 제출

제어 화면 Kotlin·XML과 캡처 2장을 제출한다. 공부 준비와 취침 준비의 앱·WlEno 창이 각각 보여야 한다. `pwm 0 128`의 두 숫자와 `result=ok`의 뜻을 한 문장씩 적는다. 실제 보드 연결, UDP 검색, 소켓 구현은 평가하지 않는다.

먼저 끝나면 친구에게 상황별 조작 순서만 주고 같은 조명이 만들어지는지 확인한다.
