# 내 방 제어
## 11주차 · LAN 연결과 책상 조명

주소 입력 → 연결 성공 → 제어 화면 → 조명 켜기·끄기

이번 주에는 새 `RoomControl` 앱을 만든다.
PC의 WlEno 시뮬레이터가 명령을 받아 LED를 바꾼다.

---

# 이번 주 학습 목표

- 주소와 포트로 시뮬레이터에 연결한다.
- 연결 성공 뒤 제어 화면을 연다.
- 버튼으로 책상 조명을 켰다 끈다.

소켓·스레드·검색 구현은 제공 코드다.
이전 프로젝트는 가져오지 않는다.

# 1일차 · 0~5분: 완성할 연결 화면

```text
내 방 제어
시뮬레이터 주소
[10.0.2.2:8266        ]
[제어 시작]
상태: 준비됨
```

오늘은 이 화면에서 연결 성공까지 확인한다.

---

# 1일차 · 5~10분: 두 프로그램의 역할

| 프로그램 | 역할 |
|---|---|
| Android 앱 | 연결을 요청하고 명령을 보냄 |
| PC의 WlEno | 연결을 받아 LED와 센서 상태를 제공 |

LAN은 유선이나 Wi-Fi로 접속한다.
같은 PC의 에뮬레이터와 WlEno만으로도 실습할 수 있다.

TCP는 연결·명령 전송, UDP는 선택 기능인 장치 검색에 쓴다.

---

# 1일차 · 10~15분: WlEno 실행

저장소의 `tools/wleno`에서 실행한다.

```powershell
uv run main
```

LED 네 개가 있는 창을 열어 둔다.
학생마다 자기 PC의 시뮬레이터 한 개를 사용한다.

---

# 1일차 · 15~20분: 주소와 포트

| 실행 환경 | 입력할 주소 |
|---|---|
| 같은 PC의 Android 에뮬레이터 | `10.0.2.2:8266` |
| Android 휴대전화 | `PC의 LAN IPv4:8266` |

`10.0.2.2`는 에뮬레이터에서 PC를 가리킨다.
`8266`은 시뮬레이터의 TCP 포트다.

주소에 `http://`를 붙이지 않는다.

# 1일차 · 20~25분: 새 프로젝트와 연결 버튼

val address = binding.addressEdit.text.toString().trim()

제공 AAR은 `app/libs/`에 넣는다.

# 2일차 · 0~5분: 조명을 제어하는 화면

```text
내 방 제어
책상 조명 (LED 0)
[조명 켜기]   [조명 끄기]
상태: 준비됨
[연결 화면]
```

앱 버튼과 시뮬레이터 LED를 함께 확인한다.

---

# 2일차 · 5~10분: 연결 성공 후 화면 전환

```kotlin
startActivity(
    Intent(this@MainActivity, ControlActivity::class.java)
)
```

`ConnState.READY`가 된 뒤 실행한다.
실패했으면 연결 화면에서 다시 시도한다.

화면 전환 동안 연결을 유지하는 코드는 제공된 틀을 쓴다.

---

# 2일차 · 10~15분: 두 버튼과 두 명령

```kotlin
binding.onButton.setOnClickListener { send("on 0") }
binding.offButton.setOnClickListener { send("off 0") }
```

| 명령 | 동작 |
|---|---|
| `on 0` | LED 0 켜기 |
| `off 0` | LED 0 끄기 |

0은 시뮬레이터에 표시된 첫 LED 번호다.

---

# 2일차 · 15~20분: 버튼부터 LED까지

1. 학생이 [조명 켜기]를 누른다.
2. 앱이 `on 0`을 보낸다.
3. 시뮬레이터의 LED 0이 켜진다.
4. 앱에 응답이 표시된다.

```json
{"result":"ok","ms":"led(s) on"}
```

이번 주에는 응답을 그대로 본다.

---

# 2일차 · 20~25분: 연결이 끊긴 경우

시뮬레이터의 [연결 끊기]를 누른다.

- 앱 상태가 `끊김`으로 바뀐다.
- 조명 버튼이 비활성화된다.
- [연결 화면]으로 돌아가 다시 연결한다.

새로 연결하면 LED는 꺼진 상태다.
연결한 뒤 [조명 켜기]를 누른다.

---

# 2일차 · 25~30분: 화면을 떠났다가 복귀

제어 화면에서 홈으로 나가면 연결을 해제한다.
회전으로 화면이 재생성된 경우에도 다시 연결한다.

수업 예제에서는 [연결 화면]으로 돌아가
[제어 시작]을 눌러 제어를 재개한다.

이번 실습은 앱을 보고 있을 때의 조작에 집중한다.
