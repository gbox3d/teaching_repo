# 11주차: LAN 연결과 내 방 제어

이번 주에는 새 앱 `RoomControl`을 만든다. 주소를 입력하고 연결하면 제어 화면이 열린다. [조명 켜기]와 [조명 끄기]로 PC 시뮬레이터의 책상 조명(LED 0)을 조작한다.

이전 주차 프로젝트와 연결하지 않는다. 전화번호부·ContentProvider와 기존 BLE 예제는 [선택 특강](../../specials/README.md)에 보존했다.

## 학습 목표

- 주소와 포트로 시뮬레이터에 연결한다.
- 연결에 성공한 뒤 제어 화면을 연다.
- 버튼에서 명령을 보내고 시뮬레이터의 LED 변화를 확인한다.

소켓·스레드·UDP 검색은 제공 코드다. 이번 주 학생이 만드는 부분은 연결 화면과 제어 버튼이다.

## 완성 화면

```text
내 방 제어                         내 방 제어
시뮬레이터 주소                     책상 조명 (LED 0)
[10.0.2.2:8266      ]               [조명 켜기] [조명 끄기]
[제어 시작]                        상태: 준비됨
상태: 연결 중                      보냄: on 0
                                   [연결 화면]
```

1일차에는 연결 화면에서 `준비됨`까지 확인한다. 2일차에는 연결 성공 후 제어 화면으로 이동하고 LED를 조작한다.

## 2일 수업 흐름

| 일차 | 설명·시연 30분 | 실습 60분 |
|---|---|---|
| 1일차 | 시뮬레이터 실행, LAN 주소와 포트, 연결 버튼 | 새 프로젝트와 연결 화면, 연결 성공·실패 확인 |
| 2일차 | 성공 후 화면 전환, 켜기·끄기 명령 | 제어 화면 구성, LED 0 조작, 재연결 |

## 준비

Android Studio의 Empty Views Activity로 `RoomControl`, 패키지 `com.example.roomcontrol`을 새로 만든다. [공통 코드 설치](../../../tools/wleno/android/README.md)를 따른다.

PC에서는 저장소의 `tools/wleno`로 이동해 `uv run main`을 실행한다. 같은 PC의 에뮬레이터는 `10.0.2.2:8266`으로 연결한다. 실기기를 쓰면 휴대전화 Wi-Fi와 PC 유선 LAN/Wi-Fi를 같은 LAN으로 연결하고 PC의 IPv4 주소를 넣는다. [연결 점검 안내](../../iot_sim/lab.md)

## 완료 기준과 제출

연결 화면 캡처 한 장과 제어 화면·시뮬레이터 LED 0이 함께 보이는 캡처 한 장을 제출한다. `MainActivity.kt`, `ControlActivity.kt`, 두 화면 XML도 제출한다.

연결 성공 후 제어 화면이 열리고, 두 버튼으로 LED 0을 켰다 끌 수 있으면 이번 주 목표를 달성한 것이다. 실패했을 때 앱이 종료되지 않고 다시 연결할 수 있는지도 확인한다. 소켓 내부 구현, UDP 검색, 연락처와 BLE 권한은 평가하지 않는다.

다음 [12주차](../week12_lighting_control/README.md)는 같은 제어 화면에서 조명을 선택하고 밝기를 조절한다.
