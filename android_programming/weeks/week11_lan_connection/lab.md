# 11주차 실습: 연결 화면과 책상 조명

완성할 동작은 주소 입력 → 연결 성공 → 제어 화면 → 조명 켜기·끄기다. 통신 라이브러리는 제공된 것을 사용한다.

## 1일차 실습 60분

| 시간 | 할 일 | 확인 |
|---|---|---|
| 0~15분 | WlEno 실행, RoomControl 새 프로젝트와 AAR 설치 | 시뮬레이터 창과 앱 실행 |
| 15~35분 | 연결 화면과 연결 버튼 구성 | 주소 입력 후 준비됨 |
| 35~50분 | 해제와 실패 후 다시 연결 | 앱 종료 없이 연결 안 됨·끊김 확인 |
| 50~60분 | 연결 성공 화면 캡처 | 주소·준비됨 표시 |

[따라하기 1~5단계](walkthrough.md#1일차-연결-화면)를 따른다. 이전 프로젝트의 권한 화면과 가짜 장치 목록은 가져오지 않는다.

아래 표를 직접 확인한다.

| 조작 | 예상 결과 | 확인 |
|---|---|---|
| 실행 중인 WlEno에 `10.0.2.2:8266`으로 연결 | 준비됨 | |
| [해제] | 연결 안 됨 | |
| 시뮬레이터 종료 후 연결 | 끊김, 앱은 실행 유지 | |
| 시뮬레이터 재실행 후 연결 | 준비됨 | |

## 2일차 실습 60분

| 시간 | 할 일 | 확인 |
|---|---|---|
| 0~15분 | 제어 화면 XML과 Activity 추가 | 두 개의 조명 버튼 표시 |
| 15~30분 | 연결 성공 뒤 화면 전환 | 연결된 경우에만 제어 화면 진입 |
| 30~45분 | 조명 켜기·끄기 구현 | PC의 LED 0 변화 |
| 45~55분 | 끊김 뒤 연결 화면에서 재연결 | 제어 버튼 복구 |
| 55~60분 | 캡처와 코드 제출 | 앱·시뮬레이터 결과 일치 |

[따라하기 6~9단계](walkthrough.md#2일차-연결-성공-후-제어-화면)를 따른다.

| 버튼 | 보낼 명령 | 관찰할 곳 |
|---|---|---|
| 조명 켜기 | `on 0` | 시뮬레이터의 LED 0 |
| 조명 끄기 | `off 0` | 시뮬레이터의 LED 0 |
| 연결 화면 | 연결 해제 후 첫 화면 | 주소 입력과 제어 시작 |

## 제출과 평가

제출물은 연결 화면 캡처, 제어 화면과 켜진 LED 0이 함께 보이는 캡처, 두 Activity와 두 화면 XML이다. 실제 휴대전화나 실물 보드는 필요 없다.

| 확인 항목 | 통과 기준 |
|---|---|
| 연결 | 올바른 주소로 연결 성공 |
| 화면 전환 | 성공 뒤 제어 화면 표시 |
| 조작 | LED 0 켜기와 끄기 모두 동작 |
| 다시 연결 | 끊긴 뒤 첫 화면에서 연결·제어 재개 |

오류가 나면 [따라하기 오류 확인](walkthrough.md#오류-확인)을 본다. 통신 내부 구현과 UDP 검색은 제출하지 않는다.

## 선택 연습

먼저 끝났으면 제어 화면의 제목을 자신이 제어할 조명의 이름으로 바꾼다. LED 번호를 0에서 1로 바꿔 앱의 표시와 시뮬레이터의 대상이 함께 바뀌는지 확인한다. 번호 선택 기능은 다음 주에 추가한다.
