# 과제 채점표 · 계획안 10점과 최종 제출 20점

[과제 안내](project_brief.md)의 필수 기능을 평가한다. 실물 보드와 UDP 검색은 평가하지 않는다. 에뮬레이터와 PC의 WlEno로 같은 기준을 적용한다.

## 계획안 발표 · 10점

| 항목 | 배점 | 만점 기준 | 부분 점수 |
|---|---|---|---|
| 앱 목적과 화면 | 2 | 연결·제어 화면과 방 제어 목적이 맞음 | 화면 또는 목적만 있으면 1 |
| 현재 기능과 추가 기능 | 2 | 조명 제어와 입력 표시 계획을 구분 | 일부만 구분하면 1 |
| 명령과 UI 대응 | 2 | 조작에 맞는 실제 명령을 작성 | 한 대응이 맞지 않으면 1 |
| 일정과 실행 환경 | 1 | 남은 일정과 시연 환경 작성 | 한 가지가 없으면 0.5 |
| 현재 앱 시연 | 1.5 | 연결 뒤 선택한 조명 제어 | 연결 또는 제어까지만 되면 0.5~1 |
| 개인 코드 설명 | 1.5 | 명령 또는 응답 코드 한 곳을 찾아 설명 | 코드 위치만 찾으면 0.5 |

항목의 근거가 없으면 해당 항목은 0점이다. 아직 배우지 않은 온습도·호출 기능이 동작하지 않는다는 이유로 계획안 점수를 깎지 않는다.

## 최종 시연 · 12점

| 항목 | 배점 | 만점 기준 | 부분 점수 |
|---|---|---|---|
| 연결과 화면 이동 | 2 | 제어 시작 뒤 제어 화면 열림 | 연결만 되면 1 |
| 조명 선택·켜기·끄기 | 2 | 선택한 조명이 각각 동작 | 일부만 동작하면 1 |
| 밝기와 결과 표시 | 2 | 선택한 밝기 적용, 응답 뒤 완료 표시 | 둘 중 하나만 되면 1 |
| 온습도 표시 | 2 | 시뮬레이터 현재 값과 앱 표시 일치 | 값은 받지만 표시가 잘못되면 1 |
| 호출 이벤트 | 2 | 입력 버튼 조작을 앱에서 확인 | 수신 근거만 있고 표시가 없으면 1 |
| 종료와 다시 제어 | 2 | 연결 화면으로 돌아간 뒤 다시 제어 | 종료 또는 재연결 한쪽만 되면 1 |

## 실행 보고서 · 8점

| 항목 | 배점 | 만점 기준 | 부분 점수 |
|---|---|---|---|
| 실행 방법 | 2 | WlEno 시작·앱 실행·주소가 재현 가능 | 일부 빠지면 1 |
| 기능 캡처 | 2 | 조명·온습도·호출의 증거 3장 | 1~2장만 확인되면 1 |
| 코드 설명 | 2 | 수정 파일과 명령·응답 처리 설명 | 위치 또는 설명만 있으면 1 |
| 시연 순서와 제한 | 2 | 2~3분 순서, 해결한 문제 또는 제한 기록 | 둘 중 하나만 있으면 1 |

계획안 10 + 최종 시연 12 + 보고서 8 = 총 30점이다. 같은 원인으로 여러 항목을 중복 감점하지 않는다. 장비·네트워크 장애는 기록을 확인하고 같은 PC의 에뮬레이터로 다시 시연할 수 있다. 재제출, 지각과 부정행위는 대학 규정과 수업 공지를 따른다.
