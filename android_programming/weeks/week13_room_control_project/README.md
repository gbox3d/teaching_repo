# 13주차 · 내 방 제어 시나리오와 계획안

책상 조명과 침대 조명이 상황에 맞게 바뀌는지 점검한다. 2일차에는 이 화면에 추가할 온습도와 호출 표시를 계획한다. 새로운 통신 API를 구현하지 않는다.

독립 프로젝트 `RoomControl`을 사용한다. 새 프로젝트를 만들 때는 공통 설정을 따른다. 기존 자료는 [BLE 특강](../../specials/legacy_week13_ble_output/README.md)에 보존되어 있다.

## 학습 목표

- 공부 준비·취침 준비·외출의 제어 순서를 설명한다.
- 조작, 명령, 응답, 시뮬레이터 결과를 비교한다.
- 현재 기능과 앞으로 추가할 입력 기능을 나누어 계획한다.

## 수업 흐름

| 일차 | 설명·시연 30분 | 실습 60분 |
|---|---|---|
| 1일차 | 방 제어 시나리오와 사용자 확인 | 상황별 조명 점검 |
| 2일차 | 과제 범위와 발표 예시 | 계획안 발표와 피드백 |

## 준비와 자료

12주차의 내 방 제어 앱과 WlEno를 준비한다. 프로젝트가 없으면 [공통 설정](../../../tools/wleno/android/README.md)과 [완성 예제](examples/README.md)로 새 Empty Views Activity를 만든다. 1일차 완성본은 12주차 2일차와 같은 제어 기능이다.

- [슬라이드](slides.md), [영문 슬라이드](slides_en.md)
- [따라하기](walkthrough.md), [실습지](lab.md)
- [과제 안내](project_brief.md), [채점표](rubric.md)

## 완료 기준

- 연결 화면에서 제어 화면을 연다.
- 선택한 조명의 켜기·끄기·밝기 조절을 재현한다.
- 명령이 전송된 뒤 서버 응답으로 완료 표시가 바뀌는지 확인한다.
- 계획안에 현재 화면, 추가할 입력 표시, 명령 목록, 남은 일정을 적는다.

14주차에는 제어 화면에서 실내 온습도를 읽고 호출 이벤트를 확인한다. 실물 보드와 UDP 검색은 필수 평가 항목이 아니다.
