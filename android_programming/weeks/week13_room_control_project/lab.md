# 13주차 실습 · 방 제어 시나리오와 발표

## 1일차 · 설명 30분 뒤 점검 60분

| 시간 | 할 일 | 결과 |
|---|---|---|
| 0~10분 | WlEno 시작과 앱 연결 | 제어 화면 |
| 10~25분 | 공부 준비·취침 준비·외출 순서 작성 | 조작 순서표 |
| 25~40분 | 순서대로 제어하고 응답 확인 | 시뮬레이터와 앱 비교 |
| 40~50분 | 동료가 순서 재현 | 사용자 점검 |
| 50~60분 | 코드 설명과 계획안 초안 | 현재 기능 기록 |

## 2일차 · 설명 30분 뒤 발표 60분

계획안 1쪽과 현재 앱을 준비한다. 1인 3분이면 60분에 20명이 발표할 수 있다. 분반 인원이 더 많으면 발표 길이와 순서는 수업 공지를 따른다. 발표 후 받은 의견 한 가지를 계획안에 반영한다.

## 제출

1일차에는 상황별 조작 순서표와 제어 캡처를 준비한다. 2일차에는 계획안 1쪽을 제출하고 앱을 실행해 발표한다. 계획안 10점과 15주차 최종 제출 20점은 [채점표](rubric.md)를 따른다. 실물 장비 보유 여부나 UDP 검색 여부는 점수에 포함하지 않는다.

## 막혔을 때

| 증상 | 확인 |
|---|---|
| 다른 조명이 바뀐다 | 선택 RadioButton과 `selectedLamp()`의 LED 번호 |
| 슬라이더만 움직이면 변화가 없다 | [밝기 적용]을 눌렀는지 확인 |
| 완료 글자와 원본 JSON이 맞지 않는다 | `result`를 확인하는 `when` 구문 |
| 다시 연결했더니 조명이 꺼졌다 | 연결은 LED 상태를 유지한다. 다른 명령·화면 초기화 여부를 로그에서 확인 |

먼저 끝나면 코드 한 곳의 설명을 동료에게 해 본다. 명령을 만드는 줄과 응답을 표시하는 줄을 구분한다.
