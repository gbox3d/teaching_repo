# a01_kotlin_card — Kotlin Playground 학생 카드

출처: [1주차 실습 제출](../../../week01_android_kotlin/lab.md#제출--두-가지만) · 권장 8분 · 범위 1주

1주차에 한 것처럼 Kotlin Playground(또는 Android Studio 의 `.kt` 파일)에서 학번·이름과 통과 여부를 세 줄로 출력한다.

## 할 일

1. `fun main()` 안에 `val` 세 개를 만든다. 학번 `"20260001"`, 이름 `"홍길동"`, 점수 `72`.
2. `println` 으로 두 줄을 출력한다. `학번: 20260001`, `이름: 홍길동`. 글자 안에 변수 값을 `$변수` 로 넣는다.
3. 함수 `grade(score: Int)` 를 만든다. 점수가 `70` 이상이면 `"통과"`, 아니면 `"재시험"` 을 돌려준다(`if/else` 한 줄).
4. `println("결과: ${grade(score)}")` 로 셋째 줄을 출력한다.
5. 실행해서 세 줄이 보이는 화면을 캡처한다.

## 확인할 것

- [ ] 출력이 정확히 세 줄이다. `학번: 20260001` / `이름: 홍길동` / `결과: 통과`.
- [ ] 점수를 `65` 로 바꾸고 다시 실행하면 셋째 줄이 `결과: 재시험` 이 된다.
- [ ] 코드에 `val`, `$`, `if`, `else`, `fun` 이 모두 보인다. 빨간 줄이 없다.

## 힌트

- 글자 안에 값 넣기: `println("학번: $studentId")`. 함수 결과를 넣을 때는 중괄호를 쓴다. `"결과: ${grade(score)}"`.
- `if` 한 줄: `val result = if (score >= 70) "통과" else "재시험"`. 함수로 쓰면 `fun grade(score: Int): String = if (score >= 70) "통과" else "재시험"`.
- `val` 은 다시 넣을 수 없는 이름, `var` 는 다시 넣을 수 있는 이름이다. 여기서는 바뀌는 값이 없으니 모두 `val` 이다.

## 이 문제의 값

| 값 | 이 문제에서 |
|---|---|
| 학번 | `20260001` |
| 이름 | `홍길동` |
| 점수 | `72` |
| 기준 점수(이상) | `70` |
| 기준 이상일 때 글자 | `통과` |
| 그 밖 | `재시험` |
| 다시 넣어 볼 점수 | `65` |

## 설명 물음(시험에서 1~2문장)

- `val` 과 `var` 의 차이는 무엇인가?
- `"학번: $studentId"` 에서 `$` 는 무슨 일을 하나?

시험에서는 같은 문제를 "이 문제의 값" 표의 값만 바꿔서 낸다. 문장·할 일·확인하는 방법은 그대로다. 답안에는 **코드(XML·Kotlin 가운데 고친 부분)·실행 화면 캡처·설명 물음의 답 1~2문장**을 낸다.
