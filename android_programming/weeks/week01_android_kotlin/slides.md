## 1일차 · 5–10분 — 실행할 곳 열기

브라우저에서 [Kotlin Playground](https://play.kotlinlang.org/)를 엽니다.

1. 코드 입력 칸에 선생님이 보여 주는 코드를 적습니다.
2. **Run(▶)** 버튼을 누릅니다.
3. 출력 영역에 나타난 글자를 확인합니다.

글자를 바꾼 뒤에는 **Run을 다시 눌러야** 결과가 바뀝니다.
실습실 PC를 씁니다. 개인 노트북 설치는 2일차 실습 마지막에 조교가 봐 줍니다.

## 1일차 · 10–20분 ① — 시작 틀과 첫 출력

아래 코드를 그대로 적고 실행합니다.

```kotlin
fun main() {
    println("안녕하세요")
}
```

- `fun main()`은 프로그램이 시작하는 곳입니다. 먼저 그대로 사용합니다.
- `{`와 `}` 사이에 실행할 코드를 적습니다.
- `println(...)`은 괄호 안의 내용을 출력한 뒤 줄을 바꿉니다.

## 1일차 · 10–20분 ② — 글자는 큰따옴표 안에

```kotlin
fun main() {
    println("안녕하세요")
    println("반갑습니다")
}
```

```text
안녕하세요
반갑습니다
```

글자는 `" "`로 감쌉니다. 괄호 `(`와 `)`, 큰따옴표는 짝을 맞춥니다.
닫는 큰따옴표가 빠지면 `Expecting '"'.` 오류가 납니다.

# 2일차 — Kotlin 기초 문법 더하기

`30분 설명·시연 → 60분 실습`

오늘 결과는 **학번·이름 두 줄 + 합격/불합격 한 줄**입니다.

- `val`: 값에 이름 붙이기
- `String`과 `Int`: 글자와 정수 구별하기
- `$`: 저장한 값을 문장에 넣기
- `var`: 나중에 다른 값을 넣을 수 있는 변수
- `if/else`: 조건에 따라 다른 값 고르기
- `fun`: 같은 일에 이름을 붙여 부르기

---

## 2일차 · 0–5분 — val로 값에 이름 붙이기

```kotlin
fun main() {
    val studentId = "20260001"
    val name = "홍길동"

    println(studentId)
    println(name)
}
```

`val 이름 = 값`으로 값을 저장합니다. `=`은 오른쪽 값을 넣는 표시입니다.

`println(name)`은 `name`에 저장된 값인 `홍길동`을 출력합니다.

---

## 2일차 · 5–13분 ① — 글자와 정수

```kotlin
val studentId = "20260001"  // String: 글자
val score = 85              // Int: 정수
```

- 큰따옴표 안의 글자는 **문자열**이며 자료형 이름은 `String`입니다.
- `85`처럼 소수점 없는 숫자는 **정수**이며, 자료형 이름은 `Int`입니다.
- Kotlin이 값을 보고 자료형을 알아내므로 지금은 직접 적지 않아도 됩니다.
- 학번은 계산할 숫자가 아니라 구별하는 글자이므로 큰따옴표로 감쌉니다.

`//` 뒤의 설명은 **주석**이며 실행되지 않습니다.

---

## 2일차 · 5–13분 ② — $로 문장에 값 넣기

```kotlin
fun main() {
    val studentId = "20260001"
    val name = "홍길동"

    println("학번: $studentId")
    println("이름: $name")
}
```

큰따옴표 안에서 `$이름`을 쓰면 저장된 값이 들어갑니다.

이것을 **문자열 템플릿**이라고 합니다. `$`를 빼면 `name`이라는 글자가 그대로 나옵니다.

---

## 2일차 · 13–18분 — val과 var

```kotlin
fun main() {
    var greeting = "안녕하세요"
    println(greeting)
    greeting = "반갑습니다"
    println(greeting)
}
```

- `val`: 실행 중 이미 저장한 값을 다른 값으로 다시 대입할 수 없습니다.
  다시 대입하면 `'val' cannot be reassigned.` 오류가 납니다.
- `var`: 위의 `greeting = "반갑습니다"`처럼 다시 대입할 수 있습니다.

`val name = "홍길동"`의 예시 이름을 편집하고 **다시 실행하는 것**은 가능합니다.

---

## 2일차 · 18–23분 — if/else: 조건에 따라 다른 값

```kotlin
val score = 85
val result = if (score >= 60) "합격" else "불합격"
println("결과: $result")
```

```text
결과: 합격
```

- `if (조건) 값1 else 값2`: 조건이 맞으면 `값1`, 아니면 `값2`가 됩니다.
- `score >= 60`은 "score가 60 이상인가"라는 조건입니다.
- `score`를 `50`으로 바꾸고 실행하면 `결과: 불합격`이 나옵니다.
- `else`를 빼면 오류가 납니다. 두 갈래를 모두 적습니다.

---

## 2일차 · 23–27분 — fun: 같은 일을 이름 붙여 부르기

```kotlin
fun intro(name: String) {
    println("이름: $name")
}

fun main() {
    intro("홍길동")
    intro("김철수")
}
```

- `fun intro(name: String) { ... }`: `intro`라는 **함수**를 정의합니다. `main` 바깥에 적습니다.
- `name: String`은 "글자 하나를 받아서 `name`이라고 부른다"는 뜻입니다.
- `intro("홍길동")`처럼 **호출**하면 `{ }` 안의 코드가 실행됩니다.
- `main`도 이렇게 만든 함수 중 하나입니다. 실행하면 `main`이 먼저 불립니다.

---

## 2일차 · 27–30분 — 오늘의 완성 코드·실습 인계

[2일차 실습](lab.md#2일차--변수와-if-fun으로-자기소개-완성하기-60분) · [따라하기](walkthrough.md#2일차) · **설명 합계: 5+8+5+5+4+3 = 30분**

```kotlin
fun intro(name: String) {
    println("이름: $name")
}

fun main() {
    val studentId = "20260001"
    val name = "홍길동"
    val score = 85

    println("학번: $studentId")
    intro(name)

    val result = if (score >= 60) "합격" else "불합격"
    println("결과: $result")
}
```
