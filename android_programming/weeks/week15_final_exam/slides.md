# 내 방 제어 앱 기말 실습

15주차 · RoomControl

연결 → 제어 화면 → 조명·온습도·호출 확인

1일차 리허설 / 2일차 기말 실습과 프로젝트 제출

---

# 1일차 · 0~5분: 평가 범위

구현 15점 + 시연·설명 5점

- 조명 버튼 연결
- 온습도 표시
- 호출 이력

통신 라이브러리와 연결 화면은 제공한다.

---

# 1일차 · 5~10분: 시작 코드

`examples/rehearsal_starter`를 프로젝트에 넣는다.

연결 화면과 제어 화면은 실행된다.
`ControlActivity`의 TODO 세 부분은 아직 동작하지 않는다.

실제 시험 문항은 학기별로 별도 공지한다.

---

# 1일차 · 10~15분: TODO 1 조명 버튼

책상 조명 선택 기준

[켜기] → `on 0`
[끄기] → `off 0`

기존 `send`를 호출한다.
시뮬레이터 LED 0의 변화로 확인한다.

---

# 1일차 · 15~20분: TODO 2 온습도

[온습도 확인] → `dht11`

`value` 문자열 → `JSONArray` → 두 숫자

온도에는 °C, 습도에는 %를 표시한다.
슬라이더를 바꾸고 다시 요청하여 확인한다.

---

# 1일차 · 20~25분: TODO 3 호출 이력

시뮬레이터 [입력 버튼] → `event: input`

`index`와 `value`를 읽는다.
한 번의 입력을 한 줄로 추가한다.

온습도 응답은 호출 이력에 넣지 않는다.

---

# 1일차 · 25~30분: 리허설 점검

| 확인 | 기대 결과 |
|---|---|
| 조명 켜기·끄기 | LED 변화 |
| 온습도 확인 | 슬라이더 값 표시 |
| 입력 두 번 | 호출 두 줄 |
| 연결 끊기 | 제어 비활성 |

---

# 리허설 실습 60분

0~10분 연결 확인
10~25분 조명 버튼
25~40분 온습도 표시
40~50분 호출 이력
50~60분 자기 점검과 완성본 비교

---

# 2일차 · 0~10분: 환경 확인

WlEno와 에뮬레이터 실행
LAN 주소·TCP 8266 확인
제어 화면 진입 확인

장비 장애는 강의자에게 알려 기록한다.

---

# 2일차 · 10~20분: 평가 진행

기말 실습 60분

문항 확인 → 구현 → 순회 시연·구술 → 저장·제출

수정 대상은 공지된 파일이다.
공개 완성본의 사용 범위는 시험 공지를 따른다.

---

# 2일차 · 20~30분: 시연 순서

1. 연결 화면에서 연결
2. 책상 조명 켜기·끄기
3. 온습도 재확인
4. 호출 버튼 두 번
5. 버튼 또는 수신 콜백의 실행 시점 설명

---

# 제출 확인

기말 실습 코드와 프로젝트 최종 제출물은 별개다.

코드를 저장하고 마지막으로 실행한다.
파일 이름과 제출 위치를 확인한다.

프로젝트 제출 기준은 13주차 과제 안내를 따른다.
