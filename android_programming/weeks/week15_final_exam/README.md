# 15주차: 내 방 제어 앱 기말 실습

연결 화면에서 시뮬레이터에 연결하고 제어 화면에서 책상 조명, 실내 온습도, 호출 이력을 확인한다. 평가는 11~14주차에 만든 화면과 버튼 동작을 대상으로 한다.

## 학습 목표

- 제공된 연결 코드를 사용하여 제어 화면을 연다.
- 버튼 클릭을 조명 명령에 연결한다.
- 온습도 응답과 호출 이벤트를 각각 알맞은 화면에 표시한다.
- 시뮬레이터에서 결과를 확인하고 동작 순서를 설명한다.

## 수업 운영

| 일차 | 설명·안내 30분 | 실습·평가 60분 |
|---|---|---|
| 1일차 | 평가 기준, 시작 코드와 TODO 위치, 시뮬레이터 점검 | 리허설 작성, 자기 점검, 완성본 비교 |
| 2일차 | 기기·연결 확인, 제출 방식과 평가 순서 안내 | 기말 실습, 순회 시연·구술, 제출 |

공개 [리허설 시작 코드](examples/rehearsal_starter/)는 연결 화면과 제어 화면이 실행되는 상태다. 조명 버튼, 온습도 표시, 호출 이력의 세 부분만 비어 있다. [완성 코드](examples/rehearsal_solution/)는 연습용 답안이다. 실제 시험 문항은 학기별로 별도 공지한다.

## 준비

PC의 WlEno와 Android 에뮬레이터를 준비한다. 실기기를 사용할 때도 같은 시뮬레이터와 평가 기준을 쓴다. 실제 보드, 연락처 접근, 블루투스 권한은 평가 조건이 아니다.

`RoomControl` 프로젝트(package `com.example.roomcontrol`)에 공통 [WlEno AAR](../../../tools/wleno/android/README.md)과 리허설 파일을 넣는다. WlEno와 같은 PC의 에뮬레이터 연결 주소는 `10.0.2.2:8266`이다. 다른 PC의 에뮬레이터나 실기기는 [주소와 방화벽 조건](../../iot_sim/lab.md#2-앱에-넣을-주소-결정)을 확인한다. 소켓·UDP 구현은 제공 코드이므로 채점 대상에서 제외한다.

## 완료 기준

- [ ] 앱에서 연결한 뒤 제어 화면이 열린다.
- [ ] 책상 조명 버튼으로 시뮬레이터 LED 0이 켜지고 꺼진다.
- [ ] 온습도 확인 결과가 시뮬레이터 값과 일치한다.
- [ ] 호출 버튼을 두 번 누르면 앱에 두 번의 호출이 표시된다.
- [ ] 제어 동작 한 개를 클릭 → 요청/입력 → 표시 순서로 설명한다.
- [ ] 실습 코드와 프로젝트 최종 제출물을 공지된 위치에 제출한다.
