# 15주차 공개 시험 자료

이 폴더는 기말 개인 실기의 **공개 구조와 평가 계약만** 제공한다.

- [시험 blueprint](exam_blueprint.md)
- [20점 rubric](rubric.md)
- [starter 공개 구조](starter/README.md)

## 포함하지 않는 자료

- 실제 prompt
- 정답·완성 코드
- 비공개 평가 사례와 내부 채점 메모
- 학생별 변형 값과 학생 데이터

## 공개 원칙

- 총점은 구현 15점 + 시연 5점 = 20점이다.
- 시험은 개인 구현과 개인 설명을 확인한다.
- Android 앱과 제공 BLE abstraction 사용을 평가하며 firmware 작업은 제외한다.
- 실제 허용 자료·도구·제출 방식·시간 보정은 시험/LMS 공지가 최종 기준이다.
- starter placeholder는 빌드 가능한 Gradle 프로젝트를 주장하지 않는다.
