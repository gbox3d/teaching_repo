# 기말 실기 채점표: 내 방 제어

총 20점으로 평가한다. 구현 15점과 시연·설명 5점을 구분한다. 통신 라이브러리, UDP 검색, 소켓 시간 제한은 제공 기능이며 구현 점수에 넣지 않는다.

## 구현 15점

| 항목 | 확인 기준 | 점수 |
|---|---|---:|
| 조명 켜기 | 버튼에서 선택한 조명 켜기 명령 전송 | 2 |
| 조명 끄기 | 버튼에서 선택한 조명 끄기 명령 전송 | 2 |
| 버튼 연결 | 켜기·끄기 버튼을 각각 알맞은 동작에 연결 | 1 |
| 온습도 값 읽기 | `value` 문자열에서 온도·습도 읽기 | 2 |
| 온습도 표시 | 두 값과 단위를 알맞은 위치에 표시 | 2 |
| 온습도 갱신 | 다시 요청한 결과로 화면 갱신 | 1 |
| 호출 값 읽기 | 입력 이벤트의 `index`·`value` 읽기 | 2 |
| 호출 이력 | 두 번의 입력을 두 줄로 표시 | 2 |
| 수신 구분 | 온습도 응답을 호출 이력에 추가하지 않음 | 1 |

리허설 시작 코드의 TODO 1·2·3이 각각 5점에 대응한다. 실제 문항이 리허설과 다르면 같은 학습 목표 안에서 기준과 시작 코드를 함께 공지한다.

## 시연·설명 5점

| 항목 | 확인 기준 | 점수 |
|---|---|---:|
| 연결 | 주소 입력 후 제어 화면 표시 | 1 |
| 출력 | 책상 조명 켜기·끄기 시연 | 1 |
| 센서 | 슬라이더 변경 후 온습도 다시 확인 | 1 |
| 호출 | 입력 버튼 두 번과 호출 이력 시연 | 1 |
| 설명 | 버튼 리스너 또는 수신 콜백 한 곳의 실행 시점을 설명 | 1 |

모든 학생은 WlEno를 사용한다. 같은 PC의 에뮬레이터 시연과 같은 LAN의 실기기 시연은 같은 기준을 적용한다.

## 채점 절차

1. 시작 프로젝트 사본에 제출 파일을 넣고 빌드한다.
2. 시뮬레이터를 실행하고 앱에서 연결한다.
3. 책상 조명, 온습도, 호출 순서로 확인한다.
4. 한 원인에서 생긴 같은 오류는 중복 감점하지 않는다.
5. 실행이 실패하면 첫 오류와 관련 구현 흔적을 기록한다.

구현 점수가 5점보다 낮아도 TODO에 요구와 관련된 코드 작성 흔적이 있으면 구현 점수를 5점으로 한다. 시작 코드를 수정하지 않은 제출, TODO 주석만 지운 제출, 요구와 관계없는 코드는 해당하지 않는다. 시연 점수에는 이 기준을 적용하지 않는다.

장비·LAN 장애는 강의자가 별도로 기록하고 환경을 복구한 뒤 재확인한다. 실제 보드와 연락처 접근은 요구하지 않는다. 프로젝트 최종 제출 평가는 [13주차 프로젝트 채점표](../week13_room_control_project/rubric.md)로 별도 진행한다.
