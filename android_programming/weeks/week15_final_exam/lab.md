# 15주차 개인 실기 진행지 — 공개판

이 문서는 시험 진행·검증·제출을 위한 공개 worksheet다. 실제 문제, 정답, 비공개 평가 사례, 학생별 값은 포함하지 않는다. 실제 요구와 허용 자료는 시험 당일 공지를 따른다.

## 공개 운영 시나리오

학생은 감독 신호 뒤 검증된 starter와 당일 요구를 받고, 현재 동작을 기록한 다음 최소 변경으로 구현한다. 정상·경계·실패를 검증하고 최종 제출본을 개인 시연·구술로 설명한다. 이 공개판은 그 진행 틀만 제공하며 문제 내용은 제공하지 않는다.

> **DEMO_CAPACITY_TBD:** 개강 전에 `N=분반 인원`, `E=동시 평가자 수`, `D=학생당 시연 분`을 확정하고 `T_demo = ceil(N / E) × D ≤ 60분`을 검증한다. 실패하면 `E`를 늘려 병렬 평가하거나 모든 학생에게 같은 별도 공식 슬롯을 공지한다. 일부 학생의 시연 또는 실기시간을 줄여 식을 맞추지 않는다.

## 2일차 60분 — 실패 검증과 개인 시연

### 시간표 — 합계 60분

- 0~10분: 배포/중간 저장 상태 확인, 미완료 항목 우선순위 결정
- 10~25분: 지정 실패·복구 구현과 정상 회귀
- 25~40분: 정상·경계·실패 최종 검증, 로그·화면 증거 정리
- 40~55분: 최종 제출 준비·증거 정리, 사전 수용량 검증을 통과한 배정 시연 병행
- 55~60분: 제출 성공 화면·SHA·개인 기록 확인, 배정 시연 종료 점검

개인 시연을 마지막 15분에 전원 순차 배치한다는 뜻이 아니다. 검증된 `N/E/D` 일정에 따라 60분 블록에서 병렬 운영하되 모든 학생에게 같은 `D`와 같은 실기시간을 보장한다. 이를 만족하지 못하면 모든 학생에게 공지된 별도 공식 슬롯에서 동일 조건으로 평가한다.

## 확장 대신 할 일

시험 시간에는 공지되지 않은 기능을 확장하지 않는다. 시간이 남으면 다음만 수행한다.

- 정상 경로 회귀 테스트
- 경계·실패 증거 명확화
- 불필요한 secret·개인정보 제거
- 제출본과 SHA 일치 확인
- 코드 설명 연습
