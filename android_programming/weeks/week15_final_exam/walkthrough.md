# 15주차 따라하기: 리허설 완성

## 1. 시작 코드 실행

`examples/rehearsal_starter` 파일을 [예제 위치 표](examples/README.md)대로 `RoomControl`에 넣는다. 파일을 중복해서 추가하지 않고 같은 이름의 파일을 교체한다. `app/libs/wleno-android-0.1.0.aar`와 Gradle 의존성은 유지한다.

PC에서 `tools/wleno`의 `uv run main`을 실행하고 앱에서 연결한다. 제어 화면은 열리지만 비어 있는 TODO 기능은 동작하지 않는다. 통신 코드를 새로 작성하지 않는다.

## 2. TODO 1: 책상 조명 버튼

`ControlActivity.onCreate`의 켜기·끄기 리스너를 찾는다. 선택한 조명 번호를 `selectedLamp()`로 읽고 켜기는 `on 번호`, 끄기는 `off 번호`를 기존 `send`에 전달한다. 책상 조명을 선택한 경우 각각 `on 0`과 `off 0`이다. 시뮬레이터 LED 0이 책상 조명이다.

앱 버튼을 번갈아 누르고 LED 0의 상태와 화면 안내를 확인한다. TCP 줄바꿈은 공통 클라이언트가 붙인다.

## 3. TODO 2: 온습도 표시

`showSensor`를 완성한다. 받은 JSON에서 `value` 문자열을 꺼내 `JSONArray`로 읽는다. 0번은 온도, 1번은 습도다. `sensorText`에 단위를 포함해 표시한다. 이 함수는 `result`가 `ok`인 온습도 응답일 때만 호출된다.

시뮬레이터 슬라이더를 바꾸고 [온습도 확인]을 누른다. 바꾸기 전후의 앱 값이 시뮬레이터와 일치하는지 확인한다.

## 4. TODO 3: 호출 이력

`showInput`을 완성한다. 이벤트의 `index`와 `value`를 읽어 호출 이력 목록에 한 줄 추가한다. 시뮬레이터 이벤트는 `index:0`이며 `value`는 누를 때마다 1과 0을 번갈아 보낸다.

[입력 버튼]을 두 번 눌러 호출 이력 두 줄을 확인한다. [온습도 확인]을 눌렀을 때 호출 이력까지 추가되지 않아야 한다.

## 5. 연결 중단 확인

WlEno의 [연결 끊기]를 누르면 앱의 제어 버튼이 꺼진다. [연결 화면]으로 돌아가 다시 연결한다. 이 기능은 제공 코드에 있으며 새 연결 관리 코드를 요구하지 않는다.

앱을 배경으로 보내거나 화면을 회전하면 연결을 닫는다. 돌아온 뒤 연결 화면에서 다시 연결한다. 호출 이력은 새 제어 화면에서 새로 시작한다.

## 6. 완성본과 비교

먼저 [실습지](lab.md)의 자기 점검을 한 뒤 `rehearsal_solution/ControlActivity.kt`와 비교한다. 함수 전체를 덮어쓰기 전에 빠진 호출·값·표시 대상이 무엇인지 한 줄로 기록한다.

## 7. 기말 평가와 프로젝트 제출

기말 실습은 공지된 시작 코드와 문항으로 진행한다. 평가자는 앱 연결, 책상 조명, 온습도, 호출 순서로 확인한다. 학생은 버튼이나 수신 콜백 한 곳이 언제 실행되는지 설명한다.

기말 코드 제출과 프로젝트 최종 제출은 별개다. 프로젝트는 [13주차 안내](../week13_room_control_project/project_brief.md)의 코드·화면·설명 자료를 공지된 마감에 제출한다.
