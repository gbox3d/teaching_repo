# RoomControl 수업 전 LAN 연결 점검

정규 수업은 [11주차](../weeks/week11_lan_connection/README.md)에서 새 앱을 만든다. 이 문서는 수업 전에 시뮬레이터와 네트워크를 확인하는 안내다. 학생의 목표는 연결 뒤 제어 화면에서 조명을 켜고 끄는 것이다.

## 1. PC에서 시뮬레이터 실행

저장소의 `tools/wleno` 폴더에서 실행한다.

```powershell
uv run main
```

창에 LED 네 개와 온습도 조절기가 보이면 준비가 끝난다. 창을 연 상태로 둔다. 설치와 실행 옵션은 [WlEno 안내](../../tools/wleno/README.md)를 따른다.

## 2. 앱에 넣을 주소 결정

| 실행 환경 | 앱 주소 | 준비 |
|---|---|---|
| 시뮬레이터와 같은 PC의 Android 에뮬레이터 | `10.0.2.2:8266` | 기본 수업 경로 |
| 다른 PC에서 WlEno를 실행한 경우의 Android 에뮬레이터 | `WlEno 실행 PC의 LAN IPv4:8266` | 두 PC 사이의 LAN 통신 허용 |
| Android 휴대전화 | `WlEno 실행 PC의 LAN IPv4:8266` | 휴대전화는 Wi-Fi, PC는 같은 LAN의 유선 또는 Wi-Fi |

`10.0.2.2`는 에뮬레이터를 실행한 PC만 가리킨다. WlEno가 다른 PC에 있으면 에뮬레이터도 그 PC의 LAN 주소를 사용한다. `127.0.0.1`은 Android 기기 자신이므로 WlEno 주소로 사용하지 않는다.

실기기는 시스템 Wi-Fi 설정에서 수업 네트워크를 선택한다. PC 주소는 WlEno를 실행한 PC의 Windows `ipconfig`에서 확인한다. VPN·가상 어댑터가 아닌 수업 LAN 주소를 사용한다. 같은 SSID여도 단말 격리가 있으면 접속할 수 없다.

앱은 TCP 8266을 사용한다. UDP 8267 검색은 선택 사항이고, HTTP 8080은 조교용 보조 API다. 앱 주소에 `http://`를 넣지 않는다.

다른 PC나 실기기에서 접속하려면 WlEno 실행 PC의 방화벽에서 TCP 8266 인바운드를 허용해야 한다. 인터넷 외부에서는 LAN 주소만 입력해 접속할 수 없다. 별도 네트워크 구성이 필요한 외부 접속은 정규 필수 과제가 아니다.

## 3. 연결과 제어 확인

[공통 라이브러리 AAR 설치](../../tools/wleno/android/README.md)를 마친 [11주차 2일차 예제](../weeks/week11_lan_connection/examples/day2/)로 확인한다.

1. 연결 화면에 주소를 넣고 [제어 시작]을 누른다.
2. 연결이 성공하면 제어 화면이 열린다.
3. [조명 켜기]를 누르면 시뮬레이터의 LED 0이 켜진다.
4. [조명 끄기]를 누르면 LED 0이 꺼진다.
5. [연결 화면]으로 돌아간 뒤 다시 연결한다.

연결·해제 때 시뮬레이터는 LED를 끈다. 시뮬레이터 하나를 여러 학생이 함께 쓰면 다른 학생의 연결이 LED 상태에 영향을 준다. 한 학생당 자기 PC의 시뮬레이터 한 개를 사용한다.

## 4. 접속이 안 될 때

| 현상 | 확인 순서 |
|---|---|
| 곧바로 연결 실패 | 시뮬레이터 실행 여부 → IP 주소 → 포트 8266 |
| 다른 PC의 에뮬레이터·휴대전화에서만 실패 | WlEno 실행 PC의 LAN 주소인지 → 단말 격리 → PC의 TCP 8266 방화벽 |
| 검색 결과 없음 | UDP 검색 없이 IP 직접 연결 |
| 제어 화면에서 조작 불가 | 연결 상태 확인 → 연결 화면으로 돌아가 재연결 |
| 연결했는데 LED가 꺼짐 | 연결 때 초기화되는 정상 동작. 연결 뒤 [조명 켜기] 실행 |

다른 PC나 실기기의 접속을 허용해야 하면 조교가 [방화벽 설정](../../tools/wleno/README.md#7-windows-방화벽)을 확인한다. 학생 실습은 같은 PC 에뮬레이터로 계속 진행한다. 인터넷 연결 성공만으로 PC 시뮬레이터 접속까지 확인한 것은 아니다.
