# AI 실습 공용 시뮬레이터 제어 도구

오픈소스 AI 10~13주차가 같은 연결·검증·평가 함수를 사용한다.
시뮬레이터 본체는 [bleuno-sim](../bleuno-sim/README.md)이다.
이 폴더는 표준 라이브러리로 제어하고, Needle 추론·학습은 선택 의존성으로 제공한다.

저장소 전체를 복제한 상태에서 주차의 `examples/`로 이동해 `uv sync`한다.
각 프로젝트의 `tool.uv.sources`가 이 폴더를 가리킨다. 주차 폴더만 떼어 복사하면 이 상대 경로가 끊어진다.
제공 코드는 공용 라이브러리로 두고, 학생은 교시 예제·상수·학습 데이터를 수정한다.

## 파일과 호출 경계

| 위치 | 역할 |
|---|---|
| [제어 함수](src/bleuno_control/__init__.py) | TCP 연결, 이벤트 건너뛰기, 전체 호출 목록의 검증, 실행·상태 조회 |
| [모델 연결](src/bleuno_control/models.py) | Ollama와 Needle 응답을 같은 호출 목록으로 변환 |
| [평가](src/bleuno_control/evaluation.py) | 초기 상태 복원, 호출·인자·실제 상태·오호출·시간 비교 |
| [학습](src/bleuno_control/training.py) | 데이터 검사, LoRA 학습, 같은 조건의 기본·학습 모델 저장 |
| [도구 스키마](src/bleuno_control/data/tools.json) | 모델에게 알려 줄 네 함수와 인자 범위 |
| [평가 문항](src/bleuno_control/data/control_cases.json) | 한국어 8·영어 8문항, 호출 10·무호출 6문항 |

모델은 `name`·`arguments` 목록만 제안한다. 실행기는 등록된 함수와 정확한 필드,
정수 타입, LED 0~3, 밝기 0~255를 검사한다. bool·소수·문자열 숫자도 거절한다.
모든 호출을 먼저 검사하므로 뒤쪽 인자가 틀리면 앞쪽 호출도 실행하지 않는다.
범위가 맞는 호출이라도 사용자 의도와 다를 수 있으므로 제어 성공률은 따로 측정한다.

TCP 연결을 한 실습 동안 유지한다. 시뮬레이터에 새로 연결하거나 끊으면 LED가 초기화된다.
`GET /state`로 LED를 확인한다. 센서는 `dht11` 응답의 문자열 `value`를 JSON 배열로 읽는다.
센서 조작용 `POST /set`은 모델 도구에 포함하지 않는다.
응답 순서를 확인할 수 없는 연결은 닫는다. CLI는 다시 실행하고, 앱은 연결 해제 후 다시 연결한다.

## 평가 조건

문항마다 LED를 `[0, 64, 128, 255]`로 맞춘다. 모델 예열 요청은 실행하지 않으며 평가에서 제외한다.
함수 선택 정확도는 이름·순서, 호출 완전일치는 이름·인자·순서를 비교한다.
제어 성공은 호출이 완전히 맞고 실제 상태도 목표와 일치하며 실행 오류가 없어야 한다.
센서를 읽는 문제는 온습도 반환값까지 대조한다. 잘못된 `ok` 응답만으로 성공을 인정하지 않는다.

무호출 6문항에서 호출을 제안한 비율을 오호출률로 쓴다. 검증기에 막힌 호출도 제안한 사실은 센다.
모델·장치 실행 오류는 별도 건수와 실패로 남기고 모든 16문항을 분모로 사용한다.
언어별 성공률도 함께 표시한다. 응답 시간은 모델 준비·시뮬레이터 제어 시간을 제외한 추론 시간이며,
중앙값과 최근접 순위 방식의 p95를 표시한다. 16문항의 p95는 최댓값이므로 일반적인 지연시간 보장으로 해석하지 않는다.
장치 오류로 추론을 시작하지 못한 문항은 시간을 미측정으로 남긴다. `latency_count`로 시간 집계의 표본 수를 확인한다.

## 같은 양자화로 학습 전후 비교

기본 Needle 배포본과 로컬 학습본의 양자화가 다르다. 학습 도구는 학습한 어댑터와,
B 행렬을 0으로 만들어 기본 가중치를 바꾸지 않는 어댑터를 각각 내보낸다.
`baseline.cact`와 `tuned.cact`는 모두 20층·4비트이고 confidence head가 없다.
같은 함수 설명·문항·초기 LED·엔진으로 비교한다. 11주차 배포본의 confidence를 이 두 모델에 적용하지 않는다.
학습 입력의 최대 토큰 수를 먼저 검사하며, 제한을 넘으면 잘라서 학습하지 않고 중단한다.
학습 직전에도 공개 평가 문장과의 완전 중복을 검사한다. 의미가 같은 다른 문장의 중복은 사람이 검토한다.
학습·내보내기가 중단되면 복원과 앱 실행을 막는다. 오류 원인을 고친 뒤 `uv run ex02`를 다시 실행한다.
기본·학습 모델 두 파일의 저장이 모두 끝나야 사용할 수 있다.

공용 학습 함수는 버전을 고정한 `cactus-compute==4.2.0`의 Python 학습·내보내기 모듈을 사용한다.
패키지를 갱신하면 해당 API와 저장 형식을 다시 검증한다. 모델 다운로드는 수업 전에 마친다.

## 검증 명령과 출처

```powershell
uv run python -m unittest discover -s tests -v
```

이 테스트는 경계값·잘못된 인자·부분 실행 방지·연결 종료·실패 집계·실제 상태 대조를 확인한다.
모델 품질과 학습 시간은 실제 모델 실행으로 별도 확인한다.

### 2026-11-13 실행 기록

Apple M1 Max, Python 3.12, 로컬 시뮬레이터에서 각 모델을 따로 실행한 한 번의 관찰이다.
Cactus 패키지는 4.2.0, 엔진은 4.1.0(`4e822c90`), Needle 가중치 revision은 `d6c7d6a2`다.
Ollama는 0.40.14, 모델은 `qwen3.5:2b`(`dfaf2605162e`)다. 생성 상한은 256토큰이다.

| 모델 | 제어 성공 /16 | 무호출 문항의 오호출 /6 | 추론 중앙값 | p95 | 오류 문항 |
|---|---:|---:|---:|---:|---:|
| Ollama qwen3.5:2b | 9 | 4 | 296.2ms | 658.2ms | 1 |
| Needle 배포본 | 10 | 1 | 60.6ms | 179.9ms | 3 |
| Needle 기본 4비트·20층 | 9 | 1 | 68.5ms | 206.8ms | 1 |
| Needle 학습 4비트·20층 | 10 | 0 | 69.6ms | 236.9ms | 1 |

학습 전후의 한국어 성공은 2/8에서 3/8, 영어는 모두 7/8이었다.
토큰 한도 초과 등 실패도 분모에 포함했다. 이 작은 평가셋의 점수로 모델의 일반 성능을 단정하지 않는다.
학습 효과는 아래 두 행끼리 비교한다. 배포본과 학습본은 양자화와 confidence 조건이 다르다.

48개 학습 예제 중 6개를 검증용으로 나누고, JAX 0.12.0.1의 CPU에서 4 epochs·batch 4로 44번 갱신했다.
가장 긴 예제는 305토큰이었고 실제 학습 길이는 512토큰이었다. 모델 준비·학습·저장까지 약 339.4초였다.
저장한 두 `.cact`는 각각 약 63.44MB이며 새 프로세스에서 복원·제어까지 확인했다.
